# 数据模型、接口、测试与实施计划

> **错误码 Source of Truth**：各模块 `*ErrorCodes.ets`（及 `PlatformErrorCodes`、SESSION/CMD/LOG 散落常量）。本文 §7 同步自代码；若与历史架构文或他处码表冲突，**以代码常量为准**。

## 1. 目的

本文把无线调试工具的公共领域模型、Repository/UseCase 接口、错误码、存储表、测试策略和开发阶段统一收束，作为后续编码、评审和真机验证的执行基线。

适用范围：

1. 蓝牙模块。
2. WiFi 与网络模块。
3. 星闪模块。
4. 统一日志中心。
5. 统一命令面板。
6. 权限、后台、能力探测、设置。

## 3. 核心领域模型

### 3.1 DebugTarget

```text
DebugTarget
  id: string
  module: ModuleType
  protocol?: ProtocolType
  displayName: string
  address?: string
  addressType?: string
  host?: string
  port?: number
  uuid?: string
  alias?: string
  favorite: boolean
  attributes: Record<string, string | number | boolean>
```

用途：

1. 抽象蓝牙设备、WiFi AP、网络 endpoint、NearLink 设备。
2. 支撑统一收藏和最近访问。
3. 支撑日志中心按目标筛选。

### 3.2 DebugSession

```text
DebugSession
  id: string
  type: SessionType
  module: ModuleType
  protocol: ProtocolType
  target?: DebugTarget
  displayName: string
  mode: expert | light
  state: SessionState
  startAtMs: number
  endAtMs?: number
  result?: SessionResult
  error?: DebugError
  tags: string[]
  attributes: Record<string, string | number | boolean>
```

### 3.3 DebugLogRecord

```text
DebugLogRecord
  id: string
  sessionId: string
  module: ModuleType
  protocol: ProtocolType
  direction: Direction
  recordType: bytes | text | state | error | metric | permission | lifecycle
  timestampMs: number
  payloadRef?: PayloadRef
  payloadSize: number
  summary: string
  displayHint: text | hex | mixed | json | none
  appCode?: string
  nativeCode?: string | number
  attributes: Record<string, string | number | boolean>
```

### 3.4 PayloadRef

```text
PayloadRef
  storageType: inline | file
  inlineBytes?: Uint8Array
  filePath?: string
  offset?: number
  length: number
  sha256?: string
```

规则：

1. 小 payload 可 inline。
2. 大 payload 写文件。
3. 导出时根据 ref 读取原始 bytes。
4. UI 展示只读 payload，不回写。

## 7. 错误码映射

> **同步说明（以代码为准）**
>
> | 源文件 | 覆盖域 |
> | --- | --- |
> | `common/yobluetooth/.../BluetoothErrorCodes.ets` | BT / BLE / `YW-PERM-1001` |
> | `features/wifi_network/.../WifiNetworkErrorCodes.ets` | WIFI / NET / MQTT / `YW-PERM-200x` / `YW-CAP-2001` |
> | `features/nearlink/.../NearLinkErrorCodes.ets` | NL / `YW-PERM-3001` |
> | `common/storage/.../StoreErrorCodes.ets` | STORE / EXPORT |
> | `common/platform/.../KitEventSubscription.ets` → `PlatformErrorCodes` | PLATFORM |
> | `SessionManager` / `CommandUseCases` / `PayloadTextCodec` / `RepeatCommandCoordinator` | SESSION / LOG / CMD（散落，尚无独立 `*ErrorCodes.ets`） |
>
> 下文语义与常量名对齐；曾冲突项已按代码纠正（如 `YW-BT-1003`≠SPP 连接失败、`YW-BLE-2001`≠扫描失败、`YW-NET-1003/1004` 与 MQTT 独立域）。

### 7.6 会话 / 日志 / 命令 / 平台（散落码）

尚无独立 `*ErrorCodes.ets`，以下自实现处摘录：

| appCode | 出处 | 含义 |
| --- | --- | --- |
| `YW-SESSION-1001` | `SessionManager` / 各模块 Session UC | 会话创建/持久化失败 |
| `YW-SESSION-1002` | `SessionManager` | 会话不存在 |
| `YW-SESSION-1003` | `SessionManager` / NearLink UC | 会话启动/状态机失败 |
| `YW-LOG-1001` | `SessionManager`（capture 失败回退） | 日志采集失败 |
| `YW-CMD-1001` | `CommandUseCases` | 命令编码失败 |
| `YW-CMD-1002` | `CommandUseCases` / FakeTransport | 连接不可写 / 写失败回退码 |
| `YW-CMD-1100` | `PayloadTextCodec` | 不支持的 payload 编码（encode） |
| `YW-CMD-1101` | `PayloadTextCodec` | 不支持的 payload 编码（decode） |

## 10. 代码评审清单

### 10.1 架构

1. UI 是否直接调用平台 API。
2. ViewModel 是否保存连接真相状态。
3. DataSource 是否有释放路径。
4. feature 之间是否出现横向依赖。
5. common 是否包含业务语义。
6. 错误是否保留 nativeCode。
7. 权限是否按场景申请。

### 10.2 日志

1. 是否保留原始 payload。
2. 是否误把 byte stream chunk 当业务帧。
3. 是否把敏感数据写入 HiLog。
4. 导出是否可选择脱敏。
5. 大 payload 是否走文件。

### 10.3 并发

1. GATT 操作是否串行。
2. 命令发送是否队列化。
3. 端口扫描是否有限并发。
4. 长任务是否可取消。
5. UI 线程是否被阻塞。

### 10.4 后台与生命周期

1. onBackground 是否通知运行会话。
2. onForeground 是否 reconcile 平台真实状态。
3. 后台扫描是否被禁止或明确申请后台策略。
4. socket 中断是否能恢复或提示。
5. 页面退出是否只释放 UI 订阅。
