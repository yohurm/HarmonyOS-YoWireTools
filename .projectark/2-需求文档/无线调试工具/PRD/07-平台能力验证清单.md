# HarmonyOS 无线调试工具 PRD - 平台能力验证清单

## 1. 文档定位

本文列出 PRD 阶段不能直接承诺、需要通过 HarmonyOS 官方文档、真机、权限审核或样例验证确认的能力。该文档不是测试计划，而是需求边界清单，用于防止后续开发把平台不确定能力写成确定功能。

## 2. 验证分级

| 分级 | 含义 |
| --- | --- |
| 文档已确认 | 官方文档已有明确能力，但仍需开发阶段接入验证 |
| 权限待确认 | API 存在，但普通应用权限可能不可用 |
| 真机待验证 | 文档有能力，但必须依赖设备、系统版本或外设 |
| 方案待确认 | 产品需要该能力，但实现路径需要技术方案选择 |
| 不作为首期承诺 | 架构预留或后续增强，不阻塞首期 |

## 7. 不能直接承诺的能力

以下能力在产品宣传或对外说明中不能直接承诺，除非后续验证通过：

- 获取真实蓝牙物理 MAC。
- 获取所有 WiFi 真实 BSSID/MAC。
- 应用内完整控制 WiFi 开关、热点、P2P。
- 所有设备后台长连接永不中断。
- 强制实时 WiFi 扫描刷新。
- 经典蓝牙 SDP 扫描与 Channel 直连。
- BLE 所有高级连接参数都可设置。
- 星闪多连接和后台长时间稳定连接。
- 未配对星闪 dataTransfer 默认加密。

| 字段 | 说明 |

| 权限条件 | 普通权限、ACL、系统应用、企业应用 |
| 降级策略 | 不支持时用户看到什么 |
| 影响文档 | 需要同步更新哪些 PRD |
