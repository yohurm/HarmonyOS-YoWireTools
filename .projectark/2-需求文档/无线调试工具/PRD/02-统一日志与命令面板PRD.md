# HarmonyOS 无线调试工具 PRD - 统一日志与命令面板

## 1. 文档定位

本文描述跨蓝牙、WiFi、星闪三个模块复用的统一会话日志、命令收藏、命令面板、周期发送、导入导出和本地数据安全需求。

统一日志与命令面板是本项目的核心能力，不是后续附加功能。用户已经确认命令面板是重点功能之一，需要从底层需求上规划完整，而不是后续临时补入口。

## 2. 设计目标

| 目标 | 说明 |
| --- | --- |
| 可复现 | 用户能用命令面板重复执行同一组操作 |
| 可追踪 | 每次扫描、连接、发送、接收、错误都能进入会话日志 |
| 可导出 | 调试结果能以 TXT、CSV、JSON 导出 |
| 可阅读 | UI 支持文本、HEX、混合视图 |
| 可扩展 | 同一套命令模型可覆盖 SPP、BLE Write、Socket、星闪 dataTransfer |
| 可控 | 周期发送、端口扫描、后台记录等高风险能力必须有开关和限制 |

## 3. 会话日志

### 3.1 会话类型

| 会话类型 | 模块 | 典型内容 |
| --- | --- | --- |
| 经典蓝牙 SPP 会话 | 蓝牙 | 连接、断开、发送字节、接收字节、错误 |
| BLE GATT 会话 | 蓝牙 | 扫描、连接、服务发现、读写、Notify、MTU、PHY |
| WiFi 扫描会话 | WiFi | AP 列表、RSSI、信道、刷新时间、扫描限制 |
| 网络诊断会话 | WiFi | Ping、DNS、TraceRoute、Whois、端口扫描结果 |
| Socket 会话 | WiFi | TCP/UDP/HTTP/WebSocket/MQTT 收发 |
| 星闪 SSAP 会话 | 星闪 | 扫描、连接、服务、Property 读写、通知、MTU |
| 星闪 dataTransfer 会话 | 星闪 | UUID 端口、连接状态、发送、接收、加密状态 |
| 命令面板会话 | 全局 | 面板中每个命令的执行结果和耗时 |

### 3.2 日志记录字段

| 字段 | 说明 |
| --- | --- |
| 时间戳 | 默认毫秒级 |
| 模块 | 蓝牙、WiFi、星闪 |
| 会话 ID | 关联一次调试过程 |
| 事件类型 | scan、connect、disconnect、send、receive、read、write、notify、error 等 |
| 方向 | 发送、接收、系统事件、用户操作 |
| 协议 | SPP、BLE、TCP、UDP、HTTP、WebSocket、MQTT、SSAP、dataTransfer 等 |
| 目标 | 设备地址、IP/端口、UUID、Property、Characteristic 等 |
| 原始数据 | ArrayBuffer/字节数据的原始记录 |
| 文本视图 | 按当前编码解析后的文本 |
| HEX 视图 | 十六进制显示 |
| 状态码 | 平台错误码、协议状态码或内部状态码 |
| 错误说明 | 用户可理解的错误解释 |
| 元数据 | RSSI、MTU、PHY、频段、信道、加密状态、权限状态等 |

### 3.3 日志显示格式

| 显示模式 | 行为 |
| --- | --- |
| 文本模式 | 优先按用户选择编码显示，无法显示的字节用占位提示 |
| HEX 模式 | 所有 payload 按 HEX 显示 |
| 混合模式 | 同时显示可读文本和 HEX 摘要 |
| 原始事件模式 | 展示完整事件字段，适合专家模式 |

SPP、TCP、UDP、dataTransfer 等字节流协议必须保存原始字节流。显示层不能把一次回调等同于业务包边界。对于 BLE Notify、SSAP Property Change 等属性型数据，也必须保存收到的原始 value。

### 3.4 日志操作

| 操作 | 要求 |
| --- | --- |
| 清屏 | 只清空当前显示，不删除底层会话日志，除非用户选择删除 |
| 暂停显示 | 暂停 UI 自动滚动，但继续记录日志 |
| 搜索 | 按关键字、HEX、UUID、IP、方向、错误码搜索 |
| 过滤 | 按事件类型、方向、协议、目标、时间范围过滤 |
| 复制 | 支持复制选中行或当前筛选结果 |
| 标记 | 用户可对关键日志行加标记 |
| 导出 | TXT、CSV、JSON |
| 删除 | 删除单个会话或清理历史日志 |

### 3.5 导出格式

| 格式 | 适用场景 | 要求 |
| --- | --- | --- |
| TXT | 人工查看、粘贴到问题单 | 格式清晰，包含方向、时间、目标、内容 |
| CSV | 表格分析、批量对比 | 每个事件一行，字段稳定 |
| JSON | 自动化复现、后续导入 | 保留完整结构和原始数据编码 |

导出默认不脱敏直出，但必须提供脱敏选项。脱敏对象包括：

- 蓝牙虚拟地址或实际地址。
- WiFi BSSID/MAC。
- IP 地址。
- 设备 SN。
- 用户手动指定的敏感字段。

## 4. 命令模型

### 4.1 命令类型

| 命令类型 | 适用模块 | 示例 |
| --- | --- | --- |
| 字节发送命令 | SPP、TCP、UDP、dataTransfer | 发送 HEX 或文本 |
| BLE 写入命令 | BLE | 对指定 Characteristic 写入 value |
| BLE 读取命令 | BLE | 读取指定 Characteristic/Descriptor |
| BLE 订阅命令 | BLE | 开启或关闭 Notify/Indicate |
| SSAP 写入命令 | 星闪 | 写入指定 Property |
| SSAP 读取命令 | 星闪 | 读取指定 Property |
| Socket 连接命令 | WiFi | 连接 TCP/WebSocket/MQTT 目标 |
| HTTP 请求命令 | WiFi | GET/POST/PUT/DELETE 等 |
| 诊断命令 | WiFi | Ping、DNS、TraceRoute、端口扫描 |
| 控制命令 | 全局 | 延迟、等待响应、停止、跳转面板 |

### 4.2 命令字段

| 字段 | 说明 |
| --- | --- |
| 命令名称 | 用户可识别名称 |
| 命令类型 | 决定执行方式 |
| 所属模块 | 蓝牙、WiFi、星闪或通用 |
| 目标绑定 | 设备、UUID、Characteristic、IP、端口、Property 等 |
| Payload | 文本、HEX、JSON、表单、文件引用等 |
| 编码 | UTF-8、ASCII、GBK 预留、原始 HEX |
| 换行 | None、CR、LF、CRLF |
| 超时 | 命令执行超时时间 |
| 重试 | 是否失败重试、重试次数 |
| 期望响应 | 可选，用于智能判断成功 |
| 标签 | 分类、搜索、面板分组 |
| 风险级别 | 普通、可能扰动、高频/高风险 |

## 5. 命令收藏

命令收藏是单条命令的保存能力。

| 需求 | 描述 |
| --- | --- |
| 保存当前输入为命令 | 用户在终端或 GATT/SSAP 页面可直接收藏当前操作 |
| 编辑命令 | 修改名称、payload、目标、编码、换行、超时 |
| 复制命令 | 基于已有命令创建新命令 |
| 删除命令 | 删除前确认 |
| 分类标签 | 支持按模块、设备、协议、项目标签分类 |
| 快速发送 | 在终端页或命令面板中一键发送 |

命令收藏必须支持跨会话复用，但目标绑定要有清晰规则：

- 绑定具体设备时，只在该设备会话中默认显示。
- 绑定协议类型时，可在同类协议中复用。
- 绑定全局时，可从命令面板入口选择目标后执行。

## 6. 命令面板

### 6.1 面板定位

命令面板用于把多条命令组织成可视化操作台。它服务于研发联调、测试复现、工厂步骤化操作。

### 6.2 面板结构

| 元素 | 说明 |
| --- | --- |
| 面板名称 | 例如“BLE 设备基础联调”“TCP 网关压测”“星闪 dataTransfer 常用命令” |
| 面板类型 | 蓝牙、WiFi、星闪、混合 |
| 按钮组 | 按场景组织命令 |
| 单个按钮 | 对应一条命令或一组命令 |
| 执行策略 | 单步、顺序、并行预留、循环 |
| 状态反馈 | 每个按钮显示执行中、成功、失败、最近耗时 |
| 日志关联 | 每次点击都进入当前会话日志 |

### 6.3 面板操作

| 操作 | 要求 |
| --- | --- |
| 新建面板 | 选择模块和模板 |
| 添加按钮 | 绑定命令或命令组 |
| 编辑按钮 | 名称、颜色、图标、命令、确认提示 |
| 排列按钮 | 支持分组、排序 |
| 执行按钮 | 单次点击执行 |
| 停止执行 | 对周期或长任务按钮可停止 |
| 查看结果 | 显示最近执行结果和日志入口 |
| 复制面板 | 便于基于模板扩展 |
| 删除面板 | 删除前确认 |

### 6.4 轻量模式与专家模式差异

| 模式 | 面板表现 |
| --- | --- |
| 轻量模式 | 只展示用户标记为轻量可用的按钮，隐藏高风险参数 |
| 专家模式 | 展示完整按钮、目标绑定、payload 摘要、执行策略 |

## 7. 周期发送

周期发送适用于 SPP、BLE Write、TCP/UDP、MQTT、星闪 dataTransfer 等。

| 配置 | 要求 |
| --- | --- |
| 间隔 | 用户可设置，必须有最小间隔限制 |
| 次数 | 可设置固定次数或持续发送 |
| 停止条件 | 手动停止、失败停止、达到次数、收到期望响应 |
| 日志 | 每次发送记录序号、时间、结果 |
| 风险提示 | 高频发送前提示可能影响设备或网络 |
| 后台行为 | 后台发送必须受全局后台设置控制 |

周期发送不应默认无限运行。若用户选择持续发送，必须显示明显的运行状态和停止入口。

## 8. 宏变量

命令 payload 需要支持宏变量，借鉴 Packet Sender 类工具。

| 宏 | 含义 |
| --- | --- |
| 当前时间 | 插入当前时间字符串 |
| Unix 时间戳 | 插入秒或毫秒时间戳 |
| 计数器 | 每次执行递增 |
| 随机数 | 指定范围随机值 |
| 随机 HEX | 指定长度随机字节 |
| 换行 | CR/LF/CRLF |
| 会话信息 | 当前设备别名、IP、端口等只读变量 |

宏展开后的结果必须写入日志，便于复现。

## 9. 本地数据

### 9.1 本地保存对象

| 对象 | 是否默认保存 |
| --- | --- |
| 会话日志 | 默认保存 |
| 收藏设备 | 默认保存 |
| 命令收藏 | 默认保存 |
| 命令面板 | 默认保存 |
| 导出记录 | 默认保存路径，不保存外部副本 |
| 敏感 payload | 跟随会话日志保存策略 |

### 9.2 清理策略

| 策略 | 要求 |
| --- | --- |
| 手动清理 | 用户可按模块、时间范围、会话类型清理 |
| 存储上限 | 设置中可配置日志总大小上限 |
| 自动清理 | 达到上限后按最旧会话提示或自动清理，策略可配置 |
| 敏感清理 | 提供一键清除日志、命令、设备收藏 |

## 10. 跨模块复用要求

| 能力 | 蓝牙 | WiFi | 星闪 |
| --- | --- | --- | --- |
| 文本/HEX 输入 | SPP、BLE Write | TCP/UDP/WebSocket/MQTT | dataTransfer、SSAP Write |
| 换行配置 | SPP、BLE 串口 | TCP/WebSocket/MQTT | dataTransfer |
| 周期发送 | SPP、BLE Write | TCP/UDP/MQTT | dataTransfer |
| 日志导出 | 所有蓝牙会话 | 所有 WiFi 会话 | 所有星闪会话 |
| 命令面板 | SPP、BLE | Socket、HTTP、MQTT | SSAP、dataTransfer |
| 设备收藏 | 蓝牙设备 | 网络目标/AP/LAN 设备 | 星闪设备 |

## 11. 风险与限制

| 风险 | 产品处理 |
| --- | --- |
| 周期发送造成设备压力 | 最小间隔、次数限制、显著停止入口 |
| 日志保存敏感数据 | 本地保存、脱敏导出、清理入口 |
| 命令面板误触 | 高风险命令可设置二次确认 |
| 后台持续发送 | 受后台设置控制，前台显示运行状态 |
| 原始字节不可读 | 同时提供文本、HEX、混合视图 |
