# HarmonyOS 无线调试工具 PRD - 权限后台兼容与降级

## 1. 文档定位

本文描述无线调试工具在权限申请、后台运行、系统能力、设备兼容、API 版本、隐私数据和降级体验上的产品需求。

无线调试工具高度依赖系统能力。蓝牙、WiFi、星闪、Socket、MDNS、WebSocket 等能力都可能受权限、设备类型、系统版本、后台策略影响。因此本项目必须把“能力不可用时用户看到什么”作为需求的一部分，而不是只描述理想路径。

## 2. 权限申请原则

权限申请遵循 HarmonyOS 推荐的按场景申请原则：

| 原则 | 要求 |
| --- | --- |
| 不在启动时一次性申请全部权限 | 用户进入具体功能时再申请 |
| 说明必须具体 | 告诉用户当前功能为什么需要该权限 |
| 拒绝后不反复打扰 | 提供页面内说明和设置引导 |
| 支持降级 | 权限缺失时尽量展示可用部分 |
| 记录状态 | 权限变化写入会话日志或状态日志 |

## 3. 权限矩阵

### 3.1 蓝牙

| 权限 | 关联能力 | 产品处理 |
| --- | --- | --- |
| `ohos.permission.ACCESS_BLUETOOTH` | 蓝牙扫描、连接、SPP、BLE、配对状态等 | 蓝牙模块主权限，进入相关功能时申请 |
| `ohos.permission.PERSISTENT_BLUETOOTH_PEERS_MAC` | 持久化蓝牙虚拟 MAC | 非基础权限，需要 ACL 审核；不可用时仍允许普通收藏 |
| `ohos.permission.MANAGE_BLUETOOTH` | 部分配对确认等管理能力 | 系统应用权限，不作为普通应用承诺 |
| `ohos.permission.MANAGE_BLUETOOTH_ADVERTISER_NAME` | BLE 广播名称设置 | 广播扩展能力中验证 |

### 3.2 WiFi/网络

| 权限 | 关联能力 | 产品处理 |
| --- | --- | --- |
| `ohos.permission.GET_WIFI_INFO` | WiFi 状态、扫描结果、连接信息 | WiFi 模块基础权限 |
| `ohos.permission.GET_WIFI_PEERS_MAC` | 真实 BSSID、P2P 真实地址等 | 不可用时显示随机/受限地址 |
| `ohos.permission.GET_WIFI_LOCAL_MAC` | 本机真实 MAC | 多数设备受限，不作为普通能力承诺 |
| `ohos.permission.SET_WIFI_INFO` | 主动扫描、连接配置、部分控制能力 | 权限敏感，控制类能力预留 |
| `ohos.permission.MANAGE_WIFI_CONNECTION` | WiFi 开关/连接管理 | 系统应用权限，不作为普通应用承诺 |
| `ohos.permission.MANAGE_ENTERPRISE_WIFI_CONNECTION` | 企业 WiFi 管理 | 企业场景权限，不作为普通用户承诺 |
| `ohos.permission.INTERNET` | HTTP、Socket、WebSocket、MQTT、Whois 等 | 网络协议调试基础权限 |
| 定位相关权限 | 部分扫描历史 API 或系统策略 | 按实际 API 版本提示 |

### 3.3 星闪

| 权限 | 关联能力 | 产品处理 |
| --- | --- | --- |
| `ohos.permission.ACCESS_NEARLINK` | 星闪扫描、广播、SSAP、dataTransfer | 星闪模块基础权限 |

## 4. 权限申请体验

### 4.1 触发时机

| 场景 | 权限申请 |
| --- | --- |
| 进入首页 | 不申请权限，只展示能力摘要或未知 |
| 进入蓝牙扫描 | 申请蓝牙权限 |
| 进入 WiFi 环境分析 | 申请 WiFi 信息权限 |
| 进入 Socket/HTTP | 申请网络权限 |
| 进入星闪扫描 | 申请星闪权限 |
| 使用持久化蓝牙地址 | 单独说明并申请对应权限 |

### 4.2 拒绝后的展示

| 状态 | 展示 |
| --- | --- |
| 首次拒绝 | 展示功能受限说明和重新申请入口 |
| 多次拒绝或不再询问 | 展示去设置开启的路径 |
| 权限不可申请 | 展示“当前应用类型不支持该能力” |
| 权限缺失但可降级 | 展示可用字段，隐藏受限字段 |

## 5. 后台运行

用户已确认后台长连接和后台持续记录日志默认支持，可在设置中开启或关闭。由于 HarmonyOS 后台策略可能影响蓝牙连接、Socket、扫描、定时任务，后台能力需要做成可配置、可解释、可降级。

### 5.1 后台设置

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 后台保持连接 | 开启 | 离开终端页后尽量保持当前连接 |
| 后台记录日志 | 开启 | 后台收到数据继续写入日志 |
| 后台周期发送 | 关闭 | 风险高，需要用户单独开启 |
| 后台通知 | 开启 | 后台运行时显示状态 |
| 后台异常提醒 | 开启 | 后台断开或失败时提醒 |

### 5.2 后台行为规则

| 场景 | 行为 |
| --- | --- |
| 用户返回上一页 | 提示保持连接或断开 |
| 应用进入后台 | 按设置保持连接和记录 |
| 后台连接丢失 | 记录日志，按自动重连设置处理 |
| 后台发送失败 | 停止周期发送并记录 |
| 系统限制后台 | 显示“系统限制导致后台能力不可用或中断” |

### 5.3 后台风险

| 风险 | 产品处理 |
| --- | --- |
| 耗电 | 设置中说明，长时间运行显示提醒 |
| 系统中断 | 会话日志记录中断原因 |
| 通知权限影响 | 提示通知关闭会影响后台可见性 |
| 周期发送扰动设备 | 后台周期发送默认关闭 |

## 6. API 版本与设备能力

### 6.1 能力检测

每个模块进入时需要检查：

- 当前设备类型。
- 当前系统版本。
- 所需 SystemCapability 是否存在。
- 所需权限是否可申请。
- 当前系统开关是否开启。
- 当前功能是否需要真机。

### 6.2 版本差异展示

| 场景 | 展示 |
| --- | --- |
| API 版本不足 | 显示当前系统不支持该功能 |
| 设备不支持 | 显示当前设备硬件不支持 |
| 仅系统应用可用 | 显示普通应用不可用 |
| 企业权限可用 | 显示需要企业管理权限 |
| 功能可降级 | 展示降级后的可用能力 |

## 7. 模块降级策略

### 7.1 蓝牙

| 受限项 | 降级 |
| --- | --- |
| 蓝牙未开启 | 只展示说明和打开系统设置入口 |
| 无蓝牙权限 | 不扫描、不连接，展示权限说明 |
| 无持久化权限 | 允许普通收藏，不固化虚拟地址 |
| BLE 多扫描实例不可用 | 降级为单扫描 |
| PHY 不可用 | 隐藏设置入口，保留状态说明 |
| SPP Server 不做首期 | 入口标为后续能力或隐藏 |

### 7.2 WiFi

| 受限项 | 降级 |
| --- | --- |
| 无 GET_WIFI_INFO | 不展示 AP 和当前 WiFi 详情 |
| 无 GET_WIFI_PEERS_MAC | BSSID/MAC 显示为随机/受限 |
| 主动扫描不可用 | 使用系统缓存扫描结果，显示更新时间 |
| WiFi 控制权限不可用 | 只提供系统设置引导 |
| WebSocket Server API 不足 | 只提供 Client |
| ARP 不可用 | LAN 扫描用 Ping/TCP 探测 |

### 7.3 星闪

| 受限项 | 降级 |
| --- | --- |
| 设备不支持星闪 | 星闪模块只展示不可用说明 |
| 无星闪权限 | 不扫描、不连接，展示权限说明 |
| 星闪开关关闭 | 提示开启 |
| dataTransfer 加密状态未知 | 显示未知，不允许标记为已加密 |
| 多连接未验证 | 限制单连接 |
| SSAP Server/Advertising 未开发 | 入口预留或隐藏 |

## 8. 隐私与安全

### 8.1 本地数据原则

用户已确认默认仅本地保存，不做云同步。

| 数据 | 默认策略 |
| --- | --- |
| 会话日志 | 本地保存 |
| 设备地址 | 本地保存 |
| 命令面板 | 本地保存 |
| 导出文件 | 用户主动导出 |
| 云同步 | 默认不做 |

### 8.2 敏感信息

| 信息 | 风险 | 处理 |
| --- | --- | --- |
| 蓝牙地址 | 可关联设备 | 导出时可脱敏 |
| WiFi BSSID/MAC | 可定位网络设备 | 导出时可脱敏 |
| IP 地址 | 可暴露网络环境 | 导出时可脱敏 |
| Payload | 可能包含 SN、密钥 | 默认直出，但提供脱敏 |
| 命令面板 | 可能包含密码或 token | 本地保存，删除入口明确 |

### 8.3 高风险操作提示

| 操作 | 提示 |
| --- | --- |
| 高频周期发送 | 可能影响设备或网络 |
| 端口扫描 | 仅用于本人管理或授权的本地网络 |
| UDP 流量发送 | 可能造成网络拥塞 |
| 未加密星闪 dataTransfer | 不要发送敏感数据 |
| 自动重连 | 可能掩盖断连问题 |

## 9. 错误解释体系

错误提示要包含三层：

| 层级 | 内容 |
| --- | --- |
| 用户说明 | 发生了什么 |
| 原因推断 | 可能是权限、开关、设备、网络、协议、系统限制 |
| 下一步 | 重新扫描、检查权限、打开系统设置、重连、导出日志 |

日志中保留原始错误码，UI 中显示可理解说明。
