> **状态：深研草稿（未定稿）**

## 1. 流程总览

```text
WiFi Tab → Segmented [网络调试]
  ├── C Segmented：Socket | HTTP | WS | MQTT
  ├── B 栏：会话/收藏列表
  ├── C 上 Traffic (~55%) + 下 Terminal/包编辑 (~45%)
  ├── Resend 队列 + Stop
  └── ⚙ 命令与面板 / 会话导出
```

**竞品**：PacketSender 主窗三区；YoWire 增 WS/MQTT（PRD）。
