## 1. 文档目的

本文定义 YoWire 无线调试工具 **L0～L2 全局用户交互流程**，覆盖：

1. 一级 Tab 切换与状态保留  
2. 模块顶栏 **⚙ 设置** 与 **更多 Tab** 全局设置  
3. 工作台 **deep link** 至模块内会话  
4. **NavDestination 返回栈** 与连接中返回 Dialog  
5. **专家 / 轻量** 模式切换及模块字段联动  

每一步均标注 **控件名**（与 UI 设计文档一致），供实现与验收对照。

## 2. 应用壳与冷启动

### 2.1 冷启动流程

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| 步1 | 点击桌面图标启动 App | 显示 Splash / 加载 Preference | — |
| 步2 | — | 恢复上次 Tab 或默认 **工作台** | `TabBar` / `SideNav` |
| 步3 | — | 若首次启动：检查蓝牙/WiFi/星闪权限摘要 | `CapabilityBanner`（各模块按需） |
| 步4 | — | 恢复各 Tab NavPathStack 栈顶（不销毁 Session） | `NavPathStack` |
| 步5 | — | 读取 **专家/轻量** 全局 Preference | `expertModePreference` |
| 步6 | — | 初始化 SessionManager：恢复进行中的连接/扫描/Resend 队列摘要 | `SessionManager` |
| 步7 | — | 读取存储上限与暂停落盘各模块 Preference | `StoragePreferenceService` |
| 步8 | 外部 Deep Link 冷启动 | 解析 URI → 目标 Tab + push（权限矩阵 §2.3 先验） | `DeepLinkHandler` |

### 2.2 冷启动权限矩阵（首次 / 摘要 Banner）

> 各模块 **按需** 展示 CapabilityBanner；**不** 阻塞进入 Tab；连接/扫描时再二次校验。

| 模块 | 检测项 | Banner 文案（摘要） | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- | --- | --- |
| 蓝牙 | 蓝牙开关 OFF | 「请开启蓝牙」 | 点 Banner | 系统蓝牙设置 deep link | `CapabilityBanner_bleOff` |
| 蓝牙 | ACCESS_BLUETOOTH 等未授 | 「需要蓝牙权限」 | 去授权 | 系统权限弹窗 | `CapabilityBanner_bleDenied` |
| 蓝牙 | 位置（扫描 BLE 需） | 「扫描 BLE 需位置权限」 | 去授权 | 弹窗；拒绝则扫描钮灰 | `CapabilityBanner_location` |
| WiFi | WiFi OFF | 「请开启 WLAN」 | 打开设置 | 系统 WLAN 页 | `CapabilityBanner_wifiOff` |
| WiFi | 位置（AP 扫描） | 「环境分析需位置权限」 | 去授权 | 扫描暂停直至授权 | `CapabilityBanner_wifiLocation` |
| 星闪 | 硬件不支持 | 「本机不支持星闪」 | — | 全占位；见星闪 01 流程 | `CapabilityBanner_nlUnsupported` |
| 星闪 | ACCESS_NEARLINK 未授 | 「需要星闪权限」 | 去授权 | 弹窗；见 P-* 流程 | `CapabilityBanner_nlDenied` |
| 星闪 | 系统星闪开关 OFF | 「请开启系统星闪」 | 打开设置 | 自动重检 | `CapabilityBanner_nlSwitchOff` |
| 全局 | 模拟器 | 各模块相应 Banner | — | 星闪/部分 BLE 受限 | `CapabilityBanner_simulator` |
| 工作台 | 聚合摘要 | 三模块 Chip：Ready/Denied/Off | 点 Chip | 切 Tab + 对应 Banner | `ModuleCapabilityCard_*` |

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| PM-1 | 首次启动完成检测 | 工作台显示 **PermissionSummaryStrip**（可折叠） | `PermissionSummaryStrip` |
| PM-2 | 点摘要 Strip 某模块 Chip | 切换 Tab 并展开该模块 Banner | `ModuleCapabilityChip` |
| PM-3 | 用户关闭摘要 Strip | 写入「不再显示冷启动摘要」Preference | `btnDismissPermSummary` |
| PM-4 | 非首次启动 | 仅模块 L0 按需显示 Banner；无全局弹窗 | `CapabilityBanner` |
| PM-5 | 从系统设置返回 | 各 Tab `onPageShow` 静默重检权限 | `CapabilityCheckService` |

## 3. 一级 Tab 切换流程

### 3.1 Tab 定义与切换

| Tab | 路由 ID | 主内容 | 明确不含 |
| --- | --- | --- | --- |
| 工作台 | `workbench` | 能力卡片、最近会话 | 日志中心、命令编辑 |
| 蓝牙 | `bluetooth` | SPP / GATT / UART / 实验室 | 全局命令 |
| WiFi | `wifi` | 环境分析 + 网络调试 | 独立日志 Tab |
| 星闪 | `nearlink` | SSAP + dataTransfer | 空白占位（不可用态） |
| 更多 | `more` | **仅全局设置** | 日志/命令/模块调试 |

### 3.2 Tab 切换逐步流程

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| 步1 | 点 **工作台** Tab | 切换至工作台 L0；保留其他 Tab 栈 | `TabItem_workbench` |
| 步2 | 点 **蓝牙** Tab | 切换至蓝牙模块 L0（默认 BLE GATT 或上次子模式） | `TabItem_bluetooth` |
| 步3 | 点 **WiFi** Tab | 切换至 WiFi Segmented 上次选中项 | `TabItem_wifi` |
| 步4 | 点 **星闪** Tab | 显示 CapabilityBanner + SSAP/dataTransfer | `TabItem_nearlink` |
| 步5 | 点 **更多** Tab | 显示全局设置单层列表 | `TabItem_more` |
| 步6 | 切换 Tab | **不销毁** 各模块进行中的连接 / 扫描 Session | `SessionManager` |
| 步7 | 切换 Tab | 后台连接按 **更多→权限与后台** 策略保持或暂停 | `backgroundConnectionSwitch` |

### 3.3 Tab 切换 Session 保留矩阵

> Tab 切换 **不 pop** NavPathStack；各模块运行时态独立保留。

| 保留项 | 蓝牙 | WiFi | 星闪 | 工作台 | 控件名 |
| --- | --- | --- | --- | --- | --- |
| NavPathStack 栈顶 | ✓ L0～L2 保持 | ✓ | ✓ | ✓ L0 | `NavPathStack` |
| BLE/GATT 连接 | ✓ 后台保持 | — | — | — | `BleConnectionSession` |
| SPP/UART 连接 | ✓ | — | — | — | `SppSession` / `UartSession` |
| BLE 扫描进行中 | ✓ 可后台暂停* | — | — | — | `BleScanSession` |
| WiFi AP 周期扫描 | — | ✓ | — | — | `WifiScanSession` |
| TCP/WS/MQTT 连接 | — | ✓ | — | — | `NetworkSession` |
| Resend/周期发送队列 | — | ✓ 独立队列 | — | — | `ResendScheduler_wifi` |
| SPP/DT 周期发送 | ✓ | — | ✓ | — | `PeriodicSendScheduler` |
| SSAP/DT 连接 | — | — | ✓ 互斥单连接 | — | `NearlinkSession` |
| Filter/Write 草稿 | ✓ Sheet 状态 | ✓ | ✓ Port/Write 草稿 | — | `UiStateRestore` |
| Traffic/Log scroll | ✓ GATT Log | ✓ Traffic | ✓ SSAP/DT Log | — | `ScrollStateStore` |
| CapabilityBanner | ✓ 各模块独立 | ✓ | ✓ | 聚合 Chip | `CapabilityBanner` |

*扫描后台策略：⚙·扫描·「切 Tab 暂停扫描」Switch 默认 OFF（保持扫描）。

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| TS-1 | 蓝牙 Connection 页 → WiFi Tab | 蓝牙栈保留 Connection；WiFi 恢复上次 Segmented | `TabBar` |
| TS-2 | WiFi Resending → 蓝牙 Tab | Resend 继续；蓝牙无 Chip 干扰 | `chipResending` |
| TS-3 | 切回原 Tab | **毫秒级** 恢复栈顶 UI；scroll 位置接续 | `TabBar` |
| TS-4 | 连接中切 Tab 且设置「切换时询问」 | KeepConnectionDialog 可选 | `KeepConnectionDialog` |
| TS-5 | App 进后台再回前台 | Session 保持；权限静默重检 | `SessionManager` |
| TS-6 | 低内存杀进程 | 下次冷启动：最近会话卡片可 deep link 恢复摘要 | `RecentSessionCard` |
| TS-7 | 专家切换 Tab | 不改变 Session；仅字段显隐 onResume 刷新 | `ExpertModeObserver` |

### 3.4 宽屏 A 栏 Tab 切换

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| 步8 | 点 A 栏 **蓝牙●** | B/C 栏加载蓝牙三分栏骨架 | `SideNavItem_bluetooth` |
| 步9 | 点 A 栏 **WiFi** | B AP 列表 + C 图表区恢复 | `SideNavItem_wifi` |

## 4. 模块顶栏 ⚙ 设置流程

### 4.1 标准顶栏模板

```text
[← 返回]  模块/页面标题          [上下文操作] [⚙ 设置]
```

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| 步1 | 在模块 L0/L1 点 **⚙ 设置** | push **模块设置 NavDestination**（非 Sheet） | `btnModuleSettings` |
| 步2 | 手机 <600vp | 全屏 `BluetoothSettingsPage` / `WifiSettingsPage` | `NavDestination_settings` |
| 步3 | 宽屏 ≥600vp | C 栏 navigate 设置（A/B 保持可见） | `SettingsPanel` |
| 步4 | 设置页点 **← 返回** | pop NavDestination；回到模块栈顶 | `btnSettingsBack` |
| 步5 | — | **禁止** 从「更多」Tab 进入模块专有设置 | IA 约束 |

### 4.2 各模块 ⚙ 上下文操作对照

| 页面 | 上下文操作（≤3） | ⚙ 目标页 |
| --- | --- | --- |
| BLE GATT 扫描 | 扫描/停止 · Filter | `bluetooth/settings` |
| 经典 SPP | 扫描/刷新 · Filter | 同上 |
| BLE UART | SCAN/STOP · Filter | 同上 |
| WiFi 环境分析 | 暂停/恢复 · Filter | `wifi/settings` |
| WiFi 网络调试 | 新建/连接 · Filter* | 同上 |
| 星闪 SSAP | 扫描/停止 · Filter | `nearlink/settings` |

*LAN/诊断模式下 Filter 替换为子网/端口 Filter。

### 4.3 设置页五大分组（蓝牙 / WiFi 摘要）

**蓝牙 ⚙ TabBar：**

| Tab | 内容 |
| --- | --- |
| 会话与日志 | Session 列表、导出、清理 |
| 命令与面板 | SPP/BLE/Macro、Panel Grid |
| 扫描 | Filter 预设、RSSI、duty |
| 连接 | UUID、MTU、PHY、收藏设备 |
| 高级 | Reliable Write、实验室、后台 |

**WiFi ⚙ 分组：**

| 分组 | 内容 |
| --- | --- |
| 会话与日志 | 扫描快照、Traffic、诊断 |
| 命令与面板 | HTTP/Socket/MQTT、Panel Grid |
| 环境分析 | scanSpeed、GroupBy、国家码 |
| LAN | 超时、线程数（专家） |
| 网络调试 | Resend、Smart Response、宏 |

## 7. 工作台 Deep Link 流程

### 7.1 工作台卡片类型

| 卡片 | 内容 | 点击行为 |
| --- | --- | --- |
| 模块能力摘要 | 蓝牙/WiFi/星闪状态 Chip | 切换对应 Tab |
| 最近会话 | 协议图标、设备名、时间 | **deep link** 至模块内会话页 |
| 星闪能力 | Ready/Denied Banner | 跳转星闪 Tab 或权限引导 |
| 快捷收藏（P1） | 常用命令/设备 | deep link 至终端或 GATT |

### 7.3 工作台 → 模块逐步流程

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| 步1 | 打开 App | 默认或上次 Tab 为 **工作台** | `TabItem_workbench` |
| 步2 | 点卡片「蓝牙 · 上次 SPP 会话」 | 切换 **蓝牙** Tab + navigate SPP 终端 | `RecentSessionCard_spp` |
| 步3 | — | 恢复 SessionLog 上下文（只读历史 + 可选重连） | `SessionRestoreService` |
| 步4 | 点「WiFi · 环境扫描快照」 | WiFi Tab → 环境分析 → C 恢复图表 | `RecentSessionCard_wifiScan` |
| 步5 | 点模块能力卡片「进入蓝牙」 | 蓝牙 Tab L0（BLE GATT 默认或上次子模式） | `ModuleCapabilityCard_bluetooth` |
| 步6 | 外部 App Link 打开 URI | `Want` 映射上表路由 | `DeepLinkHandler` |
| 步7 | deep link 目标模块权限不足 | 先显示 CapabilityBanner + 引导 | `CapabilityBanner` |

## 8. NavDestination 返回栈流程

### 8.1 层级定义

| 层级 | 名称 | 返回行为 | 示例 |
| --- | --- | --- | --- |
| L0 | 模块工作台根 | 无返回 | BLE GATT 扫描列表 |
| L1 | 子流程根页 | 返回 L0 | 经典 SPP 设备列表 |
| L2+ | 详情/设置 | 返回 L1 或 L0 | GATT 已连接、模块 ⚙ |

### 8.2 普通返回流程

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| 步1 | L2+ 页点 **← 返回** | `NavPathStack.pop()` | `btnNavBack` |
| 步2 | L1 页（无 L0 返回） | 隐藏返回按钮 | — |
| 步3 | 系统手势返回 | 同 pop 行为 | 系统 Back |
| 步4 | Sheet/Dialog 打开时 | **不压栈**；先关闭 Sheet 再 pop | `FilterSheet` / `ConnectSheet` |
| 步5 | 模块 ⚙ 设置 | push NavDestination；返回 pop 至模块页 | `BluetoothSettingsPage` |

### 8.3 连接中返回 — KeepConnectionDialog

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| 步1 | SPP/UART/GATT/SSAP **连接中或已连接** 按返回 | 拦截 pop；弹出 Dialog | `KeepConnectionDialog` |
| 步2 | 选 **保持连接** | pop 页面；连接在后台继续 | `btnKeepConnection` |
| 步3 | 选 **断开并返回** | 执行 disconnect → pop | `btnDisconnectAndBack` |
| 步4 | 选 **取消** | 关闭 Dialog；留在当前页 | `btnDialogCancel` |
| 步5 | Reliable Write 进行中 pop | 若设置 ON：自动 Abort RW | `reliableWriteAutoAbortSwitch` |

### 8.4 Tab 切换 vs 返回栈

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| 步1 | 在蓝牙 GATT Connection 页切 **WiFi** Tab | 蓝牙栈 **保留** Connection 栈顶 | `TabBar` |
| 步2 | 切回 **蓝牙** Tab | 恢复 GATT Connection 页 | `TabItem_bluetooth` |
| 步3 | 在 Connection 页切 Tab 且选「断开」 | 断开后再切换 | `KeepConnectionDialog` |
