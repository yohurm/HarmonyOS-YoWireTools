# 01 — 会话日志导出逐步交互流程

> **状态：深研草稿（未定稿）**  
> **版本**：v0.1 · 2026-07-03  
> **依据**：`01-功能清单/00-全局能力边界与PRD对照.md` §3.2 · `03-UI设计/00-全局框架/03-模块自治与会话命令模型.md` · PRD `02-统一日志与命令面板PRD.md` · `feature-inventory/00-UI架构修正-模块自治与后端统一.md` · 各模块 `04-*设置*流程.md`  
> **范围**：蓝牙 / WiFi / 星闪 各模块 ⚙ → **会话与日志**：筛选 · 预览 · TXT/CSV/JSON 导出 · 系统分享 Sheet  
> **铁律**：**无** 全局日志中心 Tab；导出入口 **仅** 模块 ⚙

---

## 1. 流程总览

```text
模块运行时（C 栏 Log / Traffic / 终端）
  └── 快捷入口：⋮ 会话记录… / SAVE / Save Log
        └── push 模块 ⚙ NavDestination → 会话与日志 分组
              ├── SessionFilterBar（类型/时间/设备）
              ├── SessionList → SessionDetail → LogViewer 预览
              └── ExportFlow：格式 · 范围 · 脱敏 · 进度 · Share Sheet
```

**八种会话类型**（统一 SessionLog 模型）：

| 类型 ID | 模块 | 列表入口 |
| --- | --- | --- |
| `spp_terminal` | 蓝牙 | 蓝牙 ⚙·会话与日志 |
| `ble_gatt` | 蓝牙 | 同上 |
| `ble_uart` | 蓝牙 | 同上 |
| `wifi_scan` | WiFi | WiFi ⚙·会话与日志 |
| `network_traffic` | WiFi | 同上 |
| `network_diagnostic` | WiFi | 同上 |
| `nearlink_ssap` | 星闪 | 星闪 ⚙·会话与日志 |
| `nearlink_datatransfer` | 星闪 | 同上 |

## 3. 筛选流程（SessionFilterBar）

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| FL-1 | 选 **类型** 下拉 | 蓝牙：SPP/GATT/UART/Lab；WiFi：scan/traffic/diag/LAN；星闪：SSAP/DT | `filterSessionType` |

| FL-5 | 点 **清除** | 恢复默认 | `btnFilterClear` |

| FL-8 | 调整 **保留天数** Stepper | 过期自动清理（可选） | `stepperRetentionDays` |
