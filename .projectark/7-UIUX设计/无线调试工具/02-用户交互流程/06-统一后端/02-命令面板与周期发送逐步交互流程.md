# 02 — 命令面板与周期发送逐步交互流程

> **状态：深研草稿（未定稿）**  
> **版本**：v0.1 · 2026-07-03  
> **依据**：`01-功能清单/00-全局能力边界与PRD对照.md` §3.3 · `03-UI设计/00-全局框架/03-模块自治与会话命令模型.md` · PRD `02-统一日志与命令面板PRD.md` §7 · 各模块 `04-*设置*流程.md` · `03-WiFi模块/06-SmartResponse与PanelGrid逐步交互流程.md`  
> **范围**：Panel Grid 运行 · Resend/周期发送队列 · 跨模块 Session/Command **隔离** · C 栏「从收藏选择」  
> **铁律**：**无** 全局命令中心 Tab；Panel Grid **编辑** 在模块 ⚙·命令与面板

---

## 1. 流程总览

```text
统一 Command 模型（后端）
  ├── 蓝牙 ⚙·命令与面板：SPP / BLE Write / Macro / 周期默认
  ├── WiFi ⚙·命令与面板：Socket/HTTP/WS/MQTT + Panel Grid
  └── 星闪 ⚙·命令与面板：SSAP Write / dataTransfer

运行时（各模块 C 栏）
  ├── 从收藏选择 Sheet（只读选取，非 Grid 编辑）
  ├── 周期发送 / Resend 队列 + Stop
  └── Panel Grid View 运行（WiFi ⚙ 内，非全局）
```

**跨模块隔离**：Command 存储分模块 namespace；Resend 队列分模块调度器；Tab 切换不串包。

## 18. Resend 队列状态机

| 状态 | UI | 转移 | 控件名 |
| --- | --- | --- | --- |
| IDLE | 无 Chip | Send+resend>0 → ACTIVE | `chipResending` |
| ACTIVE | Resending (N) 绿 | tick → ACTIVE；Stop → IDLE | `ResendScheduler_*` |
| CANCELLED | Toast 已停止 | — | `btnStopResending` |
| LIMIT | Toast 达上限 | cancelResendNum → IDLE | `cancelResendNumPreference` |

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| RS-Q1 | 队列 ACTIVE 改 resendEdit=0 再 Send | 新包独立入队或替换（设置） | `resendEdit` |
| RS-Q2 | App 杀进程 | 冷启动队列清空；最近会话可恢复单次包 | `SessionManager` |
