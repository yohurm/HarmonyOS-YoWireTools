## 3. 蓝牙模块流程树

> 索引：[02-蓝牙模块/README.md](../02-蓝牙模块/README.md)

```text
蓝牙 Tab L0（三入口并列）
├── 经典 SPP ─────────────────────────────────────────────
│   L0 设备列表 [已配对|附近]
│     → Connect UUID Sheet
│     → L1 终端（DataTerminal + 折叠 Log）
│     → ⚙ 设置 / ⋮ 会话记录
│   文档：02-经典SPP逐步交互流程.md
│
├── BLE GATT ─────────────────────────────────────────────
│   L0 扫描 [附近|已绑定] + Filter
│     → stopScan → CONNECT
│     → L1 连接阶段条
│     → L2 Connection：CLIENT | SERVER | Log
│     → Write Sheet / Macros Runtime
│     → ⚙ 会话与日志 / 命令与面板
│   文档：01-BLE-GATT逐步交互流程.md
│
├── BLE UART ─────────────────────────────────────────────
│   L0 扫描 + Filter
│     → Profile 匹配（Nordic…）
│     → L1 连接 4 步
│     → L2 终端（失败 → 引导 GATT）
│   文档：03-BLE-UART逐步交互流程.md
│
└── BLE 实验室（专家）──────────────────────────────────
    Hub → Advertiser / GATT Server / DFU(P3)
    Macros 运行时在 GATT Connection
    文档：05-BLE实验室Macros与DFU逐步交互流程.md

跨切：04-模块设置与会话命令流程.md
后端：06-统一后端/01-会话日志导出 · 02-命令面板与周期发送
```

## 4. WiFi 模块流程树

> 索引：[03-WiFi模块/README.md](../03-WiFi模块/README.md)

```text
WiFi Tab L0 Segmented
├── 环境分析 ─────────────────────────────────────────────
│   L0 AP 列表 + Filter + 周期扫描
│     → L1 详情 Sub-Tab [详情|信道|时间|…]
│     → C Export 快速 / ⚙ 会话归档

│
├── 网络调试 ─────────────────────────────────────────────
│   Segmented [Socket|HTTP|WS|MQTT]
│   B 收藏列表 + C Traffic(55%) + 编辑区(45%)
│     → TCP/UDP/SSL Resend + Stop
│     → HTTP GET/POST Headers/Auth/Upload
│     → WS Connect/Send/Close（YoWire PRD）
│     → MQTT Connect/Pub/Sub（YoWire PRD）
│   文档：02-网络调试 · 05-HTTP-WS-MQTT
│
├── LAN 与诊断 ───────────────────────────────────────────
│   子网/端口扫描 · Ping/DNS/Trace
│   文档：03-LAN与诊断逐步交互流程.md
│
└── ⚙ 设置五分组 ─────────────────────────────────────────
    会话与日志 · 命令与面板(Panel Grid)
    Smart Response（专家）· 环境/LAN/网络调试
    文档：04-WiFi模块设置 · 06-SmartResponse与PanelGrid
```
