## 1. 文档目的

本目录收录 YoWire 在 **手机 / 平板双栏 / 840vp 三分栏 / 折叠屏** 下的用户交互流程与断点穿越规则，确保：

1. 路由 ID 跨断点 **一致**  
2. Session **不断连**（除非用户确认）  
3. UI 状态 **接续**（选中、scroll、Sheet 草稿）  
4. **禁止** 第四 Inspector 列

## 3. 断点总表

| 断点 ID | 宽度 (vp) | 导航壳 | 内容布局 | 典型设备 |
| --- | --- | --- | --- | --- |
| **BP-PHONE** | <600 | 底部 5 Tab | 单栏 NavPathStack L0→L2 | 手机竖屏 |
| **BP-DUAL** | 600–839 | 底部 Tab 保留 | **B+C Split 4:6** | 平板竖持、小窗、折叠半屏 |
| **BP-TRIPLE** | ≥840 | **A 侧栏** ~240vp | **A+B+C**；B ~320–360；C flex | 平板横屏、PC 窗口 |
| **BP-XL** | >1440 | 同 BP-TRIPLE | 内容 max **2220vp** 居中 | 大屏显示器 |

### 3.1 栏职责（全断点）

| 栏 | BP-PHONE | BP-DUAL | BP-TRIPLE |
| --- | --- | --- | --- |
| A | —（底部 Tab 代） | — | **模块 Nav** |
| B | 列表在栈内 L0/L1 | **选谁** 列表 4/10 | **选谁** ~320–360vp |
| C | 工作区 push L2 | **做什么** 6/10 | **做什么** flex |

### 3.2 硬数字（全模块）

| 约束 | 值 | 验收 |
| --- | --- | --- |
| B 标题栏按钮 | **≤3** | 扫描/Filter/⚙ |
| C 工具栏按钮 | **≤6** | 超出 → ⋮ |
| Sheet（≥600） | **480×560** 居中 | Filter/Write/Port |
| 第四 Inspector | **禁止** | IA-04 P0 |
| WiFi AP 列表 | **B 栏** | 非 C Tab |
