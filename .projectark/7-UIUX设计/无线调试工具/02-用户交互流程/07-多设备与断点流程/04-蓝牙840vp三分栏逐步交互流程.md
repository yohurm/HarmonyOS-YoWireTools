## 1. 进入蓝牙 840 三分栏

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| BT-A1 | 宽度 ≥840vp | 底部 Tab → A 栏；A **蓝牙 ●** 可点 | `SideModuleNav` |
| BT-A2 | 点 A **蓝牙** | B 栏加载子 Nav + 扫描列表骨架 | `SideNavItem_bluetooth` |
| BT-A3 | — | C 栏 Empty 或上次工作区 | `EmptyState_bluetoothC` |
| BT-A4 | A 栏二级 Nav | GATT / SPP / UART / 实验室（专家） | `SideNavSub_bleGatt` 等 |
| BT-A5 | 切换 A 二级项 | B/C 切换子模式；**Session 互不影响** | `NavPathStack_bluetooth` |
| BT-A6 | 收起 A 抽屉 | B 标题「蓝牙 · {子模式}」 | `SideNavCollapse` |

**硬约束**：无第四 Inspector；B 标题 ≤3；C 工具栏 ≤6。

## 3. BLE GATT — A/B/C 逐步流程

> 手机对照：[`../02-蓝牙模块/01-BLE-GATT逐步交互流程.md`](../02-蓝牙模块/01-BLE-GATT逐步交互流程.md)  
> 600–839：[`02-600-839双栏切换流程.md`](02-600-839双栏切换流程.md) §4

### 3.1 B 栏 — 扫描与 Filter

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| G-B1 | — | B：Segmented 附近/已绑定 | `SegmentedControl_scannerBonded` |
| G-B2 | B 标题栏 | **扫描/停止 · Filter · ⚙**（≤3） | `TitleBar_B` |
| G-B3 | 点 **扫描** | 启动 BLE 扫描 | `btnScanToggle` |
| G-B4 | 点 **Filter** | 居中 Sheet **480×560** | `FilterSheet` |
| G-B5 | Filter 五维 + 专家第六维 | 实时预览匹配数 | `filterMfgDataMask` |
| G-B6 | Apply | B 列表过滤；Filter Chip 高亮 | `btnFilterApply` |
| G-B7 | 点 **⚙** | C navigate 蓝牙设置 | `btnModuleSettings` |

### 3.2 B → C 连接

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| G-C1 | 点 B `BleDeviceRow` | **stopScan** | `BleDeviceRow` |
| G-C2 | — | C 连接阶段条（Discover/Services/Notify） | `ConnectionStageBar` |
| G-C3 | Ready | C：**GATT 树 60% + Log 40%** 垂直分 pane | `GattTreeLogPane` |
| G-C4 | C 工具栏 | Disconnect · Read · Write · Notify · ⋮（≤6） | `Toolbar_gattC` |
| G-C5 | 树节点 Notify | Log pane 实时追加 | `GattLogViewer` |

### 3.3 Write Sheet 流程

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| G-W1 | C 点树节点 **Write** | 居中 Sheet 480×560 | `WriteCharacteristicSheet` |
| G-W2 | 选 Payload Text/HEX | 校验格式 | `inputWritePayload` |
| G-W3 | 勾选 Reliable Write | 专家可见 | `switchReliableWrite` |
| G-W4 | 高风险 UUID | 二次确认 Dialog | `WriteRiskConfirmDialog` |
| G-W5 | 确认 Write | Sheet 关闭；Log 记录；树值刷新 | `btnWriteConfirm` |
| G-W6 | 从 ⚙ 收藏选择 | Sheet 预填 SSAP 同构字段 | `btnPickFromFavorites` |
| G-W7 | 折叠屏开合 | Write 草稿接续（R-06） | `SheetDraftStore` |

### 3.4 Filter Sheet 840 专规

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| G-F1 | 打开 Filter | 居中 480×560；**非** 底 Sheet | `FilterSheet` |
| G-F2 | 存为预设 | 命名 Dialog → 蓝牙 ⚙·扫描 | `btnSaveFilterPreset` |
| G-F3 | 清除 Filter | Chip 消失；列表恢复 | `btnFilterClear` |
| G-F4 | Apply 空条件 | Toast（若 ⚙ 开启空 Filter 提示） | `Toast_emptyFilter` |
