| S-06 | 分屏多窗 | Split 仍生效 | 系统 MultiWindow |

## 3. 通用 B/C 职责

```text
┌────────────────────────┬──────────────────────────────┐
│ B 列表区 (4/8)         │ C 工作区 (6/8)               │
│ 标题栏 ≤3 按钮         │ 工具栏 ≤6                    │
│ Capability/Banner      │ 主内容 + 可选 Tab            │
│ List                   │ Log / Terminal / Chart       │
└────────────────────────┴──────────────────────────────┘
│ Bottom Tab（默认保留）                                  │
└────────────────────────────────────────────────────────┘
```

| 栏 | 职责 |
| --- | --- |
| B | **选谁**（设备/AP/会话） |
| C | **做什么**（调试/终端/图表） |

## 4. 蓝牙 · BLE GATT — B/C 逐步流程

> 手机对照：[`../02-蓝牙模块/01-BLE-GATT逐步交互流程.md`](../02-蓝牙模块/01-BLE-GATT逐步交互流程.md)

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| G-1 | 进入蓝牙 Tab → BLE GATT | B：Segmented 附近/已绑定；标题栏 扫描/Filter/⚙ | `SegmentedControl_scannerBonded` |
| G-2 | — | C：未选设备 → Empty「选择设备连接」 | `EmptyState_gatt` |

| G-5 | Filter Apply | B 列表过滤；C 不变 | `btnFilterApply` |

| G-7 | 连接 Ready | C：**Tab 树\|Log**（窄 C 无 60/40 分 pane） | `Tab_gattTreeLog` |
| G-8 | C 点树节点 Write | 居中 Sheet 480×560 + 确认 Dialog | `WriteCharacteristicSheet` |
| G-9 | C 点 **Disconnect** | 断开；B 行取消高亮；C Empty | `btnDisconnect` |
| G-10 | B 点 ⚙ | C navigate 替换为蓝牙设置（推荐 ≥700vp） | `btnModuleSettings` |

## 14. 断点穿越（与 840 / 手机）

### 14.1 <600 → 600–839（拉宽）

| 步 | 系统响应 | 控件名 |
| --- | --- | --- |
| U-1 | 当前栈顶 Session 映射到 B+C | `SplitLayoutMapper` |
| U-2 | 原 L2 全屏连接页 → B 选中 + C 工作区 | `NavPathStack` |
| U-3 | Sheet 打开态：Toast 关闭或转居中 Sheet | `SheetTransition` |
| U-4 | **不断连** | `SessionManager` |

### 14.2 600–839 → <600（收窄）

| 步 | 系统响应 | 控件名 |
| --- | --- | --- |
| D-1 | B 选中 + C 内容合并为 **单栏栈顶** | `NavPathStack` |
| D-2 | 典型保留 L2 连接/终端页 | — |
| D-3 | Split 选中、scroll、Write 草稿 **接续** | `UiStateRestore` |

详见 [03-840vp三分栏与折叠屏接续流程.md](03-840vp三分栏与折叠屏接续流程.md) §6。

- [ ] Filter ≥600 居中 Sheet
- [ ] 星闪不可用单栏占位
- [ ] GATT/SSAP 窄 C 用 Tab 替分 pane
