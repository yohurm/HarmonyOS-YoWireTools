## 2. 三分栏通用模型

```text
┌──────────┬─────────────────┬──────────────────────────────────┐
│ A 栏     │ B 栏            │ C 栏                              │
│ ~240vp   │ ~320–360vp      │ flex                              │
│ 模块 Nav │ 列表/会话       │ 树+Log / 终端 / 图表              │
│ 可收起   │ 标题 ≤3         │ 工具栏 ≤6 · 可放大全屏 C          │
└──────────┴─────────────────┴──────────────────────────────────┘
```

| 栏 | 职责 |
| --- | --- |
| A | **去哪**（模块级） |
| B | **选谁** |
| C | **做什么** |

Sheet/Dialog 为临时层，**不占** permanent 第四列。

## 5. 折叠屏 / 悬停 · 状态接续清单（扩展）

### 5.1 必须接续的状态（P0）

| # | 状态项 | 适用模块 | 接续要求 | 存储键 / 服务 | 验收 |
| --- | --- | --- | --- | --- | --- |
| R-01 | B 列表选中行 deviceId/sessionId | 全模块 | 开合后同一行高亮 | `SplitSelectionStore` | ✓ |
| R-02 | B Segmented 当前 Tab | 蓝牙/WiFi/星闪 | 附近/已绑定、SSAP/DT 等保持 | `SegmentedStateStore` | ✓ |
| R-03 | C GATT/SSAP 树展开节点 path[] | BLE GATT / SSAP | 展开路径完整恢复 | `TreeExpandStateStore` | ✓ |
| R-04 | C Log scroll offset | GATT/SSAP/SPP | scrollY 恢复 ±32vp | `ScrollStateStore` | ✓ |
| R-05 | C 终端 scroll + 输入框草稿 | SPP/UART/DT/Network | 终端位置 + CommandDock 文本 | `TerminalStateStore` | ✓ |
| R-06 | Write Sheet 字段草稿 | GATT / SSAP | UUID/Payload/选项保留 | `SheetDraftStore` | ✓ |
| R-07 | Filter Sheet 五维/六维条件 | 蓝牙/星闪/WiFi | Apply 态 + Chip 高亮 | `FilterStateStore` | ✓ |
| R-08 | Port UUID 输入 | dataTransfer | Sheet 输入框内容保留 | `PortUuidDraftStore` | ✓ |
| R-09 | WiFi C Sub-Tab 选中 | 环境分析 | 详情/信道/时间/评分 | `WifiEnvTabStore` | ✓ |
| R-10 | WiFi B AP 选中 bssid | 环境分析 | 图表绑定同一 AP | `ApSelectionStore` | ✓ |
| R-11 | Traffic 筛选/排序 | 网络调试 | 列筛选 Chip 保留 | `TrafficFilterStore` | ✓ |
| R-12 | Capability Banner 展开 | 星闪 | 折叠偏好保留 | `BannerExpandPref` | ✓ |
| R-13 | 模态 Sheet 打开态 | 全模块 | 关闭或恢复居中 480×560 | `ModalSheetController` | ✓ |
| R-14 | C 放大全屏态 | 终端/树类 | 折返后恢复三分栏比例 | `ExpandCStateStore` | ✓ |
| R-15 | Resend 队列运行态 | WiFi/SPP/DT | 不断连；RiskStrip 同步 | `ResendScheduler` | ✓ |
| R-16 | 连接阶段条进度 | GATT/SSAP/DT | 不重置为 Idle（除非真断） | `ConnectionStageStore` | ✓ |
| R-17 | A 栏当前模块 + 抽屉收起 | 全局 | A 高亮 ● 与路由 ID 一致 | `SideNavStateStore` | ✓ |
| R-18 | 工作台 C 会话列表 scroll | 工作台 | Recent/Active 滚动位置 | `WorkbenchScrollStore` | ✓ |
| R-19 | 设置 navigate 栈顶 | 模块 ⚙ | 返回后恢复工作区而非空 C | `SettingsNavStack` | ✓ |
| R-20 | Macros 运行进度（P2） | BLE GATT | 暂停/继续状态 | `MacrosRuntimeStore` | 可选 |

### 5.3 悬停布局流程

```text
┌─────────────────────────────┐  ← 上屏：B 列表 / 树浏览
│ 浏览区                       │
├─────────────────────────────┤  ← 折痕避让 16vp
│ C Log / 终端 / 操作          │  ← 下屏：操作区，底 40vp 边距
└─────────────────────────────┘
```

| 步 | 用户动作 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| H-1 | 折叠为悬停 | 不增加导航步骤 | `HoverLayout` |
| H-2 | 上屏滚动 B 列表 | 下屏 C 终端仍可操作 | `SplitHoverTop` / `SplitHoverBottom` |
| H-3 | 下屏 CommandDock 发送 | 上屏 B 选中不变 | `CommandDock` |
| H-4 | 展开回单屏 | §5.1 R-01～R-20 全部恢复 | `FoldStateObserver` |
| H-5 | 折痕区域 | 禁止放置 primary 按钮 | `FoldSafeArea` |

## 15. 接续失败降级策略

| 步 | 条件 | 系统响应 | 控件名 |
| --- | --- | --- | --- |
| F-1 | scroll 恢复失败 | 滚至 Log/终端 **底部**（非顶） | `ScrollStateStore_fallback` |
| F-2 | 树 path 无效 | 展开根 Service 层 | `TreeExpandStateStore_fallback` |
| F-3 | Sheet 草稿超限 | 截断 + Toast「草稿过长已截断」 | `SheetDraftStore` |
| F-4 | Session 已断开 | 清空接续；Recent 可 deep link | `SessionManager` |
