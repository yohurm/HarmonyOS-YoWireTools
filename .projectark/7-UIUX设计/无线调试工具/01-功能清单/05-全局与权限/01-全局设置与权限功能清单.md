组件 **`ModulePermissionBanner`**：各模块 L0/L1 顶栏下；**非**仅更多 Tab。

| 模块 | Banner ID | 触发条件 | 文案要点 | 动作 |
| --- | --- | --- | --- | --- |
| **蓝牙** | G-BNR-BT01 | 蓝牙关 / 无 BLUETOOTH / 无 CONNECT | 无法扫描连接 | 打开蓝牙设置 |
| **蓝牙** | G-BNR-BT02 | 无持久化 MAC ACL | 收藏不固化地址 | 说明 + 可选申请 |
| **WiFi** | G-BNR-WF01 | WiFi 关 | 无法扫描 | WiFi 设置 |
| **WiFi** | G-BNR-WF02 | 无位置 / GET_WIFI_INFO | 扫描受限 | 权限设置 |
| **WiFi** | G-BNR-WF03 | 无 GET_WIFI_PEERS_MAC | BSSID/MAC 受限 | Chip + 说明 |
| **WiFi** | G-BNR-WF04 | 无 INTERNET | 网络调试不可用 | 权限设置 |
| **星闪** | G-BNR-NL01 | Unsupported | 本机不支持 | 能力说明 |
| **星闪** | G-BNR-NL02 | Denied / 未请求 | 无 ACCESS_NEARLINK | 授权 Sheet |
| **星闪** | G-BNR-NL03 | 星闪开关关 | 请开启系统星闪 | 系统设置 |
| **星闪** | G-BNR-NL04 | Degraded | 部分能力不可用 | 可用列表 |

## 7. 模块权限矩阵与降级（PRD 06 §3、§7）

### 7.1 蓝牙（§3.1 · §7.1）

| 权限 | 关联能力 | 产品处理 | Banner/降级 |
| --- | --- | --- | --- |
| `ACCESS_BLUETOOTH` | 扫描、连接、SPP、BLE | 主权限，按场景申请 | G-BNR-BT01 |
| `PERSISTENT_BLUETOOTH_PEERS_MAC` | 持久化虚拟 MAC | ACL；不可用时普通收藏 | G-BNR-BT02 |
| `MANAGE_BLUETOOTH` | 配对确认等 | 不承诺普通应用 | 说明 |
| PHY / 多扫描实例 | 平台差异 | 单扫描；PHY 隐藏 | **蓝牙 ⚙·连接** |

### 7.2 WiFi/网络（§3.2 · §7.2）

| 权限 | 关联能力 | 产品处理 | Banner/降级 |
| --- | --- | --- | --- |
| `GET_WIFI_INFO` | WiFi 状态、扫描、连接 | 基础权限 | G-BNR-WF02 |
| `GET_WIFI_PEERS_MAC` | 真实 BSSID | 否则随机/受限 | G-BNR-WF03 |
| `GET_WIFI_LOCAL_MAC` | 本机 MAC | 多数受限，不承诺 | — |
| `SET_WIFI_INFO` | 主动扫描、控制 | 敏感；控制预留 | 缓存+更新时间 |
| `INTERNET` | HTTP/Socket/WS/MQTT/Whois | 网络调试基础 | G-BNR-WF04 |
| 定位 | 部分 API/策略 | 按版本提示 | G-BNR-WF02 |

| 受限项 | 降级 |
| --- | --- |
| 无 GET_WIFI_INFO | 不展示 AP/当前 WiFi 详情 |
| 无 GET_WIFI_PEERS_MAC | BSSID/MAC 随机或受限 Chip |
| 主动扫描不可用 | 系统缓存 + 最后更新时间 |
| WebSocket Server API 不足 | 仅 Client |
| ARP 不可用 | LAN 用 Ping/TCP |

### 7.3 星闪（§3.3 · §7.3）

| 权限/受限 | 产品处理 | Banner |
| --- | --- | --- |
| `ACCESS_NEARLINK` | 主权限 | G-BNR-NL02 |
| 设备不支持 | 模块不可用说明 | G-BNR-NL01 |
| 星闪开关关 | 系统设置引导 | G-BNR-NL03 |
| 加密未知 | 显示未知，禁止标已加密 | N-NL-07 |
| 多连接未验证 | 单连接 | N-NL-14 |
| SSAP Server/Advertising | 预留或隐藏 | N-NL-13 |
