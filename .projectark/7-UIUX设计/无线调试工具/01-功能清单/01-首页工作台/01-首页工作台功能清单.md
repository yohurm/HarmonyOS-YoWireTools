# 首页工作台功能清单

> **状态**：深研草稿  
> **依据**：`00-UI架构修正-模块自治与后端统一.md` §3、§6 · `22-YoWire-PRD与竞品能力差距矩阵-v2.md` §7（IA-01/02）、§9.1–§9.3 · **PRD 01**（IA 修订）  
> **UI 设计**：`03-UI设计/01-首页工作台/01-首页工作台页面设计.md`  
> **修订要点**：**无日志中心**；**无全局命令编辑**；最近会话 **deep link 模块内页**；周期发送/Resend 全局可见可停

---

## 1. 文档目的

枚举 **工作台 Tab（G-TAB-01）** 全量功能 ID，覆盖模块能力卡片、运行中/最近会话、快捷入口、deep link 路由及专家/轻量显隐矩阵；供首页 P0 验收与 PRD 01 回写对照。

**不做**：跨模块日志检索、命令 Panel Grid 编辑、模块专有参数（scanSpeed、MTU 等）。

---

## 5. 分组二：ModuleCapabilityCard（W-HOME-04/05）

### 5.1 卡片字段

| 字段 | 轻量 | 专家 |
| --- | --- | --- |
| 模块图标 + 名称 | ✓ | ✓ |
| 能力状态 Chip | 可用/需授权/需开启/受限/不支持 | 同左 |
| 一行说明 | 任务文案「连接 WiFi」 | + BSSID 片段、协议 |
| 主操作 Button | 进入模块 L0 | 同左 |
| 次要链接 | 权限说明、能力验证 | + 上次请求时间（G-EXP-08） |
| 角标 | 活跃会话数 | + Resend 数 |

### 5.2 分模块状态示例

| 模块 | 状态 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 蓝牙 | 受限 | 蓝牙已关闭 | 打开蓝牙设置 |
| 蓝牙 | 可用 | 已配对 3 台 | 进入蓝牙 |
| WiFi | 可用 | 已连接 `Yovo-Lab`，BSSID 脱敏 | 进入 WiFi·环境分析 |
| WiFi | 受限 | 位置权限拒绝 | 应用权限设置 |
| 星闪 | 不支持 | 设备未报告星闪能力 | 能力验证页 |
| 星闪 | Denied | 权限未授予 | 权限设置 |

### 5.3 Permission Banner 衔接（W-HOME-05）

- Card 内 **内联 Banner** 与模块 L0 **`ModulePermissionBanner`** 文案一致（见 `05-全局与权限/01-全局设置与权限设计.md` §4.3）。
- 点 Banner 动作 → 系统设置或能力说明，**非**日志中心。
- **GlobalCapabilityBanner（W-HOME-03）**：仅当 ≥2 模块同时阻断时显示；单模块阻断由对应 Card 自行 Banner。

## 6. 分组三：会话列表与 deep link（W-HOME-06/07/08/10）

### 6.1 ActiveSessionList

| 字段 | 轻量 | 专家 |
| --- | --- | --- |
| 模块图标 + 会话名称 | ✓ | + 协议 |
| 状态 Chip | 已连接/监听/Resending | + 会话 ID 片段 |
| 最近活动 | 「刚刚」 | 精确时间 + 字节数 |
| Resend | 「周期发送中」+ **Stop** | + 间隔秒数 + 剩余次数 |
| 进入 | 主按钮 deep link | 同左 |

**交互**：点卡片 / 进入 → deep link；Stop Resend 直接停止不跳转；长按 → 断开、重命名、跳转模块 ⚙·会话。

### 6.2 RecentSessionCards 与 deep link 规则（IA-02）

| 会话类型 | 目标路由 | 禁止 |
| --- | --- | --- |
| SPP / UART | `/bluetooth/spp-terminal?sessionId=` | `/log/list` |
| BLE GATT | `/bluetooth/gatt-detail?sessionId=` | `/log/detail` |
| WiFi 环境扫描 | `/wifi/env?sessionId=` | — |
| WiFi Traffic | `/wifi/net/traffic?sessionId=` | — |
| WiFi LAN/诊断 | `/wifi/net/lan?` 或 `/wifi/net/diag?` | — |
| SSAP | `/nearlink/ssap-client?sessionId=` | — |
| dataTransfer | `/nearlink/data-transfer?sessionId=` | — |

**W-HOME-10**：「更多会话」→ 先选模块 Sheet → 各模块 ⚙·会话与日志列表。

### 6.3 八种 SessionLog deep link 全表（W-HOME-08）

> 权威类型：`06-统一后端/01` §3 SL-TYPE-* · 路由：`00-全局能力边界` §6 · 流程：`02-用户交互流程/00-全局导航` §7

| SL-TYPE | sessionType | 卡片副标题示例 | deep link 路由 | Query | 恢复行为 |
| --- | --- | --- | --- | --- | --- |
| SL-TYPE-01 | `spp_terminal` | 经典 SPP · HC-05 | `/bluetooth/spp-terminal` | `sessionId` | C 终端；断开则重连 CTA |
| SL-TYPE-02 | `ble_gatt` | BLE GATT · 心率带 | `/bluetooth/gatt-detail` | `sessionId` · `charUuid?` | GATT 树 + Log pane |
| SL-TYPE-03 | `ble_uart` | Nordic UART · MTU 247 | `/bluetooth/uart-terminal` | `sessionId` | C 终端 + MTU 顶栏 |
| SL-TYPE-04 | `wifi_scan` | WiFi 扫描 · 42 AP | `/wifi/env` | `sessionId` | 环境 Sub-Tab 恢复 |
| SL-TYPE-05 | `network_diagnostic` | Ping 8.8.8.8 | `/wifi/net/diag` | `sessionId` · `tool?` | 诊断输出区 |
| SL-TYPE-06 | `network_traffic` | TCP 192.168.1.10:8080 | `/wifi/net/traffic` | `sessionId` | Traffic + 发送区 |
| SL-TYPE-07 | `nearlink_ssap` | SSAP · 温湿度 | `/nearlink/ssap-client` | `sessionId` | SSAP 树 + Log |
| SL-TYPE-08 | `nearlink_datatransfer` | dataTransfer · 端口 1 | `/nearlink/data-transfer` | `sessionId` | 终端 + 加密条 |

**附属**：`SL-TYPE-09` `command_panel_run` 不单独出现在 Recent；写入归属模块 SessionLog。

**解析失败**：未知 type → Toast「会话已过期」；**禁止** fallback `/log/*`。

### 6.4 Active / Recent 排序

| 规则 | 行为 | ID |
| --- | --- | --- |
| 活跃优先 | Active 在 Recent 之上 | W-HOME-06 |
| Recent 上限 | 8 条；超出 → W-HOME-10 | W-HOME-07 |
| Resend 置顶 | Active 内置顶 + RiskStrip | W-HOME-11 |

## 11. 布局与断点（W-HOME-14）

| 断点 | 布局 |
| --- | --- |
| <600vp | 纵向 Stack：Header → Cards → Active → Recent → QuickEntry |
| 600–839vp | ModuleCards 上、会话列表下；底部 Tab |
| ≥840vp | A Tab 栏 ●；B Cards + QuickEntry；C Active + Recent + RiskStrip |

### 11.1 ≥840vp A/B/C 栏位

| 栏 | 比 | 内容 | B 标题按钮 ≤3 |
| --- | --- | --- | --- |
| A | ~20% | L0 Tab 导航 | — |
| B | ~45% | ModuleCard ×3 + QuickEntry | 模式切换 |
| C | ~35% | Active + Recent + RiskStrip | 「更多会话」 |

**禁止**：第四 Inspector 列 · V5 式固定日志+命令。证据：`07-多设备/03` · E-HMS-001
