> **状态：架构定稿配套 · 2026-07-23**  
> **用途**：三路径（SPP / BLE-GATT / BLE-UART）+ 实验室的统一优先级与实现状态真相源。  
> **分册**：[`01-BLE-GATT`](01-BLE-GATT全量功能清单.md) · [`02-经典SPP`](02-经典SPP功能清单.md) · [`03-BLE-UART`](03-BLE-UART功能清单.md) · [`04-实验室`](04-BLE实验室与高级功能清单.md)

## 1. 定稿决策（与架构对齐）

| 决策项 | 定稿 |
| --- | --- |
| 身份 | `classicDeviceId` / `bleDeviceId` + `getRemoteDeviceTransport` |
| SPP 连接 | **单活跃写端** + 多会话摘要列表（非并行多 RFCOMM） |
| GATT 连接 | **多 Session 并行，应用层上限 4** |
| 收发 | 统一 TX WriteQueue（SPP/UART）+ 每 GATT Session 独立 OpQueue |
| 日志/命令 | `feature_debug_core`（SessionRuntimeStore / LogCapture / Command）；无全局日志中心 |
| 实验室 | P2 架构预留 / P3 不承诺 v1 |
