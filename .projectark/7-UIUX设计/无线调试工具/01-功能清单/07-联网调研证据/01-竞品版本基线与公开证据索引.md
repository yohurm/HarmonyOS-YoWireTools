## 1. 文档定位

本文不是竞品功能复述，而是 **可 citation 的公开证据注册表**。每条证据至少包含：

| 列 | 说明 |
| --- | --- |
| Evidence ID | `E-nRF-*` · `E-WFA-*` · `E-PS-*` · `E-SBT-*` · `E-NL-*` · `E-HMS-*` |
| 来源类型 | GitHub README / 官方文档 / Play Store / DevZone / 样例仓库 |
| URL | 完整 HTTPS 链接 |
| 摘要 | 一句话能力边界 |
| YoWire 落点 | `01-功能清单/` 或 `.research/feature-inventory/` 路径 |
| 版本/日期 | 能确认则写（Play Store 更新日、README 分支） |

**Gap 使用**：P0 必达项若无 `E-*` 支撑，必须在 `07-平台能力验证清单` 标 `V-*` 待验证。
