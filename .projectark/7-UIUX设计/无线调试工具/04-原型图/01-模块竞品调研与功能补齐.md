# BLE / SPP / WiFi / 星闪模块竞品调研与功能补齐

> **状态**：2026-07-03 联网调研后用于原型重设计  
> **目的**：补齐 YoWire APP 原型缺失的真实调试功能，避免只画扫描、终端和简单日志

---

## 1. BLE 调研

| 项目 / 产品 | 已实现能力 | YoWire 必须补齐 |
| --- | --- | --- |
| nRF Connect for Mobile | BLE 扫描、广告数据解析、RSSI 图、CSV/Excel 导出、连接、服务和特征解析、读写、通知/指示、Reliable Write、SIG 特征解析、BLE Advertising、GATT Server、配对设备、多连接、Beacon、DFU Profile | 高级扫描过滤、广告包详情、RSSI 趋势、导出、GATT 树、特征详情、MTU、Reliable Write、通知订阅、GATT Server / 虚拟外设、DFU/Beacon/Profile 工具 |
| LightBlue | 扫描任意 BLE 外设、名称/MAC/RSSI、服务/特征浏览、通知、读写、Hex/UTF-8、事件日志、分享日志、虚拟外设、预置 Profile | 轻量可读的扫描列表、特征写入格式选择、事件日志分享、虚拟外设/Profile 模板 |
| SimpleBluetoothLeTerminal | BLE 串口终端，支持不同厂商自定义串口 UUID | BLE UART 不能只作为 GATT 附属页，必须有独立 Profile 匹配、终端和失败转 GATT |

### BLE 原型补齐

| 页面 | 必须出现 |
| --- | --- |
| BLE 扫描高级页 | Name / MAC / RSSI / Service UUID / Manufacturer / Connectable / Bonded / Beacon 过滤 |
| 广告详情页 | Flags、Service UUID、Manufacturer、Raw HEX、RSSI 时间线 |
| GATT 详情页 | Service、Characteristic、Descriptor、Read、Write、Notify、Indicate、Reliable Write、MTU |
| BLE UART 页 | Nordic/NUS、HM-10、自定义 UUID、Profile 阶段、失败转 GATT |
| BLE 工具箱 | GATT Server、Advertiser、Beacon、DFU、Throughput、收藏设备 |

## 2. SPP 调研

| 项目 / 产品 | 已实现能力 | YoWire 必须补齐 |
| --- | --- | --- |
| Serial Bluetooth Terminal / SimpleBluetoothTerminal | 经典蓝牙 SPP，RFCOMM，标准 SPP UUID，面向 Arduino/MCU 的行终端 | 不能只有已连接终端，必须有配对、发现、UUID 选择、RFCOMM 状态 |
| Serial Bluetooth Terminal Google Play | 支持 Classic、BLE、USB 串口，面向串口设备 | SPP 终端要和 UART 体验统一：Text/HEX、换行、日志、后台 |
| Arduino 社区使用方式 | 用手机替代 Arduino IDE Serial Monitor | 必须支持 AT/宏命令、发送历史、自动换行、时间戳、清屏、复制、保存 |

### SPP 原型补齐

| 页面 | 必须出现 |
| --- | --- |
| 设备页 | 已配对 / 附近 Inquiry / 配对状态 / RSSI / 最近连接 |
| UUID 页 | 标准 SPP UUID、自定义 UUID、最近 UUID、Secure/Insecure |
| 终端页 | Text/HEX、CR/LF、Local Echo、Timestamp、宏、历史、周期发送、文件发送 |
| 日志页 | 原始字节、方向、时间、复制、暂停、过滤、TXT/CSV/JSON |
| 后台页 | 保留连接、通知、断线重连、返回确认 |

## 3. WiFi 调研

| 项目 / 产品 | 已实现能力 | YoWire 必须补齐 |

| VREM WiFiAnalyzer | 识别 AP、信道强度图、AP 信号时间图、信道评分、HT/VHT、2.4/5/6GHz、完整/紧凑视图、距离估算、导出、暂停/恢复扫描 | 环境分析不能只列 AP，必须有图表、信道评分、带宽、导出、暂停/恢复 |

| 图表 | 信道图、RSSI 时间图、信道评分、2.4/5/6GHz 切换 |
| LAN 工具 | LAN 扫描、主机详情、mDNS/Bonjour、UPnP、Ping Sweep |
| 诊断工具 | Ping、Trace、DNS、Whois、Port Scan、Routing、SSL/TLS、iPerf/Speed |
| 协议调试 | TCP/UDP Client/Server、HTTP、WebSocket、MQTT、Payload 模板、历史、Traffic Log |

## 4. 星闪 / NearLink 调研

| 来源 | 已知能力 | YoWire 必须补齐 |
| --- | --- | --- |
| Huawei NearLink Kit 发布说明 | NearLink Kit 提供低功耗、高速短距通信，支持连接和数据交互 | 首屏必须先能力检测，不支持时不能显示空白调试页 |
| NearLink Kit 开发文档目录 | 查询是否支持星闪、查询开关状态、发送广播、发起扫描、SSAP 连接及数据传输、使用星闪传输数据、合作设备集合、FAQ | 原型必须有能力检测、广播、扫描、SSAP、DT、合作设备、FAQ/降级 |
| NearLink / SparkLink 技术说明 | SLE 面向低功耗低延迟高可靠，SLB 面向高速高容量；存在安全、低延迟、多连接场景 | UI 必须显示 SLE/SLB、加密状态、连接质量、错误码、拥塞/退避、安全策略 |

### 星闪原型补齐

| 页面 | 必须出现 |
| --- | --- |
| 能力检测 | 是否支持、开关、权限、模拟器、API 可用、SLE/SLB |
| 广播与扫描 | 发送广播、扫描过滤、设备详情、RSSI、发现次数、Raw 数据 |
| SSAP | 服务树、Read、Write、Subscribe、MTU、单 Client 限制、错误码 |
| dataTransfer | Port UUID、连接、加密状态固定条、Text/HEX、周期发送、日志 |
| 安全与恢复 | 未加密/未知阻止策略、拥塞退避、连接失败、权限拒绝、FAQ |
