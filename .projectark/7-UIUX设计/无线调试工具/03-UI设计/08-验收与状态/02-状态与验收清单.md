# 状态与验收清单

> **状态**：v2 全量重构版

---

## 1. 全局状态矩阵

| 状态 | 展示层级 | 用户动作 |
| --- | --- | --- |
| 空态 | 页面主体 | 开始扫描、创建会话、查看说明 |
| 加载 | 行内或区域顶部 | 可取消时提供停止 |
| 权限拒绝 | Banner | 授权或去设置 |
| 能力不可用 | Banner 或占位页 | 查看原因、返回工作台 |
| 连接中 | 行内 Progress | 可取消 |
| 已连接 | 状态条 | 断开、后台保留 |
| 连接失败 | 错误卡 | 重试、查看日志 |
| 后台运行 | 状态条 + 工作台 + 通知 | 进入、停止 |
| 周期发送 | 固定控制条 | 停止 |
| 导出成功 | Toast + 分享入口 | 分享、关闭 |
| 导出失败 | 错误卡或 Sheet 内错误 | 重试、换格式 |

---

## 2. 页面验收

| 项 | 标准 |
| --- | --- |
| 信息架构 | 一级 Tab 只有工作台、蓝牙、WiFi、星闪、更多 |
| 模块设置 | 蓝牙、WiFi、星闪设置都是 NavDestination |
| 日志 | 会话内有日志面板，模块设置可管理日志 |
| 命令 | 命令面板归属模块设置 |
| 导出 | TXT、CSV、JSON 可选 |
| 权限 | 不在启动时一次性请求全部权限 |
| 宽屏 | 840vp 及以上为 A/B/C 三栏 |
| 触控 | 关键按钮命中区域不小于 40vp |
| 安全区 | 输入 Dock 和底部按钮不遮挡系统导航区 |
| 深色模式 | 使用语义 Token |

## 3. 禁止项检查

| 禁止项 | 检查方式 |
| --- | --- |
| 全局日志中心 Tab | 查 L0 Tabs 和路由 |
| 全局命令中心 Tab | 查 L0 Tabs 和路由 |
| 第四 Inspector | 查宽屏布局 |
| dp/sp 单位 | 查 UI 文档和原型 |
| Android Material 规范 | 查视觉和控件说明 |
| 启动全权限弹窗 | 查冷启动流程 |
| 日志只显示文本 | 查 SPP/UART/DT 页面 |
| 未加密状态只靠颜色 | 查星闪 DT |

---

## 4. 实现前评审清单

1. 功能是否出现在覆盖矩阵。
2. 页面是否说明手机、双栏、三栏布局。
3. 权限和失败状态是否有恢复路径。
4. 日志和导出是否保留原始数据。
5. 模块设置是否保持模块自治。
6. 高风险操作是否使用 Dialog。
7. Sheet 是否只承载补充任务。
8. 是否符合 HarmonyOS 安全区和触控尺寸。
