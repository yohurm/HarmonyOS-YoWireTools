## 5. 通过标准

| 标准 | 要求 |
| --- | --- |
| P0 覆盖 | 本矩阵所有行必须有实现页面 |
| 状态覆盖 | 每行至少有空态/加载/失败/恢复之一 |
| 断点覆盖 | 每行必须说明手机、双栏或三栏形态 |
| 日志导出 | 所有会话型任务必须支持 TXT/CSV/JSON |
| 模块自治 | 不新增全局日志中心或全局命令中心 |
