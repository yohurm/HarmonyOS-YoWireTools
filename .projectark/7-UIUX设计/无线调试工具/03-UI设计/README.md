# YoWire 无线调试工具 UI 设计文档

> **状态**：v2 全量重构版  
> **范围**：工作台、蓝牙、WiFi、星闪、更多设置、权限、日志、命令、导出、多设备布局、状态验收  
> **依据**：PRD、架构设计、功能清单、用户交互流程、HarmonyOS 设计指南

---

## 1. 重构结论

旧版 `03-UI设计` 已清理，不再作为实现依据。新版 UI 设计按以下原则重建：

| 原则 | 约束 |
| --- | --- |
| 用户流程优先 | 每个页面必须服务 `发现 -> 选择 -> 配置 -> 连接/执行 -> 观察 -> 恢复 -> 保存/导出 -> 返回` 的调试闭环 |
| 模块自治 | 日志、命令、过滤、设置入口归属到蓝牙、WiFi、星闪模块内，不设置全局日志中心和全局命令中心 |
| HarmonyOS 原生 | 使用 Navigation、Tabs、List、Grid、Sheet、Dialog、Menu、Toast、系统分享、语义色和 vp/fp 尺寸 |
| 多设备一致 | 手机单栈、600-839vp 双栏、840vp 及以上 A/B/C 三分栏；禁止第四 Inspector |
| 状态可恢复 | 权限拒绝、能力不支持、连接中断、后台运行、周期发送、导出失败都必须有明确 UI 状态 |
| 可验收 | 所有 P0 功能必须能在覆盖矩阵中找到页面、入口、控件、状态和断点布局 |

## 4. 不允许回退的设计

| 项 | 结论 |
| --- | --- |
| 一级导航 | 工作台 / 蓝牙 / WiFi / 星闪 / 更多 |
| 全局日志中心 | 不设计独立 Tab，不作为一级入口 |
| 全局命令中心 | 不设计独立 Tab，命令面板归属模块设置 |
| 模块设置 | 使用 NavDestination 页面，不使用临时 Sheet 承载复杂设置 |
| 宽屏结构 | 840vp 及以上使用 A/B/C 三分栏 |
| 状态反馈 | 关键状态使用 Banner、Inline State、Dialog、Sheet 分层承载，Toast 只用于轻量反馈 |
| 尺寸单位 | 使用 vp/fp，不使用 dp/sp |
| 风格 | 不使用 Android Material 或 iOS 样式作为实现规范 |

## 5. 验收入口

实现前必须完成：

1. 在 `08-验收与状态/01-功能流程覆盖矩阵.md` 中找到对应功能行。
2. 确认页面入口、主控件、关键状态、断点布局都已定义。
3. 确认模块文档中的页面契约与覆盖矩阵一致。
4. 确认未新增全局日志中心、全局命令中心、第四 Inspector 或 Android 风格控件。
