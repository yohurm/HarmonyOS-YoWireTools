# 会话、日志、命令与权限模型

> **状态**：v2 全量重构版  
> **目标**：统一后端能力，保持 UI 模块自治

---

## 1. UI 边界

| 能力 | 后端 | UI |
| --- | --- | --- |
| SessionRuntime | 统一 | 模块内展示和控制 |
| SessionLog | 统一 | 模块内日志面板、模块设置会话页 |
| CommandTemplate | 统一存储 | 模块设置中的命令面板 |
| PermissionState | 统一查询 | 按任务时机在模块内引导 |
| Export | 统一导出服务 | 模块日志、模块设置、工作台最近会话触发 |

---

## 2. 会话对象

每个会话卡片必须显示：

| 字段 | 示例 |
| --- | --- |
| 类型 | BLE GATT、SPP、UART、WiFi TCP、MQTT、SSAP、DT |
| 对象 | 设备名、地址、SSID、Host、Port |
| 状态 | 连接中、已连接、后台运行、已断开、失败 |
| 指标 | RSSI、MTU、收发字节、包数、延迟 |
| 最近操作 | Notify、Write、Send、Ping、Subscribe |
| 操作 | 进入、停止、导出、移除记录 |

---

## 3. 日志面板

| 区域 | 内容 |
| --- | --- |
| 顶部摘要 | 会话类型、连接状态、收发计数、时间范围 |
| 工具栏 | 暂停、清空、过滤、复制、导出、更多 |
| 日志列表 | 时间、方向、级别、协议字段、原始数据 |
| 详情 | 选中日志的 HEX、Text、JSON 或协议解析 |
| 空态 | 说明如何产生第一条日志 |

日志必须遵守：

| 规则 | 说明 |
| --- | --- |
| 原始数据保留 | SPP/UART/DT 不只显示文本，必须保留原始字节 |
| 方向明确 | 发送和接收有文本、图标或列区分 |
| 可暂停 | 暂停只影响滚动，不丢数据 |
| 可导出 | TXT、CSV、JSON 三种格式 |
| 可过滤 | 方向、级别、关键字、时间范围 |

---

## 4. 命令面板

命令面板只存在于模块设置或运行时输入区的最近命令调用，不设置全局命令中心。

| 模块 | 命令类型 |
| --- | --- |
| 蓝牙 | GATT Write、SPP 文本/HEX、UART 文本/HEX |
| WiFi | TCP/UDP Payload、HTTP Request、WebSocket Message、MQTT Publish |
| 星闪 | SSAP Write、dataTransfer Payload |

命令卡片字段：

| 字段 | 说明 |
| --- | --- |
| 名称 | 用户自定义 |
| 协议 | 绑定模块和任务类型 |
| Payload | 文本、HEX、JSON 或表单 |
| 参数 | Host、Port、UUID、Characteristic、QoS 等 |
| 风险 | 是否广播、是否未加密、是否周期发送 |
| 动作 | 运行、复制、编辑、删除 |

---

## 5. 权限请求

权限不在启动时一次性请求，按用户任务触发。

| 任务 | 请求时机 | UI |
| --- | --- | --- |
| 蓝牙扫描 | 点击扫描前 | Inline Banner + 授权按钮 |
| 经典 SPP 配对 | 进入配对或连接前 | 引导到系统配对或授权 |
| WiFi 扫描 | 点击刷新 AP 前 | 权限 Banner |
| 星闪能力 | 进入星闪 Tab 后先检测能力，再按需授权 | 能力 Banner + Sheet |
| 后台运行 | 用户选择后台保留连接时 | 后台可见性说明 |
| 导出分享 | 点击导出时 | 格式 Sheet + 系统分享 |

---

## 6. 风险确认

以下操作必须使用 Dialog：

| 操作 | Dialog 内容 |
| --- | --- |
| UDP 广播 | 说明广播范围和可能影响 |
| 未加密星闪发送 | 显示当前加密状态和阻止策略 |
| 删除日志 | 说明删除不可恢复 |
| 周期发送高频 | 显示频率、目标、停止方式 |
| 断开仍有任务运行 | 显示运行任务和后果 |

Dialog 按钮顺序：

| 类型 | 主按钮 | 次按钮 |
| --- | --- | --- |
| 破坏性操作 | 确认删除/确认发送，使用危险色 | 取消 |
| 后台保留 | 保留连接 | 断开 |
| 权限恢复 | 去设置 | 稍后 |
