# 信息架构与用户流程

> **状态**：v2 全量重构版  
> **目标**：用用户任务流重建 YoWire 的页面结构，而不是按技术能力堆菜单

---

## 1. L0 信息架构

| Tab | 用户意图 | 首屏内容 | 不包含 |
| --- | --- | --- | --- |
| 工作台 | 继续最近调试、查看模块状态、快速进入任务 | 模块能力摘要、最近会话、运行中任务、快捷入口 | 全量日志编辑、全局命令网格 |
| 蓝牙 | BLE GATT、经典 SPP、BLE UART、蓝牙实验能力 | 分段任务入口、扫描/配对列表、活跃会话 | WiFi/星闪任务 |
| WiFi | WiFi 环境分析、网络协议调试、LAN/诊断 | 环境/协议/诊断任务入口、当前网络状态 | 蓝牙终端 |
| 星闪 | 能力检测、SSAP Client、dataTransfer | 能力 Banner、扫描入口、会话入口 | 不支持设备上的空白调试页 |
| 更多 | 全局设置、隐私、存储、导出策略、关于 | 全局配置分组 | 模块日志、模块命令、模块连接设置 |

## 2. 全局用户流程

### 2.1 冷启动

```text
启动 App
-> 恢复上次 L0 Tab 和各模块 NavPathStack
-> 刷新模块能力摘要
-> 显示必要的非阻断权限提示
-> 用户选择继续最近会话或进入模块任务
```

设计要求：

| 状态 | UI |
| --- | --- |
| 无权限但未触发任务 | 工作台显示轻量 Banner，不弹阻断 Dialog |
| 有运行中会话 | 工作台顶部显示运行中任务条，可停止或进入 |
| 上次页面不可恢复 | 回到对应模块首页，并显示恢复失败原因 |

### 2.2 模块调试闭环

```text
进入模块
-> 选择任务类型
-> 执行扫描/输入地址/选择协议
-> 配置过滤或连接参数
-> 建立会话
-> 执行读写、订阅、发送、诊断
-> 实时观察日志
-> 异常恢复或断开
-> 导出会话证据
```

每个模块必须在页面内提供：

| 能力 | 位置 |
| --- | --- |
| 扫描/刷新 | 页面主区域顶部或列表工具栏 |
| 过滤 | 工具栏按钮，Sheet 承载 |
| 连接参数 | 连接前 Sheet 或模块设置 |
| 日志 | 会话页 C 区或手机端二级 Tab |
| 命令 | 模块设置中的命令面板，运行时可从输入区调用最近命令 |
| 导出 | 日志区域菜单或模块设置会话页 |

### 2.3 返回与保活

| 场景 | 行为 |
| --- | --- |
| 未连接返回 | 直接返回上一层 |
| 已连接返回 | 显示保留连接确认，提供断开、后台保留、取消 |
| 周期发送中返回 | 强提示周期任务仍运行，默认保持在当前页 |
| 后台保留成功 | 工作台运行中任务条和系统通知同步显示 |

## 3. 深链规则

| 来源 | 目标 | 规则 |
| --- | --- | --- |
| 工作台最近会话 | 模块内具体会话 | 恢复模块 Tab、NavPathStack、会话状态 |
| 系统分享导入 | 对应模块发送/命令 Sheet | 未连接时先进入连接配置 |
| 通知点击 | 运行中会话页 | 直接定位到会话日志区域 |
| 导出完成 | 系统分享面板或导出记录 | 不跳全局日志中心 |

## 5. 断点下的导航形态

| 宽度 | 导航 | 页面结构 |
| --- | --- | --- |
| `<600vp` | 底部 Tab + 单栈 Navigation | 列表、详情、日志分层进入 |
| `600-839vp` | 侧边或底部 Tab + 双栏 | 左列表右详情，弹层居中 |
| `>=840vp` | 侧边 Tab + A/B/C 三栏 | A 模块导航，B 对象列表，C 详情和日志 |

---

## 6. 页面命名规则

页面名必须描述用户任务，避免只描述技术对象。

| 推荐 | 不推荐 |
| --- | --- |
| BLE GATT 调试 | GATT 页面 |
| 经典 SPP 终端 | SPP Detail |
| WiFi 环境分析 | Scan WiFi |
| 网络协议调试 | Socket Page |
| 星闪能力检测 | NearLink Home |
