# HarmonyOS 布局与组件规范

> **状态**：v2 全量重构版  
> **目标**：确保 YoWire UI 完全按 HarmonyOS 原生体验设计

---

## 1. 尺寸与栅格

| 项 | 规范 |
| --- | --- |
| 尺寸单位 | 使用 vp |
| 字体单位 | 使用 fp |
| 基础节奏 | 8vp 栅格 |
| 触控目标 | 最小 40vp，常用按钮推荐 48vp |
| 图标按钮 | 40vp 容器，图标 20-24vp |
| 页面边距 | 手机 16vp，平板 24vp，宽屏 32vp |
| 列间距 | 手机 8-12vp，双栏 16vp，三栏 20-24vp |

---

## 2. 响应式断点

| 宽度 | 栅格 | YoWire 形态 |
| --- | --- | --- |
| `0-599vp` | 4 列 | 手机单栈 |
| `600-839vp` | 8 列 | 双栏，列表和详情并列 |
| `840vp+` | 12 列 | A/B/C 三栏 |

### 2.1 手机单栈

| 区域 | 设计 |
| --- | --- |
| 顶部 | 标题、状态摘要、必要工具按钮 |
| 主体 | 一个主要任务区域 |
| 底部 | L0 Tab 或输入 Dock，避免遮挡系统导航区 |
| 日志 | 二级 Tab 或详情页内折叠区，不抢占主任务 |

### 2.2 双栏

| 区域 | 宽度建议 | 内容 |
| --- | --- | --- |
| 左栏 | 280-340vp | 任务列表、设备列表、AP 列表、会话列表 |
| 右栏 | 剩余 | 详情、终端、图表、日志 |

### 2.3 三栏

| 栏 | 宽度建议 | 内容 |
| --- | --- | --- |
| A | 240-280vp | L0/L1 导航、模块任务 |
| B | 320-420vp | 对象列表、过滤摘要、扫描状态 |
| C | 剩余，最小 480vp | 详情、终端、服务树、图表、日志 |

约束：

| 规则 | 说明 |
| --- | --- |
| B 栏标题 | 不超过 3 个文本动作 |
| C 栏工具栏 | 不超过 6 个直接动作 |
| 更多动作 | 收敛到 Menu 或 Sheet |
| 第四栏 | 禁止 |
| 最大内容宽度 | 超宽屏内容不超过 2220vp，剩余留白或扩展日志密度 |

---

## 3. 安全区

| 场景 | 规则 |
| --- | --- |
| 状态栏 | 顶部标题和 Banner 不进入状态栏不可读区域 |
| 底部导航 | 输入 Dock、发送按钮、周期发送条避开底部系统导航区 |
| 横屏 | 工具栏和 Tab 不被侧边系统手势遮挡 |
| 折叠屏 | 铰链区域不放主按钮、输入框、日志关键列 |
| 悬停态 | 上半屏优先展示图表、日志、详情；下半屏优先承载输入和控制 |

## 4. 原生组件选择

| 需求 | 组件 |
| --- | --- |
| 页面导航 | Navigation、NavDestination |
| 一级模块切换 | Tabs |
| 模块内任务切换 | Segmented control 或 Tabs |
| 设备/AP/会话列表 | List |
| 能力卡片 | Grid |
| 筛选 | Sheet |
| 高风险操作 | Dialog |
| 轻量操作集合 | Menu |
| 短反馈 | Toast |
| 进度 | Progress、Loading、Inline 状态 |
| 分享导出 | 系统分享入口 |
| 图标 | 系统 SymbolGlyph 或项目图标库 |

---

## 5. 弹层规则

| 类型 | 用途 | 禁止 |
| --- | --- | --- |
| Sheet | 过滤、写入参数、UUID、端口、导出格式 | 承载模块设置主页面 |
| Dialog | 删除日志、断开连接、广播发送、未加密发送等高风险确认 | 普通说明和普通筛选 |
| Menu | 工具栏溢出动作 | 承载复杂表单 |
| Toast | 保存成功、复制成功等轻量反馈 | 连接失败、权限拒绝等需恢复场景 |

---

## 6. 视觉规范

| Token | 用途 |
| --- | --- |
| `color.background.primary` | 页面背景 |
| `color.background.surface` | 列表、工具栏、输入区 |
| `color.text.primary` | 标题和主要信息 |
| `color.text.secondary` | 说明、元信息 |
| `color.state.success` | 已连接、已加密、完成 |
| `color.state.warning` | 未加密、权限受限、后台运行 |
| `color.state.danger` | 断开、删除、高风险发送 |
| `color.state.info` | 扫描中、诊断中 |

深色模式必须使用语义 Token 切换，不允许通过整体反色实现。

---

## 7. 可访问性

| 项 | 要求 |
| --- | --- |
| 字体 | 正文不小于 14fp，日志最小 12fp 且可设置密度 |
| 对比度 | 主要文本和关键状态满足可读对比 |
| 状态表达 | 不只用颜色，必须配合文本或图标 |
| 焦点 | 键盘/鼠标可遍历扫描、连接、发送、导出等操作 |
| 长列表 | 支持搜索、过滤、虚拟滚动或分段加载 |
| 图表 | 提供数值摘要和选中点文本 |
