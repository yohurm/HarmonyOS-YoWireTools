# 星闪模块完整页面设计

> **状态**：v2 全量重构版  
> **范围**：能力检测、SSAP Client、dataTransfer、星闪设置

---

## 1. 进入策略

星闪模块必须先展示能力状态，不允许在不支持设备上显示空白扫描页。

| 状态 | 首屏 |
| --- | --- |
| Unsupported | 单栏占位，说明设备不支持星闪 |
| Simulator | 模拟器提示，禁用真实扫描 |
| PermissionDenied | 权限 Banner + 授权入口 |
| Degraded | 可用能力列表 + 受限说明 |
| Ready | 显示 SSAP 和 dataTransfer 入口 |

---

## 2. 能力检测页

| 区域 | 内容 |
| --- | --- |
| 能力 Banner | 当前状态、原因、恢复入口 |
| 检测项 | 设备支持、系统版本、权限、开关、API 可用 |
| 可用任务 | SSAP Client、dataTransfer |
| 降级说明 | 不支持项和替代路径 |

840vp 及以上在 Unsupported 状态仍使用单栏居中说明，不强行三栏。

---

## 3. SSAP Client

### 3.1 用户流程

```text
进入星闪 -> Ready
-> SSAP Client
-> 扫描设备
-> 过滤 OR/AND
-> 选择设备
-> stopScan 后连接
-> 展示 SSAP 服务树
-> Read/Write/Subscribe
-> 观察日志
-> 导出会话
```

### 3.2 页面布局

| 断点 | 布局 |
| --- | --- |
| 手机 | 设备列表 -> 服务树 -> 特征操作 -> 日志 |
| 600-839vp | 左设备列表，右服务树和日志 |
| 840vp+ | A 星闪任务，B 设备列表，C SSAP 树/操作/日志 |

### 3.3 设备列表字段

| 字段 | 要求 |
| --- | --- |
| 名称 | 无名称显示 Unknown |
| 地址 | 支持复制 |
| RSSI | 127 显示无信号 |
| 发现次数 | 显示累计发现 |
| 广播详情 | HEX、Service、Manufacturer |

---

## 4. dataTransfer

### 4.1 用户流程

```text
进入 dataTransfer
-> 选择设备
-> 输入或选择 Port UUID
-> 连接
-> 显示加密状态
-> 文本/HEX 发送
-> 观察日志
-> 未加密按策略阻止或确认
```

### 4.2 页面规格

| 区域 | 内容 |
| --- | --- |
| 连接摘要 | 设备、Port UUID、状态、收发字节 |
| 加密状态条 | 已加密、未加密、未知，必须始终可见 |
| 终端 | Text/HEX、换行、清屏、周期发送 |
| 日志 | 原始字节、方向、时间、错误码 |
| 风险确认 | 未加密发送或未知状态发送 |

加密状态不允许折叠，不允许用颜色单独表示。

---

## 5. 星闪设置

星闪设置是 NavDestination 页面。

| 分组 | 内容 |
| --- | --- |
| 会话与日志 | SSAP、DT 会话、导出、清理 |
| 命令面板 | SSAP Write、DT Payload 模板 |
| 扫描 | 默认扫描时长、过滤逻辑 OR/AND |
| 连接 | 单设备单 Client 限制、MTU 默认值 |
| 安全 | 未加密发送策略、未知状态策略 |

---

## 6. 状态与恢复

| 状态 | UI |
| --- | --- |
| 不支持 | 单栏说明，不显示扫描按钮 |
| 权限拒绝 | Banner + 去设置 |
| 扫描中 | 进度和停止 |
| 连接中 | 禁止重复连接 |
| 拥塞/错误 | 错误卡，保留错误码 |
| 未加密 | 固定安全条 + 风险确认 |
| 未知加密 | 不标记安全，按策略阻止或确认 |
