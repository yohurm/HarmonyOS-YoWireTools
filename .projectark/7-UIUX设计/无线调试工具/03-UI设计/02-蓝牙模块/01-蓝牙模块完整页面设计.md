# 蓝牙模块完整页面设计

> **状态**：v2 全量重构版  
> **范围**：BLE GATT、经典 SPP、BLE UART、蓝牙实验室、蓝牙设置

---

## 1. 模块首页

| 区域 | 内容 |
| --- | --- |
| 顶部 | 蓝牙状态、权限状态、扫描状态、设置入口 |
| 任务切换 | BLE GATT / 经典 SPP / BLE UART / 实验室 |
| 主体 | 当前任务的扫描列表或会话列表 |
| 底部或 C 区 | 选中对象详情、日志、终端 |

## 2. BLE GATT 调试

### 2.1 用户流程

```text
进入蓝牙 -> BLE GATT
-> 检查权限和蓝牙开关
-> 扫描设备
-> 过滤设备
-> 选择设备
-> stopScan 后连接
-> 展示服务树
-> Read/Write/Notify/Indicate
-> 观察日志
-> 导出会话
```

### 2.2 页面布局

| 断点 | 布局 |
| --- | --- |
| 手机 | 扫描列表 -> 设备详情 -> GATT 服务树 -> 日志分层导航 |
| 600-839vp | 左设备列表，右服务树和日志 |
| 840vp+ | A 蓝牙任务，B 设备列表，C 服务树/特征详情/日志 |

### 2.3 设备列表字段

| 字段 | 要求 |
| --- | --- |
| 名称 | 无名称显示 Unknown Device |
| 地址 | 支持复制 |
| RSSI | 数值和强度文本 |
| Service UUID | 可折叠展示 |
| Manufacturer Data | 支持 HEX 预览 |
| 最近连接 | 显示最近时间或收藏标识 |

### 2.4 GATT C 区

| 区域 | 控件 |
| --- | --- |
| 连接摘要 | 设备名、地址、RSSI、MTU、连接状态 |
| 服务树 | List 分组，Service -> Characteristic -> Descriptor |
| 特征操作 | Read、Write、Notify、Indicate |
| 日志 | 方向、时间、UUID、HEX/Text |
| 导出 | TXT、CSV、JSON |

## 3. 经典 SPP 终端

### 3.1 用户流程

```text
进入经典 SPP
-> 查看已配对设备
-> 可切换附近 Inquiry
-> 选择设备
-> 选择标准或自定义 UUID
-> 建立 SPP 会话
-> 文本/HEX 发送
-> 观察原始字节日志
-> 后台保留或断开
```

### 3.2 页面规格

| 区域 | 内容 |
| --- | --- |
| B 栏 | 已配对、附近设备、RSSI、配对状态 |
| C 栏顶部 | 连接状态、UUID、收发字节、后台状态 |
| 终端 | 原始数据、文本视图、HEX 视图 |
| 输入 Dock | 文本/HEX 切换、换行、发送、周期发送 |
| 日志菜单 | 清屏、暂停、复制、导出 |

必须保留原始字节，不允许只显示文本。

## 4. BLE UART

### 4.1 用户流程

```text
进入 BLE UART
-> 扫描 LE 设备
-> 连接前 stopScan
-> 匹配 UART Profile
-> 成功进入终端
-> 失败提供转 GATT 查看服务
-> 发送文本/HEX
-> 观察日志和 MTU
```

### 4.2 页面规格

| 区域 | 内容 |
| --- | --- |
| Profile 状态条 | 扫描、连接、发现服务、匹配 RX/TX、Ready |
| 终端 | 与 SPP 共享 Terminal 组件 |
| 输入 | 文本/HEX、换行、周期发送 |
| 失败恢复 | 显示缺失 Service/Characteristic，并提供进入 GATT |

## 5. 蓝牙实验室

实验室承载高阶或风险能力，默认不干扰 P0 调试。

| 能力 | UI |
| --- | --- |
| 高级扫描参数 | 表单 + 风险说明 |
| MTU/连接参数实验 | 参数 Sheet |
| DFU 边界说明 | 能力卡，不承诺未实现流程 |
| 协议解析预览 | 只读结果卡 |

风险操作必须使用 Dialog。

---

## 6. 蓝牙设置

蓝牙设置是 NavDestination 页面。

| 分组 | 内容 |
| --- | --- |
| 会话与日志 | 会话列表、导出、清理、保留周期 |
| 命令面板 | GATT Write、SPP、UART 命令模板 |
| 扫描 | 默认扫描时长、RSSI 阈值、过滤默认值 |
| 连接 | 自动重连、后台保留、MTU 默认值 |
| 收藏 | 收藏设备和最近 UUID |

---

## 7. 状态与恢复

| 状态 | UI |
| --- | --- |
| 蓝牙关闭 | Banner，引导开启 |
| 权限拒绝 | Banner + 去设置 |
| 扫描中 | 列表顶部进度和停止按钮 |
| 连接中 | 设备行内 Progress，禁止重复连接 |
| 连接失败 | 错误卡，显示错误原因和重试 |
| 后台运行 | 终端顶部状态条 + 系统通知 |
| 周期发送 | 输入 Dock 上方固定控制条 |
