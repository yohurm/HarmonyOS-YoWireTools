# 首页工作台与更多设置

> **状态**：v2 全量重构版

---

## 1. 工作台定位

工作台不是功能大全，也不是日志中心。它只承担三件事：

1. 让用户继续最近或运行中的调试任务。
2. 快速看到蓝牙、WiFi、星闪能力状态。
3. 提供进入模块任务的短路径。

---

## 2. 手机首屏结构

```text
标题栏：YoWire / 全局状态 / 设置入口
模块能力摘要：蓝牙、WiFi、星闪
运行中任务：可进入、停止、查看后台说明
最近会话：按最近时间排列
快捷任务：BLE GATT、SPP、WiFi 环境、TCP Client、星闪检测
底部 Tabs：工作台 / 蓝牙 / WiFi / 星闪 / 更多
```

---

## 3. 宽屏结构

| 栏 | 内容 |
| --- | --- |
| A | L0 导航和全局状态 |
| B | 工作台信息流：运行中、最近会话、快捷任务 |
| C | 选中会话摘要、日志预览、导出入口 |

C 栏只显示选中会话摘要，不变成全局日志编辑器。

---

## 4. 模块能力摘要

| 卡片 | 内容 | 操作 |
| --- | --- | --- |
| 蓝牙 | 开关状态、权限状态、最近设备、活跃连接数 | 进入蓝牙 |
| WiFi | 当前 SSID/IP、扫描权限、网络状态 | 进入 WiFi |
| 星闪 | 能力支持、权限、模拟器/设备状态 | 进入星闪 |

状态文案：

| 状态 | 文案 |
| --- | --- |
| Ready | 可调试 |
| PermissionNeeded | 需要授权 |
| Disabled | 系统能力关闭 |
| Unsupported | 当前设备不支持 |
| Degraded | 能力受限 |

---

## 5. 最近会话

会话卡片信息：

| 字段 | 说明 |
| --- | --- |
| 标题 | 任务类型 + 对象 |
| 副标题 | 地址、Host、SSID、Port 或 UUID |
| 状态 | 已连接、后台运行、已断开、失败 |
| 指标 | 收发字节、日志条数、最近时间 |
| 操作 | 继续、导出、移除 |

点击卡片必须 deep link 到模块内具体页面。

---

## 6. 更多设置

更多 Tab 只包含全局设置：

| 分组 | 内容 |
| --- | --- |
| 外观 | 主题、日志密度、字体大小 |
| 存储 | 日志保存位置、保留周期、导出默认格式 |
| 隐私 | 本地数据说明、清除历史、分享前脱敏 |
| 后台 | 后台可见性说明、通知入口 |
| 关于 | 版本、开源许可、诊断信息 |

不允许放入：

| 项 | 原因 |
| --- | --- |
| 蓝牙日志列表 | 应归属蓝牙模块 |
| WiFi 命令模板 | 应归属 WiFi 设置 |
| 星闪连接策略 | 应归属星闪设置 |

---

## 7. 工作台状态

| 状态 | UI |
| --- | --- |
| 首次使用 | 显示模块能力摘要和推荐任务，不弹全权限窗口 |
| 无最近会话 | 显示三个模块快捷任务 |
| 有后台任务 | 顶部运行中任务条固定显示 |
| 权限受限 | 对应模块卡片显示可恢复入口 |
| 存储不足 | 全局 Banner，引导到存储设置 |
