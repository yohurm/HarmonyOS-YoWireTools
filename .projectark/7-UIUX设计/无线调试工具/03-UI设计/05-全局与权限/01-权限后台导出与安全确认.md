# 权限、后台、导出与安全确认

> **状态**：v2 全量重构版

---

## 1. 权限原则

| 原则 | 说明 |
| --- | --- |
| 按任务请求 | 用户触发扫描、连接、导出、后台保留时再请求 |
| 不阻断启动 | 冷启动不弹全部权限窗口 |
| 可恢复 | 权限拒绝必须给出下一步 |
| 模块内说明 | 权限说明出现在用户正在执行的任务上下文中 |

---

## 2. 权限 UI

| 类型 | UI |
| --- | --- |
| 可直接请求 | Inline Banner + 授权按钮 |
| 需要系统设置 | Banner + 去设置 |
| 权限受限但可继续 | Warning Banner + 降级说明 |
| 永久拒绝 | 说明影响范围，提供设置入口 |

---

## 3. 后台运行

触发场景：

| 场景 | UI |
| --- | --- |
| 已连接返回 | 保留连接确认 |
| 周期发送中离开 | 高风险提示 |
| 后台保留成功 | 工作台运行中任务条 + 系统通知 |
| 后台任务异常 | 通知和模块内错误卡同步 |

后台状态必须在工作台、模块页面、系统通知三处一致。

---

## 4. 导出

导出入口：

| 入口 | 范围 |
| --- | --- |
| 日志面板菜单 | 当前会话 |
| 模块设置会话页 | 当前模块会话 |
| 工作台最近会话 | 选中会话摘要 |

导出 Sheet：

| 字段 | 说明 |
| --- | --- |
| 格式 | TXT、CSV、JSON |
| 时间范围 | 全部、最近 10 分钟、自定义 |
| 内容 | 原始数据、解析字段、状态事件 |
| 脱敏 | 地址、SSID、Host 可选脱敏 |
| 动作 | 导出、分享、取消 |

---

## 5. 安全确认

| 操作 | 确认级别 |
| --- | --- |
| 清空当前屏幕日志 | Sheet 或二次确认按钮 |
| 删除持久日志 | Dialog |
| UDP 广播 | Dialog |
| 未加密星闪发送 | Dialog |
| 高频周期发送 | Dialog |
| 断开后台任务 | Dialog |

Dialog 必须包含：对象、动作、风险、后果、确认按钮、取消按钮。
