# 多设备响应式布局完整规范

> **状态**：v2 全量重构版

---

## 1. 手机 `<600vp`

| 页面 | 结构 |
| --- | --- |
| 工作台 | 信息流 + 底部 Tabs |
| 模块页 | 任务切换 + 单列表或单详情 |
| 会话页 | 详情、终端、日志通过页面内 Tabs 或下钻切换 |
| 设置页 | NavDestination 单页表单 |
| Sheet | 底部上拉，避开键盘和导航区 |

手机端优先保持任务连续，不在同屏塞入过多面板。

---

## 2. 平板 `600-839vp`

| 页面 | 结构 |
| --- | --- |
| 工作台 | 左信息流，右选中会话摘要 |
| 扫描类 | 左列表，右详情 |
| 终端类 | 左会话列表，右终端和日志 |
| 图表类 | 左 AP 列表，右图表和详情 |
| Sheet | 居中或底部大 Sheet，最大宽度约 560vp |

---

## 3. 宽屏 `840vp+`

统一 A/B/C：

| 栏 | 内容 |
| --- | --- |
| A | L0/L1 导航、模块任务 |
| B | 当前任务对象列表 |
| C | 详情、终端、服务树、日志、图表 |

模块映射：

| 模块 | A | B | C |
| --- | --- | --- | --- |
| 蓝牙 GATT | 蓝牙任务 | BLE 设备 | GATT 树 + 日志 |
| 蓝牙 SPP | 蓝牙任务 | 配对/附近设备 | 终端 + 日志 |
| WiFi 环境 | WiFi 任务 | AP 列表 | AP 详情 + 图表 |
| WiFi 协议 | WiFi 任务 | 协议会话 | 终端/响应 + Traffic Log |
| 星闪 SSAP | 星闪任务 | 星闪设备 | SSAP 树 + 日志 |
| 星闪 DT | 星闪任务 | 设备/端口 | 终端 + 加密状态 + 日志 |

---

## 4. 折叠屏

| 场景 | 规则 |
| --- | --- |
| 展开 | 按宽度进入双栏或三栏 |
| 半折叠 | 上半屏展示日志、图表、详情，下半屏输入和控制 |
| 铰链 | 不放置主按钮、输入框、状态条关键内容 |
| 状态接续 | 折叠/展开不丢连接、输入草稿、滚动位置 |

---

## 5. 键鼠与 PC

| 项 | 规则 |
| --- | --- |
| 焦点顺序 | 导航 -> 列表 -> 详情 -> 输入 -> 日志 |
| 快捷键 | 只作为增强，不作为唯一入口 |
| Hover | 可显示工具提示，但核心动作必须可点击 |
| 滚轮 | 长日志和列表独立滚动 |
