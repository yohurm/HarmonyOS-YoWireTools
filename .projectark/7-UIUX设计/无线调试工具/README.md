1. **模块自治**：蓝牙 / WiFi / 星闪 各自 ⚙；**无**全局日志中心、命令中心 Tab  
2. **后端统一**：SessionLog / Command 跨模块复用（PRD 02）  
3. **HarmonyOS 规范**：≥600 Split · ≥840 A/B/C · 禁止第四 Inspector  
4. **竞品对齐能力、布局不对齐**：nRF / WiFiAnalyzer / PacketSender 作证据，宽屏跟 WSL

## 5. 关键 IA 决策速查

| 决策 | 结论 |
| --- | --- |
| L0 Tabs | 工作台 / 蓝牙 / WiFi / 星闪 / 更多 |
| 全局日志中心 | **取消** |
| 全局命令面板 | **取消** → 各模块 ⚙·命令与面板 |
| 模块 ⚙ | NavDestination；含会话与日志 + 命令 |
| 宽屏 | ≥840 A/B/C；B 标题 ≤3；C 工具栏 ≤6 |
| Sheet ≥600vp | 居中 480×560 |
| 星闪不可用 | 单栏占位，不空白扫描（NL-01 P0） |
