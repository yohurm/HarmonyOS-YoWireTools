# 命令面板

目标名 `/command/list`。来源：列表加详情的窄屏简化；不发明命令编号。

标题「命令」。`List` 行 56vp：主行命令名 16，次行参数摘要或「无参数」14。点行选中，背景 `interactive_select`。再次点击不 push，除非 ViewModel 给出了可打开的终端路由。

宽屏：左列表 320vp，右栏只读参数，标签/值沿链路详情。窄屏参数只在次行。

命令清单来自 ViewModel。没有条目时不画示例命令。

## 状态

| 态 | 表现 |
| --- | --- |
| 默认 | 一行选中 |
| 按下 | 未选中行按下为 `interactive_pressed`，松手变选中 |
| 禁用 | 不可执行的行 `font_fourth`，点击只选中不提交 |
| 空 | 「没有命令」 |
| 错误 | 顶栏下 `warning` |
| 加载 | 中部进度 |
| 无权限 | 若命令依赖某个无线权限，该行次行「未授权」，整页不换墙 |
