# SSAP

目标名 `/nearlink/ssap-client`。来源：GATT 详情的服务树；度量卡最多三张（RSSI，以及 ViewModel 提供的另外两项）。服务行 56vp，组头为服务标识。行点击进入特征页：读、写、通知的按钮规则与 GATT 属性页相同，文案保持「读取」「写入」「通知」。

未连接时不画空树。居中标题「未连接」，主按钮「连接」。连接不收集口令时不打开半模态，按钮直接提交 ViewModel 的连接动作。

## 状态

| 态 | 表现 |
| --- | --- |
| 默认 | 已连接，树可见 |
| 按下 | 行按下 |
| 禁用 | 连接中按钮 disabled |
| 空 | 已连接但无服务：「没有服务」 |
| 错误 | `warning` 短句在树上方 |
| 加载 | 「正在连接」+ `LoadingProgress`，不闪空树 |
| 无权限 | 权限墙 |
