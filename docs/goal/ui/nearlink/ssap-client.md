# SSAP 客户端

> 壳、Token、权限墙和深浅色以 [应用壳](../app-shell/README.md) 为准。下文保留 Phase-C 行为细则。冲突时应用壳优先。页面只读页面状态，不调用 Kit。

## 布局

本屏层级见 `YoNavDestinationKind`，结构见下方组件树。 窄屏单列。窗口宽度不小于 600vp 且本屏同时有列表和详情时，用 `YoSplitScaffold`： 普通列表 4:6，终端 6:4，每栏至少 280vp。 页边距 `YoResponsive.pageHorizontal`，分区间距 `YoSpace.XL`（16vp）。 字号 `YoTypeStyle`，地址和 HEX 用 `MONO_S`。 原 Phase-C 若在下文另写了断点或底栏，与 [导航](../app-shell/navigation.md) 冲突时以导航为准。

## ArkUI 组件树

```text
Navigation
└── NavDestination
    └── YoPageShell
        └── Column
            ├── Row
            │   ├── Text                    // 名称
            │   └── YoStatusPill
            ├── Text                        // 地址或 BSSID，MONO_S
            ├── List
            │   └── ListItem
            │       └── Row
            │           ├── Text
            │           └── Text
            └── Row
                └── YoActionButton
YoSplitScaffold                             // ≥600vp：左列表右本页
```

`ListItem` 设置 `accessibilityGroup(true)`，朗读文本包含胶囊文案。胶囊组件自身不发声。过滤和配对说明用 `bindSheet`。破坏性确认用 `AlertDialog`。不使用 `HdsListItem`。

## 状态矩阵

| 态 | 本屏 |
| --- | --- |
| 默认 | 已连接且服务已发现。读、写、通知按属性能力分开（NL-063 至 NL-070）。同一远端只建一次客户端（NL-059）。 |
| 按下 | 每个操作松手后入队一次。树节点按下只选中。 |
| 禁用 | 未连接时发现与读写禁用（NL-062）。属性不允许的操作禁用（NL-064、NL-066）。 |
| 空 | 未发现：`YoEmpty`。未读：属性区空文案。二者都不是错误 |
| 错误 | 连接失败原因可见（NL-076）。非法 HEX 不发送（NL-067）。MTU 失败不混用蓝牙码（NL-114）。 |
| 加载 | 连接、发现、读、写、MTU 各自按钮加载，不把整页换成 `YoLoading` 而丢掉日志 |
| 无权限 | 未授权不建立客户端、不发现服务。NL-059 的「同一远端只建一次」只在已授权且连接流程之内。 |

按下只改变控件外观。松手后才把意图交给页面状态。禁用控件不进入按下。错误行若仍写着未授权，归到无权限，不另做一套权限样式。组件树是该页类型的上限：行为细则没有分段就不渲染 `YoSegmentButton`，没有过滤输入就不渲染 `TextInput`。缺口墙的写法见 [权限墙与缺口墙](../app-shell/permission-gap-wall.md)。

## 行为细则


一台远端地址一份客户端会话：连接、服务树、读写、通知、MTU。端口数传不是这一页。

架构：`docs/goal/architecture/nearlink/NL-059.md` 至 `NL-076.md`，以及 `NL-105.md`、`NL-106.md`、`NL-114.md`。

## 导航

| 从 | 到 | 方式 | 返回 |
| --- | --- | --- | --- |
| 扫描详情「SSAP」 | 会话 `OBJECT` | 压栈。已有该地址的 Client 则复用，不建第二个（NL-059） | 返回详情。断开不清除日志 |
| 根页若已有会话 | 会话列表再进对象页 | 窄屏压栈；大于等于 600vp 时列表与会话 4:6 | 返回 |
| 属性行 | 读写区，仍在会话内 | 窄屏推入属性段；宽屏右栏 | 返回服务树 |
| 重连 | 同一会话 | 按钮 | 不新建页面 |
| MTU 超过提示 | 系统对话框：取消或切片 | 模态 | 未选择不发送 |

会话顶栏地址使用这次扫描得到的地址。旧收藏地址不同时，顶栏显示「旧地址可能已失效」（NL-106）。

## 信息密度

| 留在屏上 | 放进属性区或日志详情 |
| --- | --- |
| 连接胶囊、地址、已等待时间 | 属性值全文 HEX，以及能解码时的 UTF-8 |
| 协商 MTU，或「尚未协商」 | 写类型、请求值与回调值 |
| 服务 UUID 一行，属性 UUID + operation 摘要 | `reasonMsg` 只在日志详情（NL-076） |
| 通知：未启用 / 需重新启用 | 通知记录进会话日志，屏上只留最近一条摘要 |
| 失败错误码 | 不把 `1009700099` 当成未连接的唯一解释 |

服务树默认折叠到服务级。点开才看属性。值摘要最多一行，超出进属性区。

## 布局

窄屏自上而下：状态条、主操作、服务树。宽屏左树右属性。树滚动与属性滚动分开。写输入框固定在属性区底部，避开导航条。

标题 `OBJECT`，`showBack = true`。不使用终端种类；终端留给端口。

## 组件

| 区域 | 组件 |
| --- | --- |
| 页壳 | `YoPageShell` |
| 连接中、已连接、已断开、通知 | `YoStatusPill` |
| 连接、断开、发现服务、读、写、通知、请求 MTU、重连 | `YoActionButton` |
| 写类型 | `YoSegmentButton`，仅当两种写都支持时出现两项 |
| 无服务 | `YoEmpty` |
| 失败 | `YoError` |
| 未连接时的发现、读、写、MTU | 按钮禁用 + `disabledReason`，不用整页错误代替 |

## 控件六态

| 控件 | 默认 | 按下 | 禁用 | 空 | 错误 | 加载 |
| --- | --- | --- | --- | --- | --- | --- |
| 连接 | 未连接时「连接」 | 按下 | 不支持或开关关闭 | 无服务树不是连接按钮的空态 | 失败后按钮恢复，错误在状态条下 | 连接中按钮 `loading`，胶囊「连接中」，并显示地址与已等待时间（NL-060） |
| 发现服务 | 已连接可点 | 按下 | 已断开，原因「未连接」（NL-062） | 发现完成但没有服务：`YoEmpty`「没有服务」 | 发现失败带码 | 发现过程按钮 `loading`，树区不先显示空成功 |
| 读 | 属性含可读 | 按下 | 不含 `READABLE`，原因「不支持读」（NL-064） | 尚未读：属性区「尚未读取」，不是空 HEX 成功 | 读失败带码 | 该按钮 `loading` |
| 写 | 能力匹配时可点 | 按下 | 写类型与 operation 不符（NL-066）；HEX 不合法时按钮可点但提交被拦住 | 输入空时不发送 | HEX 不合法的校验句（NL-067）；超过 MTU 的对话框（NL-074） | 有响应写等待时 `loading`；无响应写不进入「等待响应超时」（NL-065） |
| 通知 | 五条件满足时可开 | 按下 | 无 `NOTIFY` 或未发现服务 | 未启用时说明「通知未启用」，静默不是链路故障（NL-069） | 启用失败带码 | 启用请求 `loading` |
| MTU | 已连接。22、256、512 都可请求（NL-071） | 按下 | 未连接，原因「需先连接」（NL-073）；21 或 513 不调用接口（NL-072） | 未请求时显示「尚未协商」 | `1009700099` 显示为星闪错误码，不写蓝牙 `2900099`（NL-114） | 请求后等待 `mtuChange` 时 `loading`，日志同时有请求值与回调值 |
| 重连 | 已断开时「重连」 | 按下 | 已连接 | 无 | 同连接失败 | 再次进入连接中（NL-075、NL-105） |

## 页面状态

| 状态 | 屏上 |
| --- | --- |
| 默认，未连接 | 胶囊「未连接」。发现、读、写、MTU 禁用。可连接、可看旧日志 |
| 连接中 | 地址与已等待时间。不显示已连接 |
| 已连接 | 胶囊「已连接」。可发现服务 |
| 服务树 | 每个服务的 UUID；属性的 UUID、operation 位、一行值摘要（NL-061） |
| 读结果 | HEX；能按 UTF-8 解码时附文本。日志为入方向（NL-063） |
| 写 | 两种都支持时分段为 `WRITE` 与 `WRITE_NO_RESPONSE`，日志记下写类型（NL-065） |
| 通知打开 | 五条件同时成立才显示通知记录：属性含 `NOTIFY`，服务端描述符含客户端属性配置，已连接，已完成 `getServices`，已 `setPropertyNotification(true)` 且已订阅 `propertyChange`（NL-068）。缺一则不显示「通知已生效」 |
| 断线后重连 | 胶囊写「通知需重新启用」。在用户再次启用前不出现「通知仍有效」（NL-070） |
| 超过 MTU | 对话框给出当前 MTU。取消或按 MTU 切片；未选不发送（NL-074） |
| 断开 | 旧日志仍在。重连调用已有 Client 的 `connect`（NL-075） |
| 连接失败 | 失败胶囊 + 错误码。`CONNECTION_FAILURE` 同样显示失败。26.0.0 及以上的 `reasonMsg` 只在日志详情（NL-076） |
| 重连文案 | 没有「系统将自动重连」。新的连接中由这次点击产生（NL-105） |
| 空 | 未发现：`YoEmpty`。未读：属性区空文案。二者都不是错误 |
| 加载 | 连接、发现、读、写、MTU 各自按钮加载，不把整页换成 `YoLoading` 而丢掉日志 |

同一地址第二次进入不增加创建次数（NL-059）。创建次数出现在会话日志，不在标题上做成成功徽章。
