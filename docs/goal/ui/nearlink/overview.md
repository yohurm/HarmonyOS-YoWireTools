# 星闪概览

现路由 `/nearlink/overview`，槽位「星闪」。`main` 上页面是空 `Column`。本屏是目标布局。模式同蓝牙概览：状态胶囊 + 两行入口。不在进入时申请权限。

## 布局

标题「星闪」。胶囊四选一：可用、已关闭、不支持、未读取。次行入口：「扫描」「数传」。扫描 push `/nearlink/scan`，数传 push `/nearlink/data-transfer`。SSAP 从扫描行进入，不放在概览，避免三个入口把概览变成菜单墙。

不支持时不渲染入口，改为缺口墙，标题「此设备没有星闪」，无按钮。已关闭：胶囊警告色，入口行禁用，文字按钮「打开系统设置」。应用不提供「打开星闪」主按钮。

## 组件树

```text
NavDestination 「星闪」
  Column padding 16 gap 16
    Row
      胶囊 「可用」|「已关闭」|「不支持」|「未读取」
      Button TEXTUAL  仅已关闭：「打开系统设置」
    SubHeader 「入口」
    List
      ListItem 64 「扫描」 次行「按名称或厂商数据」
      ListItem 64 「数传」 次行「端口收发」
```

## 状态

| 态 | 界面 |
| --- | --- |
| 默认 | 胶囊「可用」。两行可点 |
| 按下 | 行按压色 |
| 禁用 | 已关闭：行 text.disabled，不 push |
| 空 | 无设备列表，不出现「还没有设备」 |
| 错 | 胶囊「未读取」，其下 Body_M status.error 为消息。入口不渲染 |
| 加载 | LoadingProgress +「正在读取」。入口不渲染 |
| 无权限 | 概览不申请权限，不显示权限墙。无权限只出现在扫描页 |

# 星闪总览

路由 `/nearlink/overview` 已在 `main`。结构与蓝牙总览相同，文案换成星闪，避免两套壳。来源：蓝牙总览所用的 E6 分组行。

状态行「星闪」。两行 64vp：「扫描」「已连接设备」。扫描 `push` 目标名 `/nearlink/scan`。第二行在没有会话时次行「没有设备」，点击不跳。有会话时 `push` SSAP 目标名。

不放星闪宣传插画。

## 状态

| 态 | 表现 |
| --- | --- |
| 默认 | 胶囊「已开启」，扫描行可点 |
| 按下 | 行按下 |
| 禁用 | 关闭时两行不 push，箭头 `icon_fourth` |
| 空 | 第二行次行「没有设备」 |
| 错误 | 标题下 `warning` 一行 |
| 加载 | 胶囊为进度 +「正在读取」 |
| 无权限 | 权限墙 |
