# 星闪扫描

目标路由 `/nearlink/scan`。模式：过滤后扫描 + 扫描列表。过滤项以 ViewModel 能填的为准：名称、厂商 ID。没有控件对应「猜出来的」过滤字段。

## 布局

与 BLE 扫描相同的头和 64vp 行。次行是地址和 RSSI。随机地址在次行末尾加中性胶囊「随机」。行点击 push SSAP。右侧不放连接按钮，避免和行点击两套进入方式；连接发生在 SSAP 页。

标题栏文字按钮「过滤」。sheet：名称、厂商 ID 两个 `TextInput`，主按钮「用此过滤重新扫描」，空过滤说明同 BLE。

图示区仅在没有行时出现。

## 组件树

```text
NavDestination 「扫描」
  Button TEXTUAL 「过滤」
  Column
    Text Title_M + Text Body_M + Button TEXTUAL 「开始搜索」|「重新搜索」|「停止」
    List
      ListItem 64
        Text Body_L 名称或「未命名」
        Row
          Text Body_S 地址
          Text Body_S RSSI
          胶囊 「随机」  可选
bindSheet 同 BLE 过滤，字段换成名称与厂商 ID
```

## 状态

| 态 | 界面 |
| --- | --- |
| 默认 | 「搜索成功」，行可点，随机地址带胶囊 |
| 按下 | 行按压色。过滤按钮按下态 |
| 禁用 | 开关关闭：缺口结构「星闪未打开」+「打开系统设置」。无列表 |
| 空 | 「尚未搜索」+ 图示 +「开始搜索」 |
| 错 | 「搜索失败」+ 消息。不显示成功雷达 |
| 加载 | 「正在搜索」+ LoadingProgress +「停止」 |
| 无权限 | 权限墙「需要星闪权限」。这是首次扫描才出现的墙，不是概览 |

## 对照

采用蓝牙扫描的结果头、FastBle 的过滤顺序、WLAN 行的主次文本。不采用 wifi 密码框、场景 Tab、控制台、家居海报、体温数据卡。
目标名 `/nearlink/scan`。来源：与 BLE 扫描同一张 E3 卡片和 H2 状态标题。不复制心率图。

行与 M12、BLE 扫描同一张卡片：主行名称，次行地址与 RSSI，`tnum`。底部一颗「开始搜索 / 停止 / 重新搜索」。地址被 ViewModel 标为随机时，次行末尾中性胶囊「随机」（`font_secondary` 字，`comp_background_gray` 底）。行点击 `push` SSAP。右侧不放连接按钮，连接发生在 SSAP 页，避免和 BLE 行内按钮两套进入方式叠在星闪上。

头与 BLE 相同：标题、辅文、文字按钮「开始搜索 / 停止 / 重新搜索」。

## 状态

| 态 | 表现 |
| --- | --- |
| 默认 | 有行，可点进 SSAP |
| 按下 | 行按下 |
