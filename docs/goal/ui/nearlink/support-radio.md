# 支持与开关

> 壳、Token、权限墙和深浅色以 [应用壳](../app-shell/README.md) 为准。下文保留 Phase-C 行为细则。冲突时应用壳优先。页面只读页面状态，不调用 Kit。

## 布局

本屏层级见 `YoNavDestinationKind`，结构见下方组件树。 窄屏单列。窗口宽度不小于 600vp 且本屏同时有列表和详情时，用 `YoSplitScaffold`： 普通列表 4:6，终端 6:4，每栏至少 280vp。 页边距 `YoResponsive.pageHorizontal`，分区间距 `YoSpace.XL`（16vp）。 字号 `YoTypeStyle`，地址和 HEX 用 `MONO_S`。 原 Phase-C 若在下文另写了断点或底栏，与 [导航](../app-shell/navigation.md) 冲突时以导航为准。

## ArkUI 组件树

```text
Navigation
└── NavDestination
    └── YoPageShell                         // HdsNavigation
        └── Column
            ├── YoImmersiveSurface          // 仅概览状态卡
            │   └── Row
            │       ├── Text
            │       └── YoStatusPill
            ├── GridRow
            │   └── GridCol
            │       └── YoModeEntryCard     // 内含 Text 与胶囊
            └── YoContentState              // CONTENT / LOADING / EMPTY / ERROR / PERMISSION
                ├── YoLoading               // LoadingProgress + Text
                ├── YoEmpty
                ├── YoError
                └── YoPermissionDenied      // Column + Text + Button
```

`ListItem` 设置 `accessibilityGroup(true)`，朗读文本包含胶囊文案。胶囊组件自身不发声。过滤和配对说明用 `bindSheet`。破坏性确认用 `AlertDialog`。不使用 `HdsListItem`。

## 状态矩阵

| 态 | 本屏 |
| --- | --- |
| 默认 | 支持为真，开关已打开 |
| 按下 | 入口卡用系统点击反馈。胶囊不可点。松手才进入子页。 |
| 禁用 | 不支持、模拟器、正在开关或开关关闭时，扫描与连接入口 disabled，原因写在卡上（NL-002、NL-004、NL-006、NL-007）。 |
| 空 | 根页不用空列表表示不支持或未扫描。查询前不显示空胶囊冒充结果。 |
| 错误 | 801、低版本、读取本机名失败用 YoError，并带错误码（NL-003）。不把 801 画成开关关闭。 |
| 加载 | 进入模块，支持与 `getState` 尚未返回 |
| 无权限 | 只进入星闪根页不弹授权（NL-013）。用户拒绝后再扫描，扫描页才是权限墙（NL-015、NL-016）。权限名只有 `ACCESS_NEARLINK`（NL-017）。 |

按下只改变控件外观。松手后才把意图交给页面状态。禁用控件不进入按下。错误行若仍写着未授权，归到无权限，不另做一套权限样式。组件树是该页类型的上限：行为细则没有分段就不渲染 `YoSegmentButton`，没有过滤输入就不渲染 `TextInput`。缺口墙的写法见 [权限墙与缺口墙](../app-shell/permission-gap-wall.md)。

## 行为细则


根页顶部的能力条，加上从这里进入的合作设备集缺口页。模式入口的卡片只显示能否进入，扫描和连接的过程在各自屏幕。

架构：`docs/goal/architecture/nearlink/NL-001.md` 到 `NL-018.md`，以及 `NL-111.md`、`NL-112.md`、`NL-115.md`。清单分组见 `docs/goal/checklist/nearlink.md` 的「设备与开关」「权限」「与蓝牙边界」。

## 导航

| 从 | 到 | 方式 | 返回 |
| --- | --- | --- | --- |
| 应用底栏或侧栏的星闪 | 本页，`ROOT_TAB` | Tab | 切到其他 Tab 即离开模块 |
| 支持条「本机」 | 本机名称与版本说明，仍在本页展开 | 页内区块 | 收起 |
| 支持条「合作设备集」 | 缺口页，`MODULE` | 压栈 | 返回根页 |
| 入口卡 | 扫描、广播、客户端、服务端、端口、配对、日志 | 压栈到对应 `MODULE` 或 `OBJECT` | 各屏标题栏返回 |
| 开关关闭时的说明 | 系统设置路径文案，页内 | 不离开应用去伪装打开开关 | 无 |

进入本页不申请 `ACCESS_NEARLINK`。授权发生在用户点击扫描或连接之后（NL-013）。离开模块后不再接收 `stateChange`（NL-009）。

## 信息密度

屏上留三枚胶囊和一行本机摘要：

| 留在屏上 | 放进详情或说明 |
| --- | --- |
| 支持：支持 / 不支持 / 版本不可用 / 需要真机 | 801 与「不是开关关闭」的对照句，放在错误行 |
| 开关：已打开 / 已关闭 / 正在打开 / 正在关闭 | 两条设置路径的全文 |
| 本机名，最多 30 字；读失败时显示 `1009700003` | 权限用途说明只出现在系统授权框，不在根页再贴一段成功声明 |
| 入口卡标题 + 一枚状态 + 一行原因 | 合作设备集的缺口全文在独立页 |

蓝牙已打开不改变星闪胶囊（NL-111）。星闪关闭时胶囊写「星闪已关闭」，不写「蓝牙可用」。

## 布局

支持条在 4 列里纵向排列。8 列和 12 列时三枚胶囊横排，本机名跟在后面，多余宽度留白，不拉大字号。入口卡在窄屏单列，宽屏两列延伸。合作设备集页是一页说明，内容宽度跟随 `YoPageShell`，不另做插画。

标题栏场景 `LIST_CONTENT`。本页 `scrollable` 为真，底栏避让由壳负责。

## 组件

| 区域 | 组件 |
| --- | --- |
| 页壳 | `YoPageShell`，`destinationKind = ROOT_TAB` |
| 支持、开关、缺口 | `YoStatusPill` |
| 模式入口 | `YoModeEntryCard` |
| 首屏查询 | `YoContentState` + `YoLoading` |
| 不支持、801、模拟器、读名称失败 | `YoError`，放在支持条下方，不替换成空列表 |
| 去设置说明 | 页面内正文。主按钮不叫「打开星闪」 |
| 合作设备集 | 独立 `YoPageShell`，`showBack = true`，正文 + 警告胶囊 |

没有写开关的控件（NL-012）。界面不调用任何打开星闪的接口。只有系统设置里打开之后，`stateChange` 把胶囊改成已打开。

## 控件六态

| 控件 | 默认 | 按下 | 禁用 | 空 | 错误 | 加载 |
| --- | --- | --- | --- | --- | --- | --- |
| 支持胶囊 | 查询完成后显示「当前设备支持星闪」，`success` | 胶囊不可点 | 不支持时改文案，不是把胶囊禁用成空白 | 查询前不显示空胶囊冒充结果 | 801、模拟器、低版本走 `YoError`，胶囊为 `error` 或 `warning` | 首次查询时整区 `YoLoading`，文案「正在查询星闪支持」 |
| 开关胶囊 | `STATE_ON` 显示「星闪已打开」，`success` | 不可点 | `STATE_OFF` 显示「星闪已关闭」，`neutral` | 无「空开关」 | 不把 801 画成关闭 | `TURNING_ON` / `TURNING_OFF` 显示「正在打开」「正在关闭」，`info` |
| 扫描入口卡 | 支持且开关已打开时可点 | 系统点击反馈 | 不支持、模拟器、正在开关、开关关闭时 `disabled`，原因写在卡上 | 卡始终在，不用空卡代替禁用 | 卡不吞掉错误码；错误留在支持条 | 支持查询未完成时卡禁用，原因「正在查询」 |
| 广播、连接类入口卡 | 同上，连接类在开关关闭时禁用 | 同上 | 不支持时全部禁用（NL-002） | 同上 | 同上 | 同上 |
| 本机名 | 已打开且已授权时显示 `getLocalName()` | 行可展开说明 | 开关关闭时不显示空白名 | 名称尚未读到时显示「尚未读取」，不是空字符串成功 | `1009700003` 用 `YoError` 的 `nativeCode` | 读取中该行用按钮式加载不可用；行旁小进度，不挡住胶囊 |
| 合作设备集入口 | 中性胶囊「查看能力说明」 | 系统点击反馈 | 不因 CDSM 不可用而禁用扫描入口 | 无空列表冒充「没有合作设备」 | `1009700050` 留在缺口页，不记成扫描失败 | 无独立加载成功态 |

## 页面状态

| 状态 | 触发 | 屏上 | 可操作 | 不可操作 |
| --- | --- | --- | --- | --- |
| 默认 | 支持为真，开关已打开 | 两枚成功胶囊，入口可点，本机名可见 | 进入各模式 | 无打开开关按钮 |
| 加载 | 进入模块，支持与 `getState` 尚未返回 | `YoLoading` | 无 | 全部入口 |
| 不支持 | `isNearLinkSupported()` 为 false（NL-002） | 「当前设备不支持星闪」 | 阅读说明 | 扫描、广播、连接 |
| 版本不可用 | 低于 6.1.0(23)（NL-001、NL-003） | 「当前系统版本不提供该能力」，起始版本 6.1.0(23)。若调用得到 801，错误码与这句话在一起 | 阅读 | 不把界面画成开关关闭 |
| 需要真机 | 模拟器（NL-004） | 「需要真机」 | 阅读 | 不显示空的扫描列表 |
| 已关闭 | `STATE_OFF`（NL-006、NL-012） | 关闭胶囊 + 设置路径 | 阅读路径 | 扫描不启动 |
| 正在打开或关闭 | `STATE_TURNING_ON` 或 `STATE_TURNING_OFF`（NL-007） | 过渡文案 | 等待 | 扫描入口 |
| 开关变化 | 已订阅 `stateChange`（NL-008） | 胶囊与最新回调一致 | 继续使用 | 无第二套开关 |
| 未授权停留 | 只进入、不扫描（NL-013） | 无授权弹窗 | 点击扫描后才申请 | 进入时的弹窗 |
| 拒绝授权 | 用户拒绝后再扫描（NL-015） | 扫描页显示未授权；根页入口仍可进扫描页 | 再次申请 | 扫描不启动 |
| 永久拒绝 | 系统不再弹框（NL-016） | 扫描页 `YoPermissionDenied`，前往应用设置 | 打开应用设置 | 扫描 |
| 蓝牙已开、星闪已关 | NL-111 | 星闪胶囊为关闭 | 阅读 | 不以蓝牙打开启用星闪 |

授权请求的权限名只有 `ohos.permission.ACCESS_NEARLINK`（NL-017）。安装包里的用途说明出现在系统框中（NL-018），根页不另做「权限已声明」成功页。

设置路径同时写两句（NL-112）：「设置 > 多设备协同 > 星闪」，以及部分版本的「设置 > 星闪和蓝牙 > 星闪」。两句都在关闭态的说明里，不收成一句。

## 缺口：合作设备集（NL-115）

页面标题「合作设备集」。胶囊 `warning`，文案「本设备不支持合作设备集」。若结果是 `1009700050`，`YoError.nativeCode` 显示该码，`userMessage` 仍是这句缺口，`nextStep` 写「扫描和 SSAP 仍按各自前提使用」。

本页没有成功胶囊，没有「已加入合作设备集」，没有可完成的主按钮。返回根页后，扫描与 SSAP 入口仍按支持、开关和授权决定是否可点，不因这一页被禁用。

依据：`docs/goal/architecture/nearlink/NL-115.md`，`docs/goal/checklist/nearlink.md` 的缺口集合。
