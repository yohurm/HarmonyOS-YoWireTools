# 扫描与过滤

> 壳、Token、权限墙和深浅色以 [应用壳](../app-shell/README.md) 为准。下文保留 Phase-C 行为细则。冲突时应用壳优先。页面只读页面状态，不调用 Kit。

## 布局

本屏层级见 `YoNavDestinationKind`，结构见下方组件树。 窄屏单列。窗口宽度不小于 600vp 且本屏同时有列表和详情时，用 `YoSplitScaffold`： 普通列表 4:6，终端 6:4，每栏至少 280vp。 页边距 `YoResponsive.pageHorizontal`，分区间距 `YoSpace.XL`（16vp）。 字号 `YoTypeStyle`，地址和 HEX 用 `MONO_S`。 原 Phase-C 若在下文另写了断点或底栏，与 [导航](../app-shell/navigation.md) 冲突时以导航为准。

## ArkUI 组件树

```text
Navigation
└── NavDestination
    └── YoPageShell
        └── Column
            ├── Row                         // 状态条，高 56vp
            │   ├── Text
            │   └── YoStatusPill
            ├── Scroll                      // 只包分段，宽度不写在 SegmentButton 上
            │   └── YoSegmentButton         // SegmentButton，@kit.ArkUI
            ├── TextInput                   // 过滤字段，YoTextModifier
            ├── List
            │   └── ListItem
            │       └── Column
            │           ├── Row
            │           │   ├── Text        // 主行，accessibilityGroup
            │           │   └── YoStatusPill
            │           └── Text            // 次行，最多四个短事实
            └── Row
                ├── YoActionButton          // Button，PRIMARY
                └── YoActionButton          // SECONDARY
    bindSheet                               // 过滤或确认，不承载整条调试流程
```

`ListItem` 设置 `accessibilityGroup(true)`，朗读文本包含胶囊文案。胶囊组件自身不发声。过滤和配对说明用 `bindSheet`。破坏性确认用 `AlertDialog`。不使用 `HdsListItem`。

## 状态矩阵

| 态 | 本屏 |
| --- | --- |
| 默认 | 尚未扫描。过滤摘要为默认低功耗。YoEmpty「尚未扫描」，不写「0 台设备」。 |
| 按下 | 开始与列表行按下后松手才提交或进入详情。过滤确认在 bindSheet 里。 |
| 禁用 | 开关关闭时开始禁用，原因「星闪已关闭」（NL-006）。校验失败的过滤不能开始（NL-030 至 NL-033）。 |
| 空 | 扫描确实启动并结束且一条都没有：YoEmpty「没有发现设备」。这与启动失败不同。 |
| 错误 | 1009700003、1009700099 或 801：YoError。列表保持上次结果（NL-037）。 |
| 加载 | 胶囊「扫描进行中」。同一地址只更新一行（NL-039）。离开页面后变为已停止（NL-027、NL-110）。 |
| 无权限 | 拒绝授权：未授权，可再次申请（NL-015）。不再弹框：`YoPermissionDenied` 前往应用设置（NL-016）。开关关闭是禁用，不是无权限。 |

按下只改变控件外观。松手后才把意图交给页面状态。禁用控件不进入按下。错误行若仍写着未授权，归到无权限，不另做一套权限样式。组件树是该页类型的上限：行为细则没有分段就不渲染 `YoSegmentButton`，没有过滤输入就不渲染 `TextInput`。缺口墙的写法见 [权限墙与缺口墙](../app-shell/permission-gap-wall.md)。

## 行为细则


发现设备、编辑过滤、查看一条广播。收藏和已配对地址对照也在广播详情里完成，不单独做成功向导。

架构：`docs/goal/architecture/nearlink/NL-019.md` 至 `NL-052.md`，以及 `NL-104.md`、`NL-110.md`。研究里的过滤字段表见 `docs/goal/research/nearlink.md`「能力映射」。

## 导航

| 从 | 到 | 方式 | 返回 |
| --- | --- | --- | --- |
| 根页入口卡 | 扫描页 `MODULE` | 压栈 | 返回根页；若正在扫描，先停止并取消 `deviceFound`（NL-027） |
| 窄屏列表行 | 广播详情 `OBJECT` | 压栈 | 返回列表，列表滚动位置保持 |
| 宽屏（大于等于 600vp） | 同一页分栏 | `YoSplitScaffold` 4:6 | 无第二页；收起详情只清空右栏 |
| 「过滤」 | 半模态 | `MODAL` | 关闭半模态不停止当前扫描，直到用户确认重新开始 |
| 详情「SSAP」或「端口」 | 对应会话 | 压栈 | 返回详情 |
| 应用进后台 | 停在扫描页 | 扫描被停止（NL-110） | 回前台仍是本页，状态为已停止 |

进入扫描页仍不弹授权。用户点击「开始扫描」才申请（NL-013）。重复开始不叠两套订阅（NL-026）：进行中时主按钮已是「停止」，再次触发开始的入口禁用。

## 信息密度

| 留在屏上 | 放进详情 |
| --- | --- |
| 扫描胶囊：未开始 / 进行中 / 已停止 | 原始 HEX 与字节长度（NL-041） |
| 主按钮：开始或停止 | 完整名、缩短名、系统上报名及长度（NL-043–NL-045） |
| 一行过滤摘要：组数、模式、时长 | 服务数据与厂商数据分列、未知类型 HEX（NL-046、NL-047） |
| 列表行：名称、地址、RSSI、可连接、发现时间、发现次数 | 16 比特 UUID 展开全文（NL-048） |
| 地址旁短注「随机地址」 | 收藏字段、已配对对照、名称截断说明 |
| 低于门限的行标「低于门限」或「本地后滤」 | 组内与、组间或的长说明，写在过滤半模态 |
| 失败错误码贴在列表上方 | 不把失败画成「0 台设备」 |

`deviceClass` 只在系统不低于 5.1.0(18) 且有值时出现在行尾（NL-038）。RSSI 127 显示「无效」，不显示 127 dBm，不参与信号从强到弱的排序（NL-104，并见 NL-035）。

## 布局

窄屏：过滤摘要、主按钮、列表纵向排列。列表 `contentEdgeToEdge`，滚动条贴边。宽屏：左列表右详情，详情空时用 `YoEmpty`「选择一台设备」。半模态在小于 600vp 时贴底，大于等于 600vp 时居中，与 `WindowWidthBreakpointUtil.usesCenterSheet` 一致。

过滤表单折行：窄屏一项一行，宽屏地址与名称并排。不使用已删除的 `FilterSheetView`。

## 组件

| 区域 | 组件 |
| --- | --- |
| 页壳 | `YoPageShell`，`MODULE`，返回 |
| 进行中 / 已停止 / 无效 RSSI / 本地筛选 | `YoStatusPill` |
| 开始、停止、确认过滤 | `YoActionButton` |
| 模式 | `YoSegmentButton`，两项：「低功耗」「均衡」 |
| 列表与详情 | `YoSplitScaffold` |
| 无设备 | `YoEmpty` |
| 启动失败 | `YoError`，列表保持上次结果 |
| 未授权 | `YoPermissionDenied` |
| 过滤表单 | 系统半模态 + `TextInput` + 现有按钮 |

模式只有低功耗和均衡，默认低功耗。没有低时延（NL-028）。`YoSegmentButton` 的选项由页面传入这两项，不在 Kit 里写死星闪文案。

## 控件六态

| 控件 | 默认 | 按下 | 禁用 | 空 | 错误 | 加载 |
| --- | --- | --- | --- | --- | --- | --- |
| 开始扫描 | 主按钮「开始扫描」 | `YoActionButton` 按下 | 开关关闭、正在开关、未填合法过滤、时长越界、扫描已在进行 | 不负责空列表 | 点击后校验失败，按钮保持默认可再次修正 | `loading` 仅在请求发出到进行中或失败返回之间；进行中改成停止按钮，列表仍在 |
| 停止 | 进行中时为主按钮「停止」 | 按下 | 未在扫描 | 无 | 停止失败时 `YoError` 带码，胶囊保持进行中直到成功 | 停止请求发出时 `loading` |
| 模式分段 | 低功耗选中 | 系统分段按下 | 扫描进行中时禁用，原因「停止后再改模式」；改过滤走确认流程（NL-040） | 无第三项 | 无 | 无 |
| 过滤确认 | 「用此条件重新扫描」 | 按下 | 校验未过 | 字段都空时，低版本不能确认（NL-022、NL-024） | 401 或校验句在半模态内 | 确认后按钮 `loading`，直到旧扫描停止且新扫描开始或失败 |
| 列表行 | 两行摘要可点 | 系统列表按压 | 无整行禁用；连接入口在详情里按会话前提禁用 | 无结果时不画行，改 `YoEmpty` | 行内不画「扫描成功但 0 台」 | 进行中顶部胶囊，行可继续更新 |
| 详情操作 | SSAP、端口、收藏 | 按下 | 不支持或开关关闭时禁用并写原因 | 无广播数据时详情用空数据文案，操作仍可按连接前提显示 | 连接失败不画在本页成功位 | 跳转瞬间不重复加载整表 |

## 页面状态

| 状态 | 屏上 |
| --- | --- |
| 默认，尚未扫描 | 过滤摘要为默认低功耗、时长未填（全时段）。`YoEmpty` 标题「尚未扫描」，不是「0 台设备」 |
| 进行中 | 胶囊「扫描进行中」。新行按地址合并，同一地址只更新 RSSI、时间、发现次数（NL-039） |
| 已停止 | 胶囊「已停止」。之后发现时间不再变（NL-025） |
| 到达时长 | 10 或 60 秒结束后变为已停止，并写日志（NL-029） |
| 空结果 | 扫描确实启动并结束，且一条都没有：`YoEmpty`「没有发现设备」。这与启动失败不同 |
| 启动失败 | `1009700003`、`1009700099` 或 801：`YoError` 显示码和一句原因。列表保持上次结果；若没有上次结果，空态文案是失败，不写「发现 0 台」（NL-037） |
| 校验失败 | 不进入进行中。时长必须在 10 到 60 秒，留空才是全时段（NL-030）。厂商数据必须带厂商 ID（NL-031）。数据与掩码等长（NL-032）。厂商 ID 为 1 到 65535（NL-033） |
| 权限 | 拒绝：未授权，可再次申请（NL-015）。不再弹框：去应用设置（NL-016） |
| 后台恢复 | 回前台显示已停止，主按钮恢复「开始扫描」（NL-110） |
| 开关关闭 | 开始按钮禁用，原因「星闪已关闭」，并链到根页的设置路径（NL-006） |

过滤逻辑在半模态里写清楚，并在摘要里用短句复述：

- 组间是或：地址 A 的一组，或名称 B 的一组，满足一组即可出现（NL-020）。
- 组内是与：同一组的地址和名称都要满足（NL-021）。
- 非空名称可以启动，且不返回 401（NL-019）。
- 低于 26.0.0：全空过滤不启动，提示至少一项，日志含 401（NL-022）。用户选「扫描全部」时只显示该版本不能空过滤，不调用 `startScan(null)`（NL-024）。
- 不低于 26.0.0：用户明确选择扫描全部后可以启动，同时显示可能扫到非预期设备并增加功耗（NL-023）。
- RSSI 门限：低于 26.0.0 时摘要写「本地后滤」，列表仍含全部上报，低于门限的行有标记；或不写入系统过滤并说明门限自 26.0.0 起才由系统过滤（NL-034）。不低于 26.0.0 且门限为 -70 时，新上报的 RSSI 大于等于 -70，127 仍标无效（NL-035）。
- 扫描中改过滤：确认后先停止并取消订阅，再按新条件开始。旧条件命中的行去掉「仍符合过滤」标记（NL-040）。

## 广播详情

详情标题用名称，副标题用地址，并标明随机地址，映射清除后可能变化（NL-049）。

| 内容 | 表现 |
| --- | --- |
| 有 `data` | 完整 HEX 与字节长度（NL-041） |
| `data` 长度为 0 | 「无广播数据」，不写解析成功（NL-042） |
| 类型 `0x0B` 或 `0x0A` | 名称，并标明完整名或缩短名（NL-043） |
| 上报名与 `0x0B` 不一致，或服务数据把名称截成 9 字节 | 两套名称同时在，说明系统上报名可能来自设备信息管理服务的本地名称 TLV（NL-044） |
| 完整名扫不到、前 9 个字符能扫到 | 写出服务数据中的名称长度和原始 HEX，不单写「扫描失败」（NL-045） |
| `0x03`、`0x04`、`0xFF` | UUID 与值分列；厂商 ID 与 HEX 分列（NL-046） |
| 未知类型 | 类型号 + HEX，整包保留（NL-047） |
| 16 比特标准 UUID | 展开字符串的前缀对应 `37BEA880-FC70-11EA-B720-000000000000`，后 16 比特为原值（NL-048） |

收藏保存名称、有则保存设备类型、以及最近地址。只有地址时，详情写「身份可能变化」（NL-050）。

已配对：不低于 6.0.1(21) 时列出 `getPairedDevices()` 的地址，能与当前行对照（NL-051）。低于该版本时显示「当前系统版本不提供该能力」和起始版本 6.0.1(21)，不用空列表表示没有配对设备（NL-052）。

从新扫描地址连接时，若收藏里的旧地址不同，详情在前往会话前提示旧地址可能已失效。连接参数使用新地址（NL-106，会话侧见 SSAP 客户端）。

## 缺口：服务 UUID 不能作为系统过滤（NL-036）

过滤半模态里可以填写服务 UUID，旁边固定警告胶囊：「系统扫描过滤不包含服务 UUID」。摘要写「本地筛选」，不写「系统过滤」。

没有「已按服务 UUID 系统过滤」的成功胶囊，也没有把该项送进 `ScanFilters` 后的成功日志位。本地筛选关闭时，不含该 UUID 的设备仍出现在列表。本地筛选打开时，隐藏的是解析之后的行，行上的标记仍是「本地筛选」。

依据：`docs/goal/architecture/nearlink/NL-036.md`。
