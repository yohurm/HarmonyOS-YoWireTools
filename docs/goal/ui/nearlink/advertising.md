# 广播

> 壳、Token、权限墙和深浅色以 [应用壳](../app-shell/README.md) 为准。下文保留 Phase-C 行为细则。冲突时应用壳优先。页面只读页面状态，不调用 Kit。

## 布局

本屏层级见 `YoNavDestinationKind`，结构见下方组件树。 窄屏单列。窗口宽度不小于 600vp 且本屏同时有列表和详情时，用 `YoSplitScaffold`： 普通列表 4:6，终端 6:4，每栏至少 280vp。 页边距 `YoResponsive.pageHorizontal`，分区间距 `YoSpace.XL`（16vp）。 字号 `YoTypeStyle`，地址和 HEX 用 `MONO_S`。 原 Phase-C 若在下文另写了断点或底栏，与 [导航](../app-shell/navigation.md) 冲突时以导航为准。

## ArkUI 组件树

```text
Navigation
└── NavDestination
    └── YoPageShell
        └── Scroll
            └── Column
                ├── Row
                │   ├── Text
                │   └── YoStatusPill
                ├── TextInput
                ├── YoSegmentButton
                ├── List
                │   └── ListItem
                └── YoActionButton
```

`ListItem` 设置 `accessibilityGroup(true)`，朗读文本包含胶囊文案。胶囊组件自身不发声。过滤和配对说明用 `bindSheet`。破坏性确认用 `AlertDialog`。不使用 `HdsListItem`。

## 状态矩阵

| 态 | 本屏 |
| --- | --- |
| 默认 | `YoEmpty`「尚未发送广播」。表单可编辑。可连接默认需要用户确认后才发送 |
| 按下 | 开始与停止松手后才提交。 |
| 禁用 | 间隔越界或开关关闭时开始禁用，原因可见（NL-055）。 |
| 空 | 未广播不是空列表。没有对端不是本页的空态。 |
| 错误 | 启动失败显示码和原因，不出现广播 ID |
| 加载 | 只有按钮加载，列表留在屏上 |
| 无权限 | 未授权不开始广播。权限墙与「广播间隔越界」（NL-055）的错误分开。 |

按下只改变控件外观。松手后才把意图交给页面状态。禁用控件不进入按下。错误行若仍写着未授权，归到无权限，不另做一套权限样式。组件树是该页类型的上限：行为细则没有分段就不渲染 `YoSegmentButton`，没有过滤输入就不渲染 `TextInput`。缺口墙的写法见 [权限墙与缺口墙](../app-shell/permission-gap-wall.md)。

## 行为细则


本端作为外围发送广播。手机、平板、PC 之间在系统设置里配对后断开的说明也在这页，因为那是角色问题，不是端口终端的故障。

架构：`docs/goal/architecture/nearlink/NL-053.md` 至 `NL-057.md`。端口两端对等见 `NL-058.md`，界面落在端口终端，本页只用一句话链过去。

## 导航

| 从 | 到 | 方式 | 返回 |
| --- | --- | --- | --- |
| 根页「广播」 | 本页 `MODULE` | 压栈 | 返回根页。进行中的广播不因返回而自动停止，顶栏仍可从根页入口卡看到「广播中」 |
| 开始前的可连接确认 | 系统对话框 | 确认后才调用开始 | 取消则留在表单 |
| 停止 | 指定广播 ID 的行 | 行内危险按钮，再确认 | 取消则保持已开始 |
| 「为何设置里立刻断开」 | 页内说明块 | 展开 | 收起 |

本页不进入 SSAP 客户端角色。需要业务连接时，说明指向 SSAP 或端口。

## 信息密度

| 留在屏上 | 放进行详情 |
| --- | --- |
| 是否在广播、广播 ID、可连接与否 | 间隔 slot、功率档、是否包含本机名 |
| 主按钮开始或停止 | 服务 UUID 与厂商数据的完整 HEX |
| 一条角色说明的标题 | NL-057 的全文 |

列表按广播 ID 一行。同时只强调一条当前广播；多条时每行自己的胶囊表示已开始或已停止。

## 布局

窄屏表单在上、ID 列表在下。宽屏表单占 4 列、列表占 8 列，用栅格折行，不另做分栏组件。停止是行内 `YoActionButton`，`kind = DANGER`，`compact = true`，热区仍不小于 48vp。

| 区域 | 组件 |

## 控件六态

| 控件 | 默认 | 按下 | 禁用 | 空 | 错误 | 加载 |
| --- | --- | --- | --- | --- | --- | --- |
| 开始广播 | 「开始广播」 | 按下 | 不支持、开关关闭、间隔越界、未确认可连接 | 列表空时按钮仍可用 | 校验句留在表单，不进入已开始 | 请求期间 `loading`，成功后变为该 ID 的停止 |
| 停止 | 行上「停止」 | 按下 | 该 ID 已停止 | 无 ID 时没有停止按钮 | 停止失败保持已开始，并显示码 | 该行按钮 `loading` |
| 包含本机名 | 可单独打开 | 系统开关按下 | 广播进行中时禁用，原因「停止后再改内容」 | 关闭时不把空的服务 UUID 数组提交（NL-056） | 若因此得到 401，按错误显示，不假装字段已省略 | 无 |
| 间隔输入 | 占位「默认 5000」 | 输入焦点 | 进行中禁用 | 留空表示用默认 5000 | 小于 160 或大于 16777215 时不启动 | 无 |
| 角色说明入口 | 文字按钮 | 按下 | 无 | 说明未展开时不是空态失败 | 无 | 无 |

## 页面状态

| 状态 | 屏上 |
| --- | --- |
| 默认 | `YoEmpty`「尚未发送广播」。表单可编辑。可连接默认需要用户确认后才发送 |
| 已开始 | 得到广播 ID，胶囊「已开始」。日志含间隔、功率档、是否可连接（NL-053） |
| 已停止 | 该 ID 胶囊「已停止」（NL-054） |
| 间隔越界 | 不启动。提示合法范围与默认 5000（NL-055） |
| 只包含本机名 | 可以启动。未填的服务与厂商字段不作为空数组提交（NL-056） |
| 加载 | 只有按钮加载，列表留在屏上 |
| 错误 | 启动失败显示码和原因，不出现广播 ID |
| 开关关闭 | 开始禁用，原因指向根页设置路径 |

角色说明（NL-057）展开后写明：对端也是手机、平板或 PC/2in1 时，系统设置里的连接要求对端提供可用服务；两端都是中心设备时会断开。业务连接由本模块发起 SSAP 或端口连接。这段是说明，不是「已在设置里连上」的成功态。

端口角色不在本页标成 SSAP 客户端。链到端口终端的 NL-058：两端对等，任一端可发起连接。
