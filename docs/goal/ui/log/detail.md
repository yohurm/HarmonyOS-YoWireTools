# 日志详情

设计屏号 `screen.log.detail`。窄屏是 `OBJECT`，从日志中心 push。宽屏是日志中心右栏，不单独占路由也可以。两种摆法用同一棵内容树。

## 布局

标题是时间。副标题是模块和协议。下面固定顺序：方向、目标、错误码、文本、HEX。长 HEX 用 `List` 或 `Text` 的滚动，不截成成功摘要。没有的字段写「未记录」，不用 0。

导出这一条用次按钮。不在详情里提供「重新发送」，因为没有跨模块的重放接口。

## ArkUI 组件树

```text
Column
├── Text                              // 时间
├── YoStatusPill                      // 模块
├── List
│   └── ListItem
│       └── Row
│           ├── Text                  // 字段名
│           └── Text                  // MONO_S
└── YoActionButton                    // 导出这一条
```

## 状态矩阵

| 态 | 本屏 |
| --- | --- |
| 默认 | 字段按上面的顺序可见 |
| 按下 | 导出按钮松手后才写文件 |
| 禁用 | 该行没有可导出的原始值时导出禁用，原因「没有原始值」 |
| 空 | 不使用空页。打开详情时行必须存在。中心没有选中时，宽屏右栏用 `YoEmpty`「未选择记录」 |
| 错误 | 导出失败 `YoError`，字段保留 |
| 加载 | 导出写文件时按钮 `loading` |
| 无权限 | 详情不申请权限。错误码字段照实显示，包括权限类错误码 |

# 日志详情

窄屏从日志中心 push；宽屏嵌在右侧。目标路由 `/log/detail`。模式：链路详情那种标签/值，加上一块可滚动的正文。

## 布局

标签依次：时间、来源、方向、摘要。值 Body_L。来源用胶囊（蓝牙、网络、星闪、中性「未知」），不是新的底栏。

正文区 surface 卡，padding 12，圆角 16，`Text` Body_S，`tnum`，可选择复制（系统文本选择，不自绘菜单）。空正文「没有正文」，不用灰条代替整段。

没有删除按钮。没有导出按钮。契约若以后要导出，再加文字按钮，本规范不先画。

## 组件树

```text
NavDestination 「详情」  或宽屏 Column
  Scroll
    Column padding 16 gap 16
      标签「时间」 Text
      标签「来源」 胶囊
      标签「方向」 Text 「收」|「发」|「未记录」
      标签「摘要」 Text
      Column 表面卡
        Text Body_S 正文
```

## 状态

| 态 | 界面 |
| --- | --- |
| 默认 | 四项都有字，正文可见 |
| 按下 | 仅返回或宽屏列表的按下，详情本身无按钮 |
| 禁用 | 无 |
| 空 | 方向「未记录」，正文「没有正文」。不编 HEX |
| 错 | 卡片位置改为 status.error 消息，标签仍保留能显示的项 |
| 加载 | 值的位置 LoadingProgress，标签在 |
| 无权限 | 无权限墙 |

## 对照

采用 WLAN 详情的标签/值。胶囊用状态 Token。不采用其余六种布局；控制台的单行省略只在列表，详情必须能看全正文。
# 日志详情

目标名 `/log/detail`。来源：链路详情的单卡片；正文用 12 `tnum` 以便对行。

标题为时间。卡片 padding 12，圆角 16，背景 `comp_background_primary`。首行胶囊级别，次行来源模块 14。正文 `Text` 可系统选择，不自绘复制菜单。

空正文写「没有正文」。

## 状态

| 态 | 表现 |
| --- | --- |
| 默认 | 全文可见，可滚动 |
| 按下 | 无单独按下 |
| 禁用 | 不适用 |
| 空 | 「没有正文」 |
| 错误 | 卡片上 `warning`「无法读取」 |
| 加载 | 卡片内进度 |
| 无权限 | 权限墙 |
