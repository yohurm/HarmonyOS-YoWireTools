# 局域网发现

目标名 `/wifi/lan-discovery`。来源：扫描列表，但不用 H2 的「搜索成功」雷达文案。行是主机而不是周边设备。

行 64vp：主行主机名，没有主机名时主行是 IP；次行另一项，`tnum`。无「连接」按钮。行点击 `push` HTTP，并把主机写入 URL 初值。HTTP 页仍停在「尚未发送」，不自动发请求。

空：14「尚未发现」+ 主按钮「开始」。不用雷达。

## 状态

| 态 | 表现 |
| --- | --- |
| 默认 | 有主机行 |
| 按下 | 行按下 |
| 禁用 | 「开始」在扫描中变成「停止」 |
| 空 | 「尚未发现」 |
| 错误 | 列表上 `warning` 一行 |
| 加载 | 「正在发现」，已发现的行保留 |
| 无权限 | 权限墙 |
