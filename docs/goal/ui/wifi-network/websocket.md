# WebSocket

与 HTTP 分开一屏，因为发送的是帧而不是一次请求/响应。模式：控制台 + 连接 sheet。

未连接：Title_M「未连接」，`TextInput` URL，主按钮「连接」。这一块最大宽 480vp。

已连接：日志行 48vp，方向色点（出 brand，入 info），底栏输入+「发送」，菜单「断开」。URL 收在标题 Body_S，不占一行大标题。

不设 GET/POST。不设过滤。

## 状态

| 态 | 界面 |
| --- | --- |
| 默认 | 已连接，日志在滚，发送可点 |
| 按下 | 发送与断开 |
| 禁用 | URL 空时「连接」禁用；断开后底栏移除 |
| 空 | 已连接无帧：「还没有帧」 |
| 错 | 连接失败留在未连接布局，按钮下 Body_S status.error。已连接后的发送失败追加日志行 |
| 加载 | 「正在连接」，按钮禁用 |
| 无权限 | 权限墙 |

## 对照

采用 Socket/控制台和 wifi 的单主按钮。不采用 HTTP 的方法页签、扫描、WLAN 详情、家居、FastBle、数据卡。
目标名 `/wifi/websocket`。来源：Socket 终端；日志行 48vp。URL 放在标题栏副标题 12，不占内容区的大标题。

未连接：标题「未连接」，`TextInput` URL，主按钮「连接」，块最大宽 448。

已连接：日志行，收到的点为 `brand`，发出的点为 `font_secondary`。底栏输入 +「发送」。菜单「断开」。
