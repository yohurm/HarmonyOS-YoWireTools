# WebSocket

目标名 `/wifi/websocket`。来源：Socket 终端；日志行 48vp。URL 放在标题栏副标题 12，不占内容区的大标题。

未连接：标题「未连接」，`TextInput` URL，主按钮「连接」，块最大宽 448。

已连接：日志行，收到的点为 `brand`，发出的点为 `font_secondary`。底栏输入 +「发送」。菜单「断开」。

## 状态

| 态 | 表现 |
| --- | --- |
| 默认 | 已连接 |
| 按下 | 发送按下 |
| 禁用 | URL 空时「连接」disabled |
| 空 | 「还没有消息」 |
| 错误 | 标题下 `warning` |
| 加载 | 「正在连接」 |
| 无权限 | 权限墙 |
