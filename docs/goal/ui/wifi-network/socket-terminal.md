# Socket 终端

目标路由 `/wifi/socket-terminal`。模式：控制台日志。连接参数在 sheet：主机 `TextInput`、端口 `TextInput`、`SegmentButton`「TCP」「UDP」（只有这两项，ViewModel 不支持的一项不渲染）。主按钮「连接」。

已连接后的列表和发送栏与 SPP 终端相同，胶囊文案「已连接」，菜单「断开」走 AlertDialog。标题是「主机:端口」。

未连接的空态不是「还没有数据」，而是 Title_M「未连接」和主按钮「连接」。不要同时显示空日志和连接按钮抢焦点；未连接时不渲染日志和发送栏。

宽屏：未连接表单最大宽 480vp 居中。已连接日志最大宽 720vp。

## 状态

| 态 | 界面 |
| --- | --- |
| 默认 | 已连接日志，发送可点（输入非空） |
| 按下 | 发送、断开确认按钮 |
| 禁用 | 主机或端口空：sheet「连接」禁用。断开后发送栏禁用并隐藏，回到「未连接」 |
| 空 | 已连接无字节：「还没有数据」 |
| 错 | sheet 或日志末行 status.error |
| 加载 | 「正在连接」，sheet 不关，按钮禁用并带 LoadingProgress |
| 无权限 | 权限墙「需要网络权限」 |

## 对照

采用控制台行、wifi sheet 的单主按钮、SPP 的发送栏。不采用 WLAN 分组、扫描雷达、四场景（协议只有 TCP/UDP 两段）、家居、FastBle、体温卡。
