# Socket 终端

目标名 `/wifi/socket-terminal`。来源：SPP 终端的已连接布局；连接半模态用于主机和端口（H1 的「一个表单、一颗主按钮」，字段换成地址而不是 Wi‑Fi 密码）。

未连接不渲染日志。标题「未连接」，主按钮「连接」打开 `bindSheet`：`TextInput` 主机、`TextInput` 端口、主按钮「连接」。失败时结果行留在 sheet 里。

已连接：行 48vp，底栏输入 +「发送」，菜单「断开」。

宽屏：未连接按钮区最大宽 448。已连接日志最大宽 720。

## 状态

| 态 | 表现 |
| --- | --- |
| 默认 | 已连接可发送 |
| 按下 | 发送按下 |
| 禁用 | 主机空时 sheet 主按钮 disabled |
| 空 | 已连接无数据：「还没有数据」 |
| 错误 | sheet 内 `warning` |
| 加载 | 「正在连接」，sheet 保持打开直到成功或失败 |
| 无权限 | 若 ViewModel 报告网络权限缺失，未连接区换权限墙 |
