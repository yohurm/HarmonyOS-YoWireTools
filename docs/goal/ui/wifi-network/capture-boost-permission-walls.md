# 抓包、加速与权限墙

> 壳、Token、权限墙和深浅色以 [应用壳](../app-shell/README.md) 为准。下文保留 Phase-C 行为细则。冲突时应用壳优先。页面只读页面状态，不调用 Kit。

## 布局

本屏层级见 `YoNavDestinationKind`，结构见下方组件树。 窄屏单列。窗口宽度不小于 600vp 且本屏同时有列表和详情时，用 `YoSplitScaffold`： 普通列表 4:6，终端 6:4，每栏至少 280vp。 页边距 `YoResponsive.pageHorizontal`，分区间距 `YoSpace.XL`（16vp）。 字号 `YoTypeStyle`，地址和 HEX 用 `MONO_S`。 原 Phase-C 若在下文另写了断点或底栏，与 [导航](../app-shell/navigation.md) 冲突时以导航为准。

## ArkUI 组件树

```text
Navigation
└── NavDestination
    └── YoPageShell
        └── List
            └── ListItem                    // 固定说明行，不是成功数据
                └── Column
                    ├── Text
                    ├── YoStatusPill        // warning 或 neutral
                    └── Text                // 系统设置路径
// 不出现「开始抓包」Button
```

`ListItem` 设置 `accessibilityGroup(true)`，朗读文本包含胶囊文案。胶囊组件自身不发声。过滤和配对说明用 `bindSheet`。破坏性确认用 `AlertDialog`。不使用 `HdsListItem`。

## 行为细则


本页把开发者选项、缺口、受限和系统能力放在同一张说明列表里。每一项的默认内容就是拒绝或系统设置路径。列表里没有这些能力的应用内成功态，也没有「开始」之后会变成完成的按钮。

## 布局

`YoPageShell` 标题「权限墙」，`MODULE`。

一行一项，主行是能力名，次行是路径或拒绝原因，右侧 `YoStatusPill` 为 `warning` 或 `neutral`。行高至少 56vp，次行允许两行，`maxLines` 2。`<600vp` 单列。`≥600vp` 仍单列阅读，宽度缩进到 8 栅格，避免说明被拉得过宽（响应式布局方法里的缩进）。

行按下只展开同一段说明的完整句子，不导航到执行页。

| 条目 | 标记 | 胶囊 | 次行 |
| --- | --- | --- | --- |
| WN-118 | 开发者选项 | 系统设置 | 开发者选项中的网络报文分析。抓包在 PC 的 Wireshark。与 USB 调试互斥。没有开始抓包按钮 |
| WN-119 | 开发者选项 | 系统设置 | USB 未连接时，该开关不可用 |
| WN-120 | 缺口 | 未提供 | 没有捕获其他应用流量或导出整机 pcap 的动作 |
| WN-121 | 缺口 | 未提供 | 仅限带 kernel.NET_RAW 且 sudo 的二进制。本应用不提供 PF_PACKET |
| WN-122 | 开发者选项 | 系统设置 | 弱网场景在网络领航员。本页没有带宽滑杆 |
| WN-123 | 受限 | 受限权限 | 多网并发需要 LINKTURBO。本页不发起多网激活 |
| WN-124 | 真机 | 未通过 | 模拟器不支持 P2P、VPN、网络加速。不把失败记成真机缺陷。验收保持未通过 |
| WN-125 | 受限 | 受限权限 | 没有 GET_WIFI_PEERS_MAC 时 P2P 失败可见。同一块写明模拟器不支持 P2P |
| WN-126 | 受限 | 拒绝 | Phone 上读取以太网 MAC 被拒绝 |
| WN-127 | 系统或企业 | 企业或系统 | 没有防火墙规则编辑。面向企业或系统应用，当前仅 2in1 可申请 |

模拟器上，P2P、VPN、网络加速三行的胶囊为「未通过」，并写明模拟器不支持该项。这个胶囊保持未通过，不改成「已通过」，也不写成真机缺陷。真机上这三行仍只显示受限或系统路径，本页没有对应的应用内成功结果。

需要去系统设置的行使用 `YoActionButton` `TEXT`「打开系统设置」。该按钮的结果是离开到设置，返回后本页胶囊不变成成功。报文分析、网络领航员、WLAN 开关的路径写在次行，用户按系统界面自己找开关。

## 状态

### 默认

上表十行全部可见。这就是本页的 `CONTENT`。它不是成功数据。

### 按下

行与「打开系统设置」按下时透明度为 `YoOpacity.PRESSED`。松手展开说明或离开到设置。

### 禁用

本页不放置禁用的「开始抓包」「开始镜像」「应用带宽滑杆」「激活多网」「编辑防火墙」「读取以太网 MAC」。这些动作不出现，所以没有一个看起来像成功、只是暂时禁用的按钮。若系统设置按钮在没有设置入口的缺口行上，该行不放这个按钮。

### 空

本页不用 `EMPTY`。十行是固定说明。缺少其中一行就视为页面不完整，而不是「没有数据」。

### 错误

若调用点仍然返回 201、801 或其他拒绝码，该行次行追加 `nativeCode`，胶囊保持 `warning`。整页不因为这个码进入可重试的成功流程。`YoError.retryable = false`。

### 加载

进入页面不发这些 Kit 调用，因此没有「正在抓包」「正在加速」的加载。页面状态就绪后直接是说明列表。若权限结论尚在读取，仅顶部一条 `YoLoading`「正在核对权限」，核对完十行同时出现。核对失败也要露出十行说明。

## 与其他页的边界

P2P 的失败说明留在本页，不做到扫描页或链路页的成功区。弱网模拟不出现在吞吐页。以太网 MAC 不出现在链路页的地址格子里。
