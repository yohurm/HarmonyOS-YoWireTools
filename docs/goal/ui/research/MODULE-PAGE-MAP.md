# 页面地图

一页一行。后续 Goal 按「模块」领取，一次只做一列模块里的页面，并使用指定的组合编号。半模态不是页，列在各模块末尾，避免被画成全屏。

主状态六种：

| 状态 | 含义 |
| --- | --- |
| 默认 | 主路径有可读数据，或对象已就绪 |
| 空 | 读取成功，但没有对象 |
| 加载 | 第一次结果未返回 |
| 失败 | 接口或任务失败，必须有错误码或 `warnings` |
| 关射频 | 系统开关关闭，页面不能假装仍在扫描 |
| 权限 | 缺少这一页需要的权限 |

「不适用」表示这一页不读该条件。降级（例如 BSSID 被系统隐藏）写在默认态里，不单独占一种整页。

组合编号见 [COMPONENT-COMPOSITION.md](COMPONENT-COMPOSITION.md)。

## 看板

领取 Goal：只做本节。

### `DB-BOARD` 应用看板

组合 C1。职责见 [DASHBOARD.md](DASHBOARD.md)。

| 状态 | 表现 |
| --- | --- |
| 默认 | 状态带、焦点数字、三枚次级数字、告警、趋势或「样本不足」 |
| 空 | 全部为未采样且无历史告警。主按钮「读取射频状态」 |
| 加载 | 数字与告警行为骨架 |
| 失败 | 采样失败条，保留上次读数与时间 |
| 关射频 | 对应格为关。三路都关时焦点告警可下钻，页面仍是看板 |
| 权限 | 缺权限的格单独提示「去授权」，其余格保持 |

### `DB-ALERTS` 告警时间线

组合 C2。

| 状态 | 表现 |
| --- | --- |
| 默认 | 时间倒序。行：级别、模块、对象、错误码、时间 |
| 空 | 「这个时间窗没有告警」。主按钮回到看板 |
| 加载 | 行骨架 |
| 失败 | 日志源不可读，主按钮重试 |

## 蓝牙

领取 Goal：只做本节。根页不是发现列表。

### `BT-BOARD` 链路板

组合 C1。读数：活跃经典链路、BLE 订阅数、最近错误、地址类型摘要。

| 状态 | 表现 |
| --- | --- |
| 默认 | 焦点为活跃链路数。次级为最近错误码与 BLE 订阅数 |
| 空 | 射频开、有权限、无链路也无最近错误。主按钮进入上次的发现页；没有上次则进入 `BT-CLASSIC-DISCOVERY`。另一条发现方式是文字按钮，不做成两张入口卡 |
| 加载 | 骨架 |
| 失败 | 状态接口失败，主按钮重试 |
| 关射频 | 焦点「蓝牙已关闭」。主按钮去系统蓝牙设置。不进入空列表 |
| 权限 | 阻断。主按钮申请或去设置 |

### `BT-CLASSIC-DISCOVERY` 经典发现

组合 C3。两组：已配对、附近。行：名称、虚拟地址、Profile。已配对优先。

| 状态 | 表现 |
| --- | --- |
| 默认 | 两组列表。行内胶囊进入连接半模态 |
| 空 | 扫描结束且两组都空。「附近没有经典设备」 |
| 加载 | 状态条「正在发现」，保留上一轮行 |
| 失败 | 状态条写错误码，列表停在上一轮 |
| 关射频 | 阻断，不留空白列表 |
| 权限 | 阻断 |

### `BT-SPP-TERMINAL` 经典终端

### `NW-LAN` 子网主机

组合 C5 的表。

| 状态 | 表现 |
| --- | --- |
| 默认 | 主机、存活、时延、开放端口 |

### `NW-PORT` 端口扫描

组合 C5。范围与并发来自设置，不在结果页上铺开成菜单。

### `NW-SOCKET` 套接字会话

组合 C6。TCP 与 UDP 用连接条上的协议字段区分，不拆成两套页面壳。

| 状态 | 表现 |
| --- | --- |

### `NW-HTTP` 报文

组合 C8。

| 状态 | 表现 |

### `NW-WS` WebSocket 会话

组合 C6。状态同 `NW-SOCKET`。自动重连是否开启写在连接条，开关本身在设置。

### `NW-MQTT` MQTT 会话

组合 C6，连接条下增加主题列表。

| 状态 | 表现 |
| --- | --- |
| 默认 | 连接、主题、载荷记录 |

| 失败 | 认证或网络失败 |

### 网络半模态

| 编号 | 任务 |
| --- | --- |
| `NW-SHEET-TARGET` | 确认诊断或扫描目标 |

组合 C9。数据来自 `yolog` 的 `LogRecord`。按会话过滤依赖尚未存在的会话 ID，在字段落地前，筛选只用 tag、级别、时间窗，页面上写明「尚未按会话过滤」。

| 默认 | 搜索、来源分段、级别芯片、列表 |

| 加载 | 行骨架 |
| 失败 | 文件不可读 |
| 关射频 | 不适用 |
| 权限 | 不能读日志文件时阻断 |

### `LOG-SESSION` 单次会话

组合 C9 的详情栏。会话 ID 尚未写入 `LogRecord` 之前，本页展示同一 tag 与时间窗的记录，标题标明这个限制。

| 状态 | 表现 |
| --- | --- |
| 默认 | 元数据加原始行 |
| 空 | 时间窗内没有匹配行 |
| 加载 | 骨架 |
| 失败 | 读取失败 |
| 关射频 | 不适用 |
| 权限 | 阻断 |

导出用 `LOG-SHEET-EXPORT`（C13）：TXT、CSV、JSON。脱敏开关读取设置，不在导出弹层里重做一套设置页。

## 设置

领取 Goal：只做本节。

### `SET-ROOT` 设置

组合 C11。

| 状态 | 表现 |
| --- | --- |
| 默认 | 搜索与分组：显示、日志、后台、蓝牙、网络、星闪、安全、关于 |
| 空 | 不适用。分组始终在 |
| 加载 | 当前值用骨架，组标题仍在 |
| 失败 | 某一行读取失败时该行显示失败，其余行保持。整表失败才整页阻断 |
| 关射频 | 不适用 |
| 权限 | 不适用 |

### 设置子页

都用 C11。关射频与权限在这些页上不适用，除非该页正在申请一项权限。

| 编号 | 内容 | 空 | 加载 | 失败 |
| --- | --- | --- | --- | --- |
| `SET-DISPLAY` | 专家/轻量、主题、语言 | 不适用 | 骨架 | 该页读取失败 |
| `SET-LOG` | 自动保存、格式、脱敏、容量 | 不适用 | 骨架 | 容量读取失败 |
| `SET-BACKGROUND` | 后台长连接与记录 | 不适用 | 骨架 | 读取失败 |
| `SET-BT` | 默认 UUID、MTU、自动重连 | 没有默认 UUID 时行值为「未设置」 | 骨架 | 读取失败 |
| `SET-NW` | 扫描间隔、端口范围、超时 | 行值为默认 | 骨架 | 读取失败 |
| `SET-NL` | 默认 MTU、加密提示 | 行值为默认 | 骨架 | 读取失败 |
| `SET-SECURITY` | 高风险确认、清除本地数据 | 不适用 | 骨架 | 清除失败留在本页说明 |
| `SET-ABOUT` | 版本、bundle 名 | 不适用 | 不适用 | 不适用 |

专家/轻量只改变其他页的字段密度，不增加页面。

## 宽屏

领取 Goal：只做壳与分栏，不改页面编号，不新增目的地。

| 编号 | 是什么 | 默认 | 空 | 加载 | 失败 | 关射频 | 权限 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `WD-SHELL` | `xl` 侧栏 240vp，四项 | 选中项与内容一致 | 不适用 | 不适用 | 不适用 | 不适用 | 不适用 |
| `WD-SPLIT` | 达分栏阈值时左主右检 | 右检显示当前对象 | 右检「未选择」 | 右检骨架 | 右检写错误，左主保留 | 左主变为该页的阻断，右检清空 | 同左 |
| `WD-BOARD` | `DB-BOARD` 的宽屏排列 | 左指标，右告警与趋势 | 与窄屏空相同，不在右栏放入口 | 骨架 | 失败条在左栏顶部 | 与窄屏相同 | 与窄屏相同 |
| `WD-LOG` | 日志列表与详情分栏 | 右栏为选中行 | 右栏「未选择」 | 骨架 | 读取失败 | 不适用 | 阻断覆盖两栏 |

模块页在宽屏上的右检：

| 左主 | 右检 |
| --- | --- |
| `NW-SPECTRUM` | `NW-AP-DETAIL` |
| `BT-GATT-TREE` / `NL-SSAP` | 选中特征 |
| 任一终端 | `CMD-TRAY` |
| `LOG-STREAM` | `LOG-SESSION` |
| `SET-ROOT` | 选中的设置子页 |

窄屏这些右检是子页或半模态。Goal 不要为宽屏复制一套业务页面。
