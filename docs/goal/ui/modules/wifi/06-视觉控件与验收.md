# 视觉、控件与验收

## 总则

视觉沿用 YoUI Kit 已有 Token，不为网络模块单独发明品牌色。原型画布是 360×800、800×640、1280×800，单位按 vp 理解。

## Token

| 用途 | 浅色 | 深色 | 资源 |
| --- | --- | --- | --- |
| 品牌 | `#0A59F7` | `#317AF7` | `youi_primary` |
| 页面背景 | `#F1F3F5` | `#191A1C` | `youi_background` |
| 卡片 | `#FFFFFF` | `#202224` | `youi_surface` |
| 主文字 | 90% 黑 | 90% 白 | `youi_text_primary` |
| 次文字 | 60% | 60% | `youi_text_secondary` |
| 三级 | 40% | 40% | `youi_text_tertiary` |
| 成功 | `#64BB5C` | `#5BA854` | `youi_success` |
| 警告 | `#ED6F21` | `#DB6B42` | `youi_warning` |
| 错误 | `#E84026` | `#D94838` | `youi_error` |
| 选中底 | 品牌 10% | 品牌 10% | `youi_surface_selected` |

成功、警告、错误不互相替代，也不用品牌色表示危险。端口扫描确认用警告色。断开用错误色文字按钮。

字体：HarmonyOS Sans。原型在开发环境用 Noto Sans CJK SC 代替。标题 20fp / 中黑，列表标题 15fp / 中黑，正文 13–14fp，说明 12fp。报文用等宽。系统大字体时路径节点改折行，不把 6 个节点压到不可读；极端缩放下允许节点区横向滑动，但主操作仍留在视口内。

间距：8vp 网格。卡片圆角 16vp，芯片和按钮全圆角。页面水平边距 16vp。列表行最小高度 64vp。图标按钮热区 40vp，推荐 48vp。

图标优先 HarmonyOS Symbol：返回、扫描、停止、信号。信号格同时给数字 dBm，不单靠格数。

## 控件

| 场景 | 控件 | 不这样 | 原因 |
| --- | --- | --- | --- |
| 四类对象 | 模块内子页签 | 再做一个底部页签 | 底部页签属于工作台 |
| 宽屏透镜 | SideBarContainer Embed | 手机侧滑抽屉当主导航 | 窄屏没有足够宽度 |
| 列表进详情 | Navigation 推入；宽屏用分栏 | 始终新开全屏 | 中宽屏要留住列表 |
| 筛选 | 芯片单选 | 单独一页筛选器 | 维度少，就地切换 |
| 关联与新建会话 | 手机 bindSheet，宽屏检查器 | 对话框套长表单 | 半模态不阻断到底下的上下文；宽屏不必再遮一层 |
| 端口大范围 | 对话框 | Toast | 必须确认 |
| 轻量结果 | 页内横幅 | 连续 Toast | 冷却和门户需要留在页面上 |
| 未知时长 | 进度条加文字 | 只有转圈 | 扫描和探测要能停止 |
| 报文 | 列表 + 等宽文本 | 富文本卡片墙 | 对齐日志阅读 |

组件状态：默认、按下（品牌加深或 10% 黑叠底）、悬停（宽屏 5% 叠底）、焦点（品牌描边）、禁用（`youi_brand_primary_disabled` 或禁用字色）、加载（按钮内进度，标签改为「停止」或保持动词加进度）。

## 动效

- 子页之间左右过渡，表示它们同级。
- 详情从右推入。半模态自下而上，跟手。
- 信道图数据更新用短插值；暂停时不再插值。
- 扫描结束不闪白。
- 减少动态效果时，路径节点和进度改为静态图标加文字。

## 无障碍

- 正文与背景对比按 Token 的主文字，不使用 40% 黑做正文。
- 状态除颜色外有文字：当前、隐藏、已跳过、掩蔽。
- 图标按钮有读屏名：扫描、停止、返回、断开。
- 焦点顺序与视觉顺序一致。
- 报文行的读屏顺序是时间、方向、载荷。

## 系统特性

| 特性 | 本模块做法 |
| --- | --- |
| 状态栏 | 与标题栏同一表面色，保证时间可读 |
| 导航条 | 固定底栏抬高；半模态盖住页面底时，半模态自己留出底部空隙 |
| 深色 | 同名 Token，见原型 `26` |
| 后台 | 不继续主动扫描；会话断开用页内状态，不依赖通知才能恢复 |
| 分屏 | 按窗口宽度切单栏或分栏 |
| 分享 | 详情和报文的「更多」可走系统分享导出文本。导出不是首页 |

本模块不做服务卡片、实况窗和元服务。

## UX 对齐

| 标准项 | 等级 | 方案 | 验收 |
| --- | --- | --- | --- |
| 系统返回 | 必须 | 详情、终端返回；半模态和对话框可取消 | 非根页面都有返回或关闭 |
| 布局基础 | 必须 | 三档断点，见宽屏文档 | 360 / 800 / 1280 主任务完整 |
| 手势冲突 | 必须 | 核心动作都有点击入口 | 不依赖边缘手势 |
| 热区 | 必须 | 行高 ≥ 64vp，图标热区 ≥ 40vp | 主按钮可点中 |
| 对比与字号 | 必须 | Token 与 12fp 以上说明文字 | 深色主文字仍可读 |
| 导航条 | 必须 | 底栏抬高 | 发送按钮不被导航条挡住 |
| 深色 | 必须 | 同名 Token | `26` 与浅色层级一致 |
| 大屏 | 必须 | 四列职责不同 | 宽屏同时看见图和详情 |
| 键鼠焦点 | 必须 | 宽屏列表与主按钮可聚焦 | 连接表单可键盘提交 |

## 研发落地时的页面名

实现时建议的目的页名称：`LinkDestination`、`AirDestination`、`HostsDestination`、`SessionsDestination`、`ApDetailDestination`、`HostDetailDestination`、`SessionTerminalDestination`。半模态不进导航栈。

状态枚举直接复用 `WifiScanPhase`、`DiagnosticStepState`、`PortProbeState`、`LanHostAliveState`，不在界面层再发明一套同义词。
