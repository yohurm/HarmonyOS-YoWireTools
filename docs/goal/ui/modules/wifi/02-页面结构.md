# 页面结构

## 总则

下列页面都属于网络模块。状态栏保持可读的浅色或深色表面，不在左右做高对比分屏。底部为系统导航条留出区域，固定操作栏抬高，不压住导航条。

非根页面标题栏有返回。半模态有取消。对话框有取消。

## 链路

层级：模块根，子页签第 1 项。  
目标：看清当前路径的每一跳，并从这里开始一次检查。  
入口：进入网络模块的默认页；主机、会话、空口可切回。

```text
链路
├── 状态栏
├── 标题栏「网络」 / 动作「检查」
├── 子页签：链路 空口 主机 会话
├── 路径节点：射频 关联 地址 网关 解析 出口
├── 当前对象卡或步骤列表
├── 主操作：测这条路径 / 打开系统 WLAN / 去授权 / 重试
└── 系统导航条
```

信息优先级：路径节点高于 IP 明细，明细高于历史记录。  
主操作在路径异常时变成恢复动作（授权、打开系统 WLAN、重试），不固定成「检查」。

多端：窄屏纵向排列。宽屏时路径和步骤在画布，历史在对象列，选中的一跳在检查器。

## 空口

层级：模块根，子页签第 2 项。三种视图。

```text
空口
├── 标题栏动作：扫描 / 停止 / 冷却倒计时
├── 视图切换：列表 | 信道 | 时间
├── 列表视图
│   ├── 数量与缓存时间
│   ├── 筛选芯片：全部 2.4G 5G 6G 当前
│   └── 接入点行：信号格、名称、当前或隐藏、安全、频段、信道、dBm
├── 信道视图
│   ├── 频段芯片：2.4 / 5 / 6 GHz
│   ├── 信道图：横轴信道，纵轴 dBm，图形宽度表示占用
│   └── 选中接入点摘要
└── 时间视图
    ├── 窗口：30 秒 / 1 分钟 / 5 分钟
    ├── 曲线：至少当前选中项，可再叠加一条
    └── 图例
```

点列表行或信道图形，推入接入点详情。筛选不换页。

信道图的纵轴固定从 -30 到 -100 dBm。横轴随频段变化。系统没返回信道宽度时，图形用该频段常见宽度示意，摘要写明「宽度未返回」。

## 接入点详情

层级：推入。返回空口，并保持进入时的视图和选中项。

```text
接入点详情
├── 返回 / 标题「接入点」 / 「收藏」
├── 身份：名称、是否当前关联、信号格
├── 键值：BSSID 与掩蔽原因、RSSI、频段与频率、信道、
│         信道宽度、安全、标准、来源与时间、厂商
└── 底栏「交给系统连接」
```

系统未返回的字段保留行，值写「系统未返回」或「需要真实 BSSID」。不把空行删掉，避免用户以为应用漏读。

## 主机

层级：模块根，子页签第 3 项。

```text
主机
├── 网段条：推断出的 CIDR、私网说明、「修改」
├── 扫描进度或结果列表
└── 主机行：地址、时延、开放端口摘要、存活
```

点主机行进入详情。修改网段打开半模态。目标不是私网时，半模态内联错误，不发起扫描。

```text
主机详情
├── 返回 / 地址 / 「扫端口」
├── 存活、时延、厂商未知原因
└── 端口行：端口、协议、服务名、「打开」
```

「打开」进入新建会话，并带上主机与端口。常见端口给出建议协议：22 不默认开终端以外的协议名欺骗，1883 建议 MQTT，80/443 建议 HTTP，5353 标为 mDNS 实验项。

## 会话

层级：模块根第 4 项，终端为推入页。

```text
会话列表
├── 标题动作「新建」
└── 行：协议、目标、状态摘要

协议终端
├── 返回 / 协议与端口 / 「断开」
├── 状态条：已连接或错误码
├── 报文：时间、TX / RX / SYS、载荷
└── 底栏：文本或 HEX、输入、发送
```

HTTP 的报文区改为方法、URL、状态码、耗时和响应体。MQTT 的报文区改为订阅芯片和按主题分组的消息，底栏是发布。WebSocket 与 TCP 共用报文流，连接参数多一组 Header。UDP 无「保持连接」，状态用绑定是否成功表示。

这些差异都在同一终端页内，列表不按协议拆页。

## 半模态与对话框

系统 WLAN 交接半模态盖在空口或详情上：

```text
交给系统连接
├── 说明：普通应用不能直接关联
├── SSID、安全、频段
├── 主按钮「打开系统 WLAN」或禁用并说明原因
└── 取消，或在禁用时改为「复制 SSID」
```

新建会话半模态：

```text
新建会话
├── 协议芯片：TCP UDP HTTP WS MQTT
├── 主机、端口、超时；MQTT 另有 Client ID 与 QoS
├── 来源说明：手动，或来自某台主机的某个端口
└── 「连接」
```

端口扫描确认对话框写明目标、端口数量、仅限有权诊断的局域网，以及超过阈值会被拒绝。确认按钮用警告色。

## 跳转

| 从 | 动作 | 到 |
| --- | --- | --- |
| 链路 | 看空口 | 空口，选中当前关联的接入点 |
| 链路 | 测这条路径 | 链路的检查中状态 |
| 空口 | 点接入点 | 详情 |
| 详情或列表 | 交给系统连接 | 半模态，成功则离开应用去系统 WLAN |
| 主机详情 | 打开某端口 | 新建会话，字段已填 |
| 会话列表 | 点一行 | 该会话的终端 |
| 任一对象 | 系统返回 | 关闭半模态、对话框，或回到上一个网络页面 |
