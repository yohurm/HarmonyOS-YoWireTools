# 状态与文案

## 总则

每个对象都有可恢复的失败，而不是只有一句「请重试」。错误码使用 `WifiNetworkErrorCodes` 里已有的值。颜色之外还有文字或图标，色盲用户能区分成功、警告和失败。

下表是状态矩阵。会改布局的状态在表后展开。

| 状态 | 出现位置 | 用户能做什么 | 原型 |
| --- | --- | --- | --- |
| 链路就绪 | 已关联且出口可达 | 检查路径、切到空口 | `01` `26` |
| WLAN 关闭 | 射频关闭 | 打开系统 WLAN，或改诊断蜂窝 | `02` |
| 无 WLAN 读权限 | 缺少 `GET_WIFI_INFO` | 去授权，或只诊断默认网络 | `03` |
| 门户拦截 | 地址和网关通，出口被认证页拦住 | 复制网关、打开系统 WLAN。应用不代填门户 | `04` |
| 检查进行中 | 步骤有运行中 | 停止 | `05` `29` |
| 部分失败 | 某步失败，后续跳过 | 重试。文案带 `YW-NET-1001` 等 | `06` |
| 空口有结果 | 缓存或新扫描 | 筛选、进详情、切到图 | `07` |
| 扫描中 | `ACTIVE_SCANNING` | 停止。旧结果保持可见 | `08` |
| 空口为空 | 缓存为空 | 开始扫描 | `09` |
| 扫描冷却 | `COOLING_DOWN` 或 `LIMITED` | 看缓存。扫描动作禁用并显示剩余时间 | `10` |
| 信道 / 时间 | 同一选中项 | 暂停，避免图形跳动 | `11` `12` |
| 详情可读 | 选中接入点 | 收藏、交接连接 | `13` |
| 可以交接 | 能打开系统 WLAN | 打开系统设置 | `14` |
| 不能交接 | 无 `SET_WIFI_INFO` 或同等能力 | 复制 SSID。主按钮禁用 | `15` |
| 主机扫描中 | 私网探测进行中 | 停止 | `16` |
| 主机有结果 | 至少一台有响应或未知 | 进详情 | `17` |
| 主机为空 | 网段无响应 | 改网段，或回链路看是不是蜂窝 | `18` |
| 端口列表 | 主机详情 | 打开会话，或发起受控扫描 | `19` |
| 扫描范围确认 | 端口数达到确认线，未超过拒绝线 | 取消或开始 | `27` |
| 范围被拒绝 | 超过 256 或非私网 | 改范围。`YW-NET-2201` | 与确认框同结构，主按钮不出现 |
| 会话列表 | 零到多条 | 新建或进入 | `20` |
| 终端已连接 | TCP/WS 已建立，或 UDP 已绑定 | 发送、断开 | `21` |
| 新建会话 | 半模态或宽屏检查器 | 改字段、连接 | `22` `30` |
| HTTP 完成 | 收到状态码 | 再发送。超限时说明 `YW-NET-1005` | `23` |
| MQTT 已连接 | 订阅可收发 | 发布、退订、断开 | `24` |
| 会话丢失 | 回前台后套接字失效 | 重新连接。`YW-NET-2104` | `25` |
| WebSocket 服务端不可用 | 能力探测失败 | 只保留客户端。`YW-CAP-2001` | 新建会话里该模式不可选 |
| 后台恢复 | 模块从后台回来 | 刷新链路和缓存时间；不自动狂扫 | 链路就绪的刷新，不另做页 |

## 会改布局的状态

### WLAN 关闭

触发：`wifiActive == false`。  
展示：射频节点为关闭，后续节点停用。横幅说明空口不可用，蜂窝上的诊断和会话仍可进行。  
可操作：打开系统 WLAN；改为诊断蜂窝网络。  
禁用：空口扫描。  
文案：「WLAN 已关闭。空口分析不可用。」

### 无权限

触发：缺少 `GET_WIFI_INFO`，错误码 `YW-PERM-2002`。  
展示：关联节点为不可读。解析和出口仍可对默认网络检查。  
可操作：去授权；仍诊断默认网络。  
文案：「缺少读取 WLAN 信息的权限。」

真实 BSSID 不可读是详情里的一行，不是整页。原因用 `YW-PERM-2003` 或「系统未提供」，值显示掩蔽，不显示随机地址冒充真实地址。

### 门户

触发：本地地址存在，出口探测被认证拦截。  
展示：出口节点为警告。  
可操作：复制网关；打开系统 WLAN。  
禁用：应用内提交门户密码。  
文案：「出口被门户拦截。本应用不代填认证页。」

### 检查部分失败

触发：某 `DiagnosticStepState` 为失败。  
展示：失败步用错误色和错误码，后续步写「已跳过」。  
可操作：重试、改目标。  
文案示例：「解析失败，后面的步骤已跳过。YW-NET-1001。」

### 扫描冷却

触发：`WifiScanPhase.COOLING_DOWN` 或 `LIMITED`，错误码 `YW-WIFI-1002` / `YW-WIFI-1001`。  
展示：列表仍在，每行来源是缓存。标题动作改为剩余秒数并禁用。  
可操作：筛选、看图、进详情。  
文案：「主动扫描冷却中，列表来自 12 秒前的缓存。」

### 不能交接

触发：连接指定 WLAN 的系统能力不可用。  
展示：半模态主按钮禁用，下方改为复制 SSID。  
文案：「当前身份没有 SET_WIFI_INFO。不能打开系统连接流程。」

### 会话丢失

触发：进后台后连接被系统回收，错误码 `YW-NET-2104`。  
展示：报文保留，顶部错误条，发送禁用。  
可操作：重新连接。重连使用原参数。  
文案：「回到前台后套接字已断开。」

### 端口扫描确认

触发：用户请求的端口数量达到确认线且仍小于等于 256，目标是私网。  
展示：对话框，确认按钮为警告色。  
超过 256 或目标不是私网：不提供开始，说明 `YW-NET-2201` 或私网限制。  
文案：「将向 192.168.1.20 发起大量探测。仅用于你有权诊断的局域网。」

## 文案原则

- 按钮用动词：检查、停止、打开系统 WLAN、去授权、重试、连接、断开、发送、发布。
- 空状态说明原因：缓存为空、网段无响应、可能在用蜂窝，而不是只写「暂无数据」。
- 协议名、错误码、dBm、信道可以出现，但同一屏的第一句要能指导下一步。
- 所有用户可见句子进资源，中文变长时换行，不把正文字号降到 10fp 以下。

## 深色

`26-link-ready-dark` 使用 `youi_kit` 深色 Token：背景 `#191A1C`，表面 `#202224`，品牌 `#317AF7`。语义不变：成功仍是成功色，不把品牌蓝拿来表示警告。其余页面同一套映射，不逐张另绘。
