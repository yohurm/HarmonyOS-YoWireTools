# 视觉组件与适配

## 总则

星闪页面使用 YoUI Kit 已有 Token，不另做一套蓝牙蓝或调试绿。品牌色是鸿蒙宇宙蓝。密度按调试工具处理：一屏能看见状态、约束和下一步，但不把原始字节缩到不可读。

原型是浅色手机。深色走同名 Token，不在本目录重复出一套反色稿。

## 色彩

| 用途 | Token | 浅色 |
| --- | --- | --- |
| 品牌、链接、主按钮 | `youi_primary` | `#0A59F7` |
| 页面背景 | `youi_background` | `#F1F3F5` |
| 卡片 | `youi_surface` | `#FFFFFF` |
| 主文字 | `youi_text_primary` | 黑 90% |
| 次文字 | `youi_text_secondary` | 黑 60% |
| 说明 | `youi_text_tertiary` | 黑 40% |
| 错误 | `youi_error` / `youi_error_container` | `#E84026` |
| 警告 | `youi_warning` / `youi_warning_container` | `#ED6F21` |
| 成功 | `youi_success` / `youi_success_container` | `#64BB5C` |
| 分割 | `youi_divider` | 黑 10% |

错误只用在不能继续的能力失败。地址可能变化、RSSI 无效、名称不一致用警告。已连接、有效 RSSI、已加密用成功色，并且旁边有文字。

## 字体与间距

字体为 HarmonyOS Sans。地址、UUID、HEX 使用等宽。

| 层级 | 字号 | 用途 |
| --- | --- | --- |
| 标题 | 20fp / 中黑 | 导航标题 |
| 卡片标题 | 16–18fp / 中黑 | 平面名、设备展示名 |
| 正文 | 14fp | 说明 |
| 辅助 | 12fp | 能力条、字段名 |
| 等宽 | 12–15fp | 地址、UUID、记录载荷 |

间距用 8vp 网格：页边 16vp，卡片间距 12vp，卡片内边 16vp。卡片圆角 16vp，主按钮高度不小于 40vp、原型使用 44vp，胶囊圆角。点击热区不小于 40vp，主要按钮按 48vp 目标留白。

系统大字体时，平面卡和广播卡片允许增高，UUID 中间省略，不把字号降到 10fp 以下。

## 控件映射

| 界面对象 | ArkUI / YoUI |
| --- | --- |
| 模块导航 | `Navigation` + `NavDestination`。工作台是根 |
| 能力条 | 标题栏下方的通栏，不用 Toast |
| 过滤组、服务树 | `List` + `ListItemGroup` |
| 扫描模式、记录视图、编码 | 分段按钮 |
| 属性检视、过滤组细节 | `bindSheet`，一个宿主一个 sheet |
| 销毁端口 | `Dialog`，只用于这个不可撤销动作 |
| 发现进度 | `Progress`。持续发现用已运行时间，不用假百分比 |
| 终端记录 | `List`，新记录插在底部并保持可回看 |
| 空、错误、无权限 | YoUI 的空态、错误态、权限态，文案用本模块句子 |

不使用底部页签切换三个平面。不使用雷达动画作为发现的主要反馈。进度和「已上报 N 条」已经说明发现是否在进行；雷达会让人以为正在全量搜索附近蓝牙设备。

## 动效

页面推入使用 Navigation 的横向转场。半模态自下而上。过滤校验错误定位到字段，不整页闪动。发现进度跟随剩余时间。尊重系统「减少动效」时，进度改为数字，转场改为淡入。

## 深色

深色使用 `youi_kit` 的 dark 同名颜色。卡片仍比页面背景抬高一层。错误、警告、成功的文字色保持语义，不把品牌蓝拿来表示失败。等宽 HEX 在深色下使用主文字色，保证对比。

## 系统区域

内容避开状态栏和底部导航条。滚动内容的底部留出导航条高度，原型里手势条不压住按钮。非根页面都有返回。半模态底部按钮同样留出导航条，不贴在手势条上。

## 断点

| 宽度 | 布局 |
| --- | --- |
| 小于 600vp | 本目录原型。单栏栈 |
| 600vp 到 840vp | 仍单栏。卡片拉到内容最大宽度，记录行不拆成多列 |
| 大于等于 840vp | 发现台：过滤组在左，广播卡片在右。SSAP：树在左，属性在右。端口终端保持单栏，日志加高 |

分栏之后，选中的广播卡片和选中的属性要有选中底，避免左右栏失去对应关系。折叠屏开合时保留过滤草稿、未发送的端口输入和终端滚动位置。

## 无障碍

- 能力条、加密结论、拥塞、RSSI 无效都有可读文字。
- 图标按钮带文字，或提供可读标签。发现台的「绑定服务」「绑定端口」是文字按钮。
- 焦点顺序按视觉顺序：能力条、过滤或树、主按钮、记录。
- 禁用按钮保持可见，并有禁用原因可被读出。

## 关键文案

| 位置 | 文案 |
| --- | --- |
| 发现主按钮 | 按这组过滤开始发现 |
| 空过滤 | 不能开始发现。API 13 会拒绝空过滤 |
| 无结果 | 没有匹配这组过滤的广播 |
| 绑定页说明 | 这里不把两条能力合成一次连接 |
| SSAP 终止 | 终止连接 |
| SSAP close 确认 | 关闭后这个 Client 不能再使用 |
| 端口主按钮 | 注册端口 |
| 未加密 | 链路还没加密。配对完成不等于已加密 |
| 拥塞 | 对端来不及收 |
| 销毁确认 | 销毁端口。未发送的周期任务会停止 |

## 验收口径

- 原型中的主按钮、错误和警告能对应到上表 Token，而不是另一套色板。
- 手机宽度下，主按钮不被底部手势条遮挡。
- 宽屏分栏只发生在发现台和 SSAP，端口终端不拆成设备列表加日志的蓝牙双栏。
- 三个平面的入口文案能看出 API 下限和各自约束。

## 禁止事项

- 禁止为星闪单独引入新的品牌色。
- 禁止用 Toast 展示错误码或加密结论。
- 禁止在减少动效时只剩一个没有文字的加载圈。
