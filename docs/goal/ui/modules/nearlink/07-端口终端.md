# 端口终端

## 总则

端口终端调试的是 dataTransfer 通道。通道身份是双方一致的 UUID，对端地址只说明这一轮发给谁。页面把端口生命周期、加密结论和写拥塞放在收发记录上面，避免把这里做成另一份服务树或蓝牙串口页。

原型：

| 状态 | 文件 |
| --- | --- |
| 注册 UUID | `docs/goal/ui/prototypes/nearlink/16-port-register.svg` |
| 已连接收发 | `docs/goal/ui/prototypes/nearlink/17-port-terminal.svg` |
| 写拥塞 | `docs/goal/ui/prototypes/nearlink/18-port-congested.svg` |
| 未加密阻止发送 | `docs/goal/ui/prototypes/nearlink/19-port-unencrypted.svg` |

## 注册页

标题「端口」。能力条给出对端缩写地址，并标明需要 API 18。

区域：

1. 说明「通道身份是 UUID，不是设备名」。
2. UUID 输入。支持粘贴、最近使用和收藏。格式不合法时字段报错，不调用 `createPort`。
3. 期望包长。这是连接参数里的可选 MTU，示例值可以是 1024。文案写明它不是 SSAP 的默认 256。留空表示不传。
4. 加密意向。默认「不要求」。打开「要求加密」后，连接前必须走配对和 ACB 检查。
5. 主按钮「注册端口」。

注册结果：

| 结果 | 码 | 界面 |
| --- | --- | --- |
| 成功 | 无 | 进入「端口已就绪」，可以连接 |
| UUID 已注册 | 1009700020 / `YW-NL-3201` | 说明可以选择复用或先销毁 |
| 端口达到上限 | 1009700021 / `YW-NL-3202` | 列出已占用 UUID，引导销毁其中一个 |
| 参数非法 | 401 / `YW-NL-3101` | 留在表单 |
| 系统不支持 | 801 / `YW-CAP-3001` | 关闭本页入口，回到工作台 |
| 星闪已关 | 1009700003 / `YW-NL-1002` | 去系统设置 |
| 无权限 | 201 / `YW-PERM-3001` | 重新授权 |

## 终端区域

连接之后标题改为「端口终端」。

1. 能力条：连接状态、加密结论、是否拥塞。
2. 端口摘要：缩短 UUID、发送字节、接收字节、错误数。
3. 记录列表。每条有时间、方向「发 / 收」、长度和载荷。方向同时用文字和颜色。
4. 输入条。编码为文本、十六进制或 Base64。换行为无、CR、LF、CRLF。主按钮「发送」。次操作放在标题栏菜单：周期发送、清空视图、导出。
5. 周期发送的间隔和次数在菜单里设置。拥塞时自动暂停，不继续往队列里堆。

记录视图可以在「文本」「十六进制」「并列」之间切换。并列时同一条同时给出两种表示。导出为 TXT、CSV、JSON，导出的是当前会话记录，不另做日志模块页面。

## 连接与释放

端口已就绪后，主按钮是「连接」。连接参数为地址、UUID、可选包长。连接中可以断开。

正常释放顺序写在「销毁端口」的确认框里，让用户知道会停止周期发送、断开、再 `destroyPort`。确认框是这一页唯一的强打断对话框。销毁未注册 UUID 得到 1009700022 / `YW-NL-3203` 时，界面标成「已经释放」，不重复报错。

断开后记录保留，发送禁用，可以再次连接或销毁。

## 加密

能力条的加密结论只使用这些词：

| 状态 | 显示 | 发送 |
| --- | --- | --- |
| 不要求 | 加密未要求 | 允许 |
| 尚未查询 | 未确认 | 要求加密时禁止 |
| 配对中 | 正在配对 | 禁止 |
| 已配对但 ACB 不是 ENCRYPTED | 未加密 | 要求加密时禁止 |
| ACB 为 ENCRYPTED | 已加密 | 允许 |
| 查询失败 | 未确认 | 要求加密时禁止 |

「已配对」不能显示成「已加密」。查不到 `getAcbState` 时不能显示「已加密」。

用户打开「要求加密」后，连接前先 `startPairing`，再读 ACB。未加密时页面用错误条说明「链路还没加密」，主按钮「发起配对」，次按钮「改为不要求」。在改为不要求之前，发送保持禁用。

## 拥塞

`writeData` 返回 1009700023 时，能力条进入拥塞，错误码 `YW-NL-3301`。

- 当前这一包进入等待，不再接收新的发送。
- 周期发送暂停。
- 按退避重试，间隔从 50 毫秒增到最多 500 毫秒，最多 5 次。
- 界面写明当前退避和「第 n / 5 次」。
- 超过 5 次后停止，记录留在错误数里，发送按钮恢复为可手动重试。

拥塞期间「发送」禁用。断开仍然可用。

## 其他状态

| 状态 | 表现 |
| --- | --- |
| 注册中 | 主按钮加载，输入禁用 |
| 连接中 | 能力条「正在连接」，发送禁用，可断开 |
| 已连接 | 发送可用，除非加密策略或拥塞禁止 |
| 发送中 | 当前包显示在记录顶部为「发送中」 |
| 断开中 | 按钮禁用，直到状态回调 |
| 开关关闭 | 记录保留，连接和发送禁用 |

回到前台时调用 `getConnectionState`。若系统已断开，能力条改为「已断开」，不把旧的「已连接」留在屏幕上。

## 验收口径

- 注册页的主身份是 UUID，设备名不占据标题。
- 期望包长的说明能和 SSAP MTU 256 区分开。
- 未得到 `ENCRYPTED` 时，界面不出现「已加密」。
- 要求加密且未加密时，发送按钮不可用。
- 拥塞时周期发送停止，并且看不到新的待发数据继续入队。
- 销毁未注册 UUID 不会连续弹出同一条错误。
