# 会话绑定

## 总则

会话绑定是发现和两条数据平面之间的决定页。它把一条广播收成身份指纹，然后让用户选择 SSAP Client 或端口通道。这一页没有「连接」按钮。

原型：`docs/goal/ui/prototypes/nearlink/11-session-bind.svg`。

## 区域

1. 能力条写「随机地址只在这一轮有效」。
2. 身份卡：展示名、本轮地址、广播指纹。指纹由服务 UUID、厂商 ID 和本地名组成，与发现去重键一致。
3. 服务平面卡。说明将创建一个 Client，连接后发现 Service 和 Property。附注「同一远端不重复创建 Client」。
4. 端口平面卡。说明将用双方一致的 UUID 注册端口，不经过服务树，通道默认不加密。附注「UUID 才是通道身份」。

从广播卡片带预选进入时，对应平面卡用品牌色描边，另一张仍可点。点卡片即进入下一页，不再加第二颗确认按钮。

## 交互

选择服务平面：

- 若这个随机地址已经有未 close 的 Client，不创建第二个。进入已有服务树，并提示「沿用已有 Client」。
- 否则进入 SSAP 页，状态从「创建 Client」开始。

选择端口平面：

- 进入端口注册页。对端地址带入，UUID 仍要用户确认。
- 若收藏里有默认端口 UUID，填入输入框，不自动 `createPort`。

返回发现台不改变已创建的 Client 或端口。

## 收藏

身份卡提供「记住这台设备」。保存别名、最近地址、广播指纹、默认平面、默认 UUID、是否要求加密。保存成功用页面内一行说明，不用 Toast 承载这些字段。地址旁永久保留「可能变化」。

下次从收藏进入时，若只有旧地址、没有新的扫描结果，工作台不打开本页的连接动作，而是回到发现台并把指纹填进后筛。

## 状态

| 状态 | 表现 |
| --- | --- |
| 可选择 | 两张平面卡都可点 |
| 已有 Client | 服务卡文案改为「打开已有服务树」 |
| 端口 API 不足 | 端口卡禁用，说明当前系统没有 dataTransfer |
| 开关已关 | 两张卡都禁用，能力条引导去系统设置 |
| 权限丢失 | 两张卡禁用，提供重新授权 |

## 验收口径

- 页面上不存在同时代表两条平面的「连接」。
- 同一地址已有 Client 时，不会再出现「创建 Client」。
- 收藏写入的字段包含广播指纹，不只是地址。
