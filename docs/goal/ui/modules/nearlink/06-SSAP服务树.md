# SSAP 服务树

## 总则

SSAP 页是一个 Client 的工作台。连接成功之后，主体是可展开的服务树；属性读写放在半模态里，避免把树压成扁平操作列表。MTU 和操作队列始终可见，因为它们决定下一次写能不能发出去。

原型：

| 状态 | 文件 |
| --- | --- |
| 连接中 | `docs/goal/ui/prototypes/nearlink/12-ssap-connecting.svg` |
| 服务树就绪 | `docs/goal/ui/prototypes/nearlink/13-ssap-tree.svg` |
| 属性检视 | `docs/goal/ui/prototypes/nearlink/14-ssap-property.svg` |
| 连接失败 | `docs/goal/ui/prototypes/nearlink/15-ssap-connect-failed.svg` |

## 区域

标题为「SSAP」，可返回。返回时若 Client 仍在连接或已就绪，先问是否断开。确认断开走 `disconnect`。只有用户选择「关闭 Client」才 `close`。close 之后实例不可再用，页面回到发现台。

能力条按运行状态切换，始终带上对端别名。

### 连接步进

未就绪时不显示空树，显示四步：创建 Client、连接、发现服务、就绪。当前步写明耗时。连接中的次按钮是「终止连接」，调用 `disconnect` 取消正在建立的连接，不 close。

### 就绪后的树

1. 服务节点显示缩短后的 UUID，可展开。展开后列出属性。
2. 每个属性一行：UUID、权限芯片、通知状态、进入检视的「打开」。
3. 权限芯片只显示实际权限：读、写、通知。未知权限显示「权限未知」，不猜成可写。
4. 已订阅的属性在行下给出最近值的十六进制摘要。
5. 树下方固定操作队列一行，以及「请求 MTU」「刷新服务」。

服务节点用 List 的分组。属性不是第二层页面。宽屏大于等于 840vp 时，树在左栏，检视在右栏，不再盖半模态。

## 属性半模态

点「打开」拉起半模态，宿主是该属性行，不在页面根上链式绑定多个 sheet。

半模态内容：

- 属性 UUID 和权限芯片。
- 最近值。可在十六进制和文本之间切换。文本含不可见字符时仍保留十六进制。
- 「读取」。无读权限时禁用，并写「没有读权限」。
- 「写入」。无写权限时禁用。有权限时提供文本或十六进制输入，以及写入类型。
- 「订阅」或「停止订阅」。无通知权限时不显示订阅。
- 超过当前 MTU 的写入在发送前拦截，说明需要分包或先协商更大的 MTU。

关闭半模态不取消进行中的读、写或订阅。队列完成前，半模态里的对应按钮保持加载。

## MTU

默认 256。请求范围 [22, 512]。输入超出范围时字段报错 `YW-NL-2401`，不调用接口。请求后队列显示「正在协商」，收到 `mtuChange` 才把能力条改成协商值。超时未收到事件则保留默认值，并记一条警告 `YW-NL-2402`，不把请求值假装成已生效。

## 操作队列

读、写、订阅、请求 MTU 串行。队列非空时，其他会触发这些调用的按钮禁用，能力条写明当前动作。失败不自动跳过下一项；用户看到错误后再决定重试。

## 状态

| 状态 | 能力条 | 主区域 | 恢复 |
| --- | --- | --- | --- |
| 创建中 | 正在创建 Client | 步进停在第一步 | 失败 `YW-NL-2101`，回到发现 |
| 连接中 | 连接中和秒数 | 步进停在第二步 | 终止或等待 |
| 连接失败 | 未连接 | 错误 `YW-NL-2102` | Client 未 close 时可重试；否则重新发现 |
| 发现服务中 | 正在读取服务 | 步进停在第三步 | 失败 `YW-NL-2103` 可刷新 |
| 就绪 | 已连接、MTU、队列 | 服务树 | 断开或关闭 Client |
| 读写失败 | 队列失败 | 半模态标出权限或错误码 | `YW-NL-2201` 读、`YW-NL-2202` 写、`YW-NL-2301` 订阅 |
| 断开后 | 已断开 | 树和日志保留，操作禁用 | 重试连接或关闭 Client |
| 开关关闭 | 星闪已关 | 树保留为只读 | 去系统设置，回来后重连 |

发现服务成功但服务列表为空时，树区写「服务端没有返回服务」，保留「刷新服务」，不画假节点。

## 验收口径

- 同一远端看不到第二个「创建 Client」。
- close 之后页面不再提供重试连接，只提供重新发现。
- 无读权限的属性，读取按钮禁用且说明原因。
- MTU 输入 21 或 513 不能发出请求。
- 未收到 `mtuChange` 时，界面仍显示 256，并有警告。
- 队列执行期间不能并行发起第二次写。
