# 能力工作台

## 总则

能力工作台回答「这台机器现在能不能做星闪调试」。它不扫描、不连接。三个平面在就绪之前只显示原因，不进入空白流程。

原型：

| 状态 | 文件 |
| --- | --- |
| 三平面就绪 | `docs/goal/ui/prototypes/nearlink/01-bench-ready.svg` |
| 硬件不支持 | `docs/goal/ui/prototypes/nearlink/02-bench-unsupported.svg` |
| 开关关闭 | `docs/goal/ui/prototypes/nearlink/03-bench-switch-off.svg` |
| 未授权 | `docs/goal/ui/prototypes/nearlink/04-bench-permission.svg` |

## 区域

自上而下：

1. 标题「星闪」。根页面无返回。
2. 本机就绪。四格：硬件、开关、权限、环境。每格都有文字，不只靠颜色。
3. 三张平面卡。每张写明 API 下限和这一平面特有的风险，右侧是「进入」或「预留」。
4. 最近会话。写明平面、对端别名、Client 或端口是否还在、MTU 或包长。
5. 预留说明。广播、SSAP Server、合作集合成一行，不可点进页面。

平面卡的正文只写该平面的约束，不写「点击连接设备」。

| 平面 | 标题 | 正文要点 | 进入条件 |
| --- | --- | --- | --- |
| 发现 | 按过滤契约发现设备 | 组间任一、组内同时；地址会变 | 支持、开关已开、已授权 |
| 服务 | 服务与属性树 | 一个远端一个 Client；操作串行 | 同上，且 API 不低于 13 |
| 端口 | UUID 端口终端 | 不默认加密；拥塞会暂停发送 | 同上，且 API 不低于 18 |

API 不到 18 时，端口卡保持可见但不可进入，说明「当前系统没有 dataTransfer」。不把整张卡藏起来，避免用户以为模块没有这条能力。

## 交互

- 点发现卡进入发现台。
- 点服务卡时，若没有存活 Client，进入发现台并提示先选定对端。不打开一棵空服务树。
- 点端口卡时，若没有存活端口，同样先去发现台。已有端口则进入终端。
- 最近会话的「继续」只在 Client 未 close 或端口未 destroy 时可用。
- 地址失效时，「继续」改为「按指纹重新发现」。
- 「打开系统星闪设置」使用系统设置跳转，目标路径按 Codelab：设置、多设备协同、星闪。不调用 `enableNearlink()`。

## 状态

### 就绪

四格为支持、已开、已授、真机。三张平面卡可进入。最近会话可空，空时不画假设备，写「还没有会话」。

### 不支持

`isNearLinkSupported()` 为否，或运行在模拟器。错误码 `YW-NL-1001`。四格里硬件为「不支持」，开关和权限显示「—」。三张平面卡收成一张不可进入的说明。没有扫描按钮。

恢复：更换支持星闪的真机。工作台保持可看，避免用户以为应用崩溃。

### 开关关闭或切换中

`STATE_OFF` 使用警告条，主按钮「打开系统星闪设置」，错误码 `YW-NL-1002`。`STATE_TURNING_ON` 与 `STATE_TURNING_OFF` 用同一位置显示「正在开启」或「正在关闭」，按钮禁用，直到 `stateChange` 给出 `STATE_ON` 或 `STATE_OFF`。切换中不保留可点的平面入口。

### 未授权

硬件支持且开关已开，权限格为「未授」。说明 `ohos.permission.ACCESS_NEARLINK` 同时覆盖发现、SSAP 和端口。主按钮「去授权」，次按钮「暂不」。拒绝后错误码 `YW-PERM-3001`，三个平面锁定，就绪区仍可读。永久拒绝时，「去授权」改为「前往系统权限页」。

### 探测失败

支持查询抛错时，四格显示「未能确认」，提供「重新读取」。不把失败画成「不支持」。

### 回到前台

每次回到前台重新读支持、开关和权限。发现或会话若在后台被系统打断，工作台不自动重扫；最近会话标明中断原因。

## 文案

| 场景 | 文案 |
| --- | --- |
| 不支持 | 这台设备没有星闪硬件 |
| 模拟器 | 星闪不能在模拟器里调试，请换真机 |
| 开关关闭 | 星闪开关关闭。路径：设置 › 多设备协同 › 星闪 |
| 未授权 | 发现、服务和端口都需要星闪权限 |
| 端口 API 不足 | 当前系统没有端口通道 |

## 验收口径

- 不支持时，界面上不存在可点的发现、服务、端口入口。
- 开关关闭时，主按钮打开系统设置，而不是直接打开星闪。
- 权限拒绝后，仍能看见硬件和开关状态。
- 最近会话能区分 SSAP 和端口，并能在地址失效时改走重新发现。
