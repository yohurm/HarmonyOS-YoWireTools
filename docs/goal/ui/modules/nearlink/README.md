# 星闪模块界面设计

## 总则

本目录是 YoWireTools 星闪模块的界面设计。它只定义星闪相关页面、状态和原型，不改蓝牙、Wi-Fi 或其他模块。

旧的星闪界面稿作废。本次按 NearLink 的真实能力流重做：先判断本机能不能用，再按过滤契约发现广播，然后在服务平面和端口平面里二选一。发现结果不是蓝牙设备列表，会话建立也不是一颗「连接」按钮。

文档遵循本仓 `.projectark/0-通用项目开发规范/0.2-文档规范.md` 的写法：说明是什么、为什么、怎么组织；流程用图；不写排期、人员和测试计划。页面状态和验收口径按 `.projectark/4-专家模型/HarmonyOS UIUX设计师.md` 收口，方便 ArkUI 落地。

## 范围

| 包含 | 不包含 |
| --- | --- |
| 能力工作台 | 蓝牙发现、配对、SPP、GATT |
| 发现台与广播检视 | Wi-Fi、网络调试 |
| 会话绑定 | 应用壳、底部主导航、设置总页 |
| SSAP Client 服务树 | SSAP Server 可操作页 |
| dataTransfer 端口终端 | 星闪广播可操作页、合作集 |

SSAP Server、星闪广播、合作集只在工作台上说明预留，不提供可进入的半成品页面。

## 页面与原型

| 页面 | 必要状态原型 |
| --- | --- |
| 能力工作台 | 就绪、不支持、开关关闭、未授权 |
| 发现台 | 过滤契约、发现中、广播卡片、无匹配、空过滤被拒绝 |
| 广播检视 | 原始字节与字段 |
| 会话绑定 | 服务 / 端口二选一 |
| SSAP | 连接中、服务树就绪、属性半模态、连接失败 |
| 端口终端 | 注册 UUID、已连接、写拥塞、未加密阻止发送 |

## 禁止事项

- 禁止把发现结果做成头像、名称、「未配对」和右箭头组成的蓝牙列表。
- 禁止用一颗「连接」同时代表 SSAP 和 dataTransfer。
- 禁止在 API 13 上允许空过滤直接开扫。
- 禁止把随机地址当成可以长期依赖的设备身份。
- 禁止在 `getAcbState` 未返回 `ENCRYPTED` 时显示「已加密」。
- 禁止为了换皮去改其他模块的页面或组件。
