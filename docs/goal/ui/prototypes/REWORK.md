# 这套原型怎么画的

高保真从 `main`（`d125048`）新建，目录就是本文件夹。版式逐页对照 PR #26 `cursor/ui-spec-market2-5ad2` 里的 `docs/goal/ui/`，尤其是 `app-shell/layout-patterns.md`、`app-shell/design-tokens.md` 和各模块页面说明。

## 采用的布局

- 蓝牙和星闪扫描：白卡片，圆角 16，行高 76。经典蓝牙和低功耗的「连接」是浅灰胶囊、品牌色字，贴在卡片右侧。页面底部一颗实心胶囊按钮。
- 星闪扫描行内不放连接。随机地址在次行末尾用中性胶囊「随机」。
- 日志：顶栏分类、关键字、一排级别芯片。选中为黑底白字。列表是 48 高的白行和圆点，不是彩色描边卡。
- 空态和权限墙：中部一句说明，能恢复时底部一颗主按钮。不放超过 48vp 的插画，也不在正式页上同时摆三颗演示芯片。
- 连接：底部半模态。第一行标题和关闭，然后字段，底部一颗主按钮。Wi-Fi 是只读 SSID、密码和「下一步」。星闪只在需要端口时出现「端口」和「连接」。
- 测速在诊断的「故障」页：一个页标题字号的速率，下面三列时延、下载、上传，再是通过/失败清单。

## 工作台两案

PR #24 的线框把工作台入口留成未选定：方案 A 是分组列表，方案 B 是模块宫格。这两张现在都按本目录的组件画成高保真，并各有 PNG，对照图是 `phone/workbench-ab.svg`。

- 方案 A：状态条、最近会话、模块三行都是列表。
- 方案 B：蓝牙、网络、星闪三张宫格，下面仍是最近会话。
- `workbench-default` 仍是 PR #26 正文里的工作台：只有最近会话，不重复底栏上的三个模块，也不用宫格。

选定之前，A/B 和规范页并存在这个目录里。

## 和上一套稿的差别

PR #28 那套四页签、工具宫格、空态插画、测速刻度弧、深色彩虹日志和日志侧滑，都不在 #26 的组件树里。本分支没有沿用那些画面，也没有改 #28 的分支。

壳保持五个目的地。工作台只放最近会话。日志和设置从页内推进去。

## 字体

规范写的是 HarmonyOS Sans。出图环境只有文泉驿微米黑和文泉驿等宽微米黑，PNG 用它们栅格化。换成 HarmonyOS Sans 后，字宽会有少量差别，行高和边距仍按 4/8/12/16 和页面说明里的 48/56/64/76。

## 这套图没有单独展开的页

HTTP、WebSocket、Socket 终端、局域网发现和 SSAP 树没有各自的整页。网络总览已经给出前四者的入口；星闪连接半模态覆盖需要端口时的连接。命令行上的文字是排版样例，不代表已合并的命令编号。
