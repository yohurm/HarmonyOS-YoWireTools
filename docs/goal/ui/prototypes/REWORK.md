# YoWire 高保真原型重画

从 `main` 新开分支，只提交说明和原型图。业务代码不动。PR #19 的界面文案规范、PR #22 的静态稿、以及此前按薄目录画出的稿，都不作为这套图的来源。

`main` 上没有 `docs/goal/ui` 的逐屏规格。这里不把旧规格抄回来。页面内容来自仓库里的 PRD（工作台、蓝牙、Wi-Fi、星闪、日志与命令、权限），视觉来自下面读过的样例。

## 信息架构

一个应用、一条导航。手机底栏只有四个目的地：首页、调试、控制台、设置。Wi-Fi、蓝牙、星闪是「调试」里的三行，点进去仍是同一条栈，不各做一套底栏。

宽屏把同一组四个目的地放到左侧竖栏，内容区再做列表|详情。分栏时不画返回键。

## 色彩

用 HarmonyOS NEXT 色彩文档里的浅色 Token，不另做一套 Material 色。

| Token | 值 | 用在 |
| --- | --- | --- |
| brand | `#0A59F7` | 选中、主按钮、强调文字、信号条 |
| background_secondary | `#F1F3F5` | 页面雪域灰 |
| comp_background_primary | `#FFFFFF` | 分组卡片 |
| font_primary | `#E5000000` → `#1A1A1A` | 标题和正文 |
| font_secondary | `#99000000` → `#666666` | 辅助文字，对比约 5.7:1 |
| comp_emphasize_tertiary | 约 `#E7EFFE` | 选中芯片、图标底 |
| warning | `#E84026` | 错误图标和级别字母 |
| alert | `#ED6F21` | 警告字母和未加密提示底 |

`#64BB5C` 是系统确认色，小字对比不够，状态句子改用正文色。ibest-ui-v2 的主色是 `#1989fa`，只借组件结构，不借这套蓝。

字号：页面标题 24，导航标题 16，行标题 16，正文 14，元信息 12。底栏标签用 12，样例里是 10fp，抬高是为了可读。间距 4 / 8 / 12 / 16。卡片圆角 16。主按钮高 40、胶囊。触控行不低于 56。

## 技能怎么用的

1. **ui-ux-pro-max**：跑过 design-system 检索。它建议海军蓝 `#1E3A5F`、绿色 CTA 和营销首屏。产品是调试工具，色彩又被宇宙蓝/雪域灰钉死，所以丢掉配色和 Hero 结构，留下对比度 4.5:1、不用表情当图标、底栏不超过五项、表单要有可见标签。
2. **interface-design**：按工具界面来排，不按落地页。每屏一个主动作。首页的重点是最近会话，扫描页的重点是搜索结果，设置页的重点是分组。没有眉题，没有大数字指标墙。
3. **ui-design-brain / baoyu-design**：层次和密度。空态留在内容区。开关只给立刻生效的设置。半模态里不再套半模态。
4. **impeccable**：Operate 模式，过了一遍工艺底线。没有渐变字、左侧色条、阴影加描边、彩虹徽章、表情图标、等权双主按钮。等宽字体只出现在日志和报文。

## 和旧稿不同的决定

- 底栏第四项写「设置」，不写「我的」，避免变成社交个人页。
- 补上 Wi-Fi / 蓝牙 / 星闪三个模块首页，以及协议调试、星闪不支持。PRD 要求进星闪前先看能力。
- Wi-Fi 环境列表上方有信道占用，是环境分析的数据，不是装饰条。
- 连接网络在手机上是底部半模态。工具库网页把同一组件预览成居中灯箱，那是市场页，不是手机导航。
- 宽屏侧栏是 multi-nav-bar 的 lg 竖栏（96），不是再做一条 40% 的应用轨。40% 分栏留给 NavigationSettings 那种「列表|详情」，用在 Wi-Fi 内容区。
