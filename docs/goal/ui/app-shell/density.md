# 密度

来源：S3 interface-design 的 Operate 模式（可扫读优先于表现）；S2 impeccable 的工具界面；列表文档「效率型应用看见的是文本，不是插画」；H5 智慧家居只说明底栏可以有五项，不搬生活方式大卡。

一屏一个焦点：

1. 扫描页的焦点是结果列表，空的时候才是状态标题。
2. 连接页的焦点是半模态里的一颗主按钮。
3. 详情页的焦点是标签/值列表。
4. 日志页的焦点是滚动行，筛选收在顶栏。
5. 设置页的焦点是分组列表，没有搜索框，除非组多到需要找（现在只有三组，见设置页）。

效率列表不放超过 48vp 的插画。扫描尚无结果时，可以用 48vp 的系统 Symbol 表示「正在听」，资源名必须在 SDK 里核对，不猜 `sys.symbol` 名字。已有行之后图示收起。

行内结构：主行 `font_primary` 16，次行 `font_secondary` 14，上下间隔 2vp。右侧控件与正文间隔 12vp。图标 24vp 或 16vp。

状态胶囊是 `Row` + `Text`，高 20vp，水平内边距 8vp，圆角沿标签场景用 4vp（小于卡片 16vp，避免和设备卡抢圆角）。填充用 `comp_emphasize_tertiary` / `confirm` 的 10% 容器 / `warning` 的浅底，字用对应语义色。不新造名为 StatusPill 的系统组件；`youi_kit` 里的同名控件不在本规范里当 API。
