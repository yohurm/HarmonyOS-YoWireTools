# 工具类密度

调试界面以扫读为主。智慧家居模板的大图卡片只说明壳可以有底栏，不作为行高。WLAN 列表和蓝牙扫描结果才是密度样板。

## 层级

一屏三层，再多就拆页：

1. 结果或页状态：一句 Title_M，一句 Body_M。例如「搜索成功 / 已搜索到周边设备」。
2. 可操作列表或表单：64vp 或 48vp 的行，或 sheet 里的字段。
3. 说明：Caption_L，只做标签，不做段落。错误原因可以到两行 Body_M，第三行起收进详情。

ui-design-brain：一个区域内一颗主按钮。扫描页的主操作是文字按钮「重新搜索」，连接 sheet 的主操作是胶囊「连接」或「下一步」。两颗不同时强调。

## 间距节奏

左右始终 space.16。结果标题到辅文 space.2。辅文到列表 space.24。列表组与组 space.12。组内行与行 0，靠行高分开，不在每行下加 12vp。数据卡之间 space.12。

宽屏列表与详情之间 space.12，详情内部左右仍是 space.16。

## 触控

- 列表行全部可点，行高即热区，不低于 48vp。
- 行右侧若还有「连接」「信息」，该按钮自己 40vp 高，和行点击不是同一件事。行点击进详情，按钮做连接或说明。WLAN 参考里信息图标是独立命中。
- 底栏每一项宽度均分，高度 56vp。
- 不把 Caption 当按钮。

## 列表行

| 种类 | 高 | 内容 |
| --- | --- | --- |
| 扫描 / WLAN | 64vp | 24vp 图标，名称 Body_L，次行 Body_S，右侧 40vp 文字或图标按钮 |
| 设置 / 更多 | 48vp 或 56vp | 名称 Body_L，有当前值时次行 Body_S，右侧箭头 `SymbolGlyph` 16vp |
| 日志 | 48vp | 4vp 色点，时间 Caption_L，摘要 Body_S 单行省略 |
| 详情值 | 不固定行组件 | 标签 Caption_L，值 Body_L，块间距 space.16 |

效率型列表不放 48vp 以上的插画。设备图只出现在扫描还没有行的图示区。

## 状态胶囊

高 20vp，左右 padding space.8，字 Caption_L，圆角 radius.4。文案不超过四个汉字或一条短状态（已连接、扫描中、未授权、不可用）。颜色只用 Token 里的四态加中性。胶囊不可点；要点击去授权，旁边另放文字按钮。

## 宽窄

| 窗口宽 | 壳 | 列表+详情 | 半模态 |
| --- | --- | --- | --- |
| <600vp | 底栏 | 列表 push 详情 | 底部面板 |
| 600–839vp | 仍是底栏（五个目的地，侧栏会挤内容） | 页内左右分栏 | 居中面板 |
| ≥840vp | 侧栏，底栏隐藏 | 页内左右分栏 | 居中面板 |

栅格：<600 四列，600–839 八列，≥840 十二列（`布局基础.md`）。边距仍用 space.16，不因为八列改成 24。平板 32vp 边距留到有平板 HAP 再定；现在只有 phone。

分栏时列表不窄于 240vp。详情值的行宽随列伸展，数字和地址不换到图标下面。
