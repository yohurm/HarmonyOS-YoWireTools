# 布局模式

八个参考各管一种布局。页面选用其中的模式，不把家居模板的大卡片或品牌色抄进来。对照表写在每一屏文末。

## 扫描列表

来源：蓝牙扫描组件的结果页（标题「搜索成功」、辅文「已搜索到周边设备」、手机雷达图、蓝色文字按钮「重新搜索」、下方「已搜索到设备」）。wifi 扫描选择组件的预览也是先选网络再进入下一步，列表本身不是营销卡。

窄屏自上而下，整页一个 `Scroll` 只包在列表还没出现时的结果区；有列表后列表自己滚动，结果头固定在列表外：

1. 结果标题用 Title_M（24vp、Bold）。辅文用 Body_M，二级文本色。
2. 没有行时，标题下是 160vp 高的图示区：`Stack` 里居中 `SymbolGlyph`（24vp 不够表达雷达时用 48vp 的 `sys.symbol` 无线图标，具体资源名实现时在 SDK 面板核对，禁止猜名字）。
3. 图示下是一颗文字按钮「重新搜索」或「开始搜索」，`ButtonStyleMode.TEXTUAL`，品牌色，热区高度 40vp。
4. 有行时图示收起，`SubHeader` 写「已搜索到设备」，下面 `List` + `ListItem`。行高 64vp：左 24vp 图标，主行 Body_L，次行 Body_S 二级色，右缘文字按钮「连接」，与正文间隔 12vp。

不采用：把雷达图和长列表叠在同一屏上抢高度。成功且已有行时，雷达让位给列表。

## 连接 sheet

来源：wifi 扫描选择组件。市场灯箱里能看见的控件是：下拉「点击选择 Wi-Fi」/ 已选 `wlanaccessv2.0`、密码框带可见性图标、一颗蓝色胶囊「下一步」、下一行结果「wifi名称: … 密码…」。灯箱把这块放在手机画面中央；设计指南里手机竖屏的同类面板是底部半模态（`半模态面板.md`：遮罩、标题、内容、关闭）。本规范在手机上用 `bindSheet`，不另做一套居中自定义窗去模仿灯箱裁切。

- 模态，有遮罩。点遮罩或关闭按钮收起。
- 圆角 32vp（半模态/弹出框）。
- 内容自上而下，间距 16vp，左右 16vp：`Select`（高度至少 40vp，外观接近截图里的白底大圆角字段，圆角用按钮档 20vp）、`TextInput` type Password、尾部 40vp 图标按钮切换 `showPassword`、一颗 `Button` EMPHASIZED「下一步」或「连接」、结果行 Body_S。
- 一个区域只有这一颗主按钮。动词开头。
- 不可逆动作不放在这张 sheet。断开用列表行上的文字按钮，再经 `AlertDialog` 确认。

宽于 600vp 时，设计指南的半模态改为居中面板。仍是 `bindSheet` 的宽度适配，不新开路由。

## list + detail

来源：WLAN 信息查询。左机「WLAN」下分「已连接 WLAN」「可用 WLAN」，行上是名称、锁图标、「加密」、右侧信息图标。右机「Test WIFI」返回后是 MAC、IP、子网掩码、网关、DNS，标签在上、值在下，空值是灰条。

- 窄于 600vp：列表 push 一个 `NavDestination` 详情。详情 `Scroll` > `Column`，每项标签 Caption_L 二级色，值 Body_L。空值显示「未读取」，灰底圆角 8vp 的条，高度 8vp，不留白假装有数。
- 600vp 及以上：同一目的地里 `Row`，列表宽 280vp（不低于 240vp），详情 `layoutWeight` 1。不为此再套一棵 `Navigation`。
- 分组用 `ListItemGroup` + `SubHeader`。已连接组最多一行，可用组可滚动。

## 场景 Tab

来源：NetworkQuery 的四格：「连接到指定网络」「网络状态感知」「WLAN定位」「网络故障诊断」。等宽文字，选中与未选中靠字重和品牌色区分，没有图标。

- `Tabs` `barPosition` Start，`barMode` Fixed。页签 2–4 个。超过 4 个改成扫描列表上的 `SegmentButton`，不把底栏变成第二排页签。
- 切换页签不 push、不清栈。各页签保留自己的滚动位置。
- 页签文字 Subtitle_S。选中 Medium + 品牌色，未选中 Regular + 二级色。条高 40vp。

## 控制台日志

来源：IKConsoleKit 商品页上的页签「网络 / 日志 / 悬浮 / UserAgent / Web / cookie / pref」。本应用不引入该库，只取「顶栏用页签切开调试流」这一种结构。

- 顶上场景 Tab，内容是 `List`，行高 48vp，单行不换行时尾部省略，点行进入详情。
- 日志正文 Body_S，十六进制开 `fontFeature` `tnum`。方向用 4vp 圆角色点（收/发），不用表情。
- 底栏输入只在终端屏出现：`TextInput` + 一颗主按钮「发送」。日志中心没有发送栏。

## App shell

来源：智慧家居模板四台手机的底栏（首页、产品、我的，以及设备模拟）。拿走的是「图标 24vp + 文字、当前项品牌色、内容在底栏之上」。不拿走家居海报、房间卡片、登录插画。

五个目的地见 [navigation.md](navigation.md)。窄屏悬浮式底栏高 56vp；840vp 及以上改为侧栏，底栏消失。侧栏项高 48vp，左图标右文字。

## 数据卡

来源：BluetoothLowEnergy 通信预览。竖向白卡片，左侧色点，大号数字，右侧或下方说明（体温、心率一类）。

调试里用来展示少量实时量（RSSI、MTU、吞吐），不用来代替设备列表。卡：宽 100%，高至少 72vp，圆角 16vp，内边距 12vp。数字 Title_S，说明 Caption_L。一屏最多三张，再多改列表。

## 过滤后扫描

来源：FastBle 的商品说明（过滤、扫描、连接）。交付的截图里没有它的界面，所以只规定顺序：过滤条件在 `bindSheet` 里改完，回到扫描列表再开始。不在列表每一行内嵌整张过滤表单。空过滤是否允许，由该模块的 ViewModel 决定并反映到主按钮的禁用态，规范不另造错误码。
